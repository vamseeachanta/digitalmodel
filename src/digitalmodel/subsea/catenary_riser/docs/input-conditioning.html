Catenary riser input conditioning

These contracts cover offline input conditioning and defaults. Commercial-solver exports, statics, dynamics, material presets and design acceptance remain separate prerequisites. The lazy-wave analyzer and uncited arch-height estimate refuse calculation. Strict expected failures for the separate legacy vertical-force defect remain unchanged.

Units and gravity

The modern API uses metres, kg/m³, newtons and m/s². Configuration gravity defaults to 9.81 m/s² as a compatibility assumption, not a measured site value or standard gravity. An explicit calculator override takes precedence without changing the source configuration. Legacy pipe geometry uses inches with SI densities and gravity. No automatic unit inference is performed.

Compatibility

Before this change, the legacy router returned configurations with missing or unsupported calculation names unchanged, without performing a calculation. It now raises ValueError. Callers must select catenary or catenary_riser, directly or under meta; a basename containing catenary does not supply that selection.

The declination grid previously included 0 degrees; it now starts at 0.01 degree and retains fractional angles. Existing grid consumers must account for the changed first sample. The historical meaning of BuoyancyFactor is not established by the synthetic tests. Maintainer confirmation that uplift divided by reference-fluid bare weight matches historical inputs is required before engineering use.

Worked examples

For the synthetic modern riser OD=2 m, wall=0.5 m, material/contents/external densities=4/1/2 kg/m³, net mass is 1.25π kg/m. At g=2 m/s², weight is 2.5π=7.853982 N/m. With a=3 m and height=2 m, suspended length is 4 m, H=7.5π=23.561945 N and top tension=12.5π=39.269908 N. At g=4 every force doubles and geometry is unchanged. Independent arithmetic appears in test_simple_configured_gravity_and_default_override_hand_case.

The legacy buoyancy case uses coated OD=2 inch, water/foam densities=4/2 kg/m³ and reference weight=8π(0.0254)² N/m. A factor of 0.5 specifies uplift=4π(0.0254)² N/m. At g=2, continuous OD=√8 inch; at 25% coverage, discrete OD=√20 inch. At g=4 the same specified uplift gives OD=√6 inch. Actual bare weight=12π(0.0254)² N/m becomes 8π(0.0254)² N/m after subtracting uplift.

The independent declination case uses depth=10 m and angle=0.75 degree from vertical. With ψ=90°−q, Catenary Curve (2019), equations (9)–(12), page 5 gives a=d sin(q)/(1−sin(q)), X=a ln(cot(q)+csc(q)) and S=a cot(q). The reported bend radius, horizontal distance and suspended length are 0.133 m, 0.667 m and 10.132 m. The regression compares all three against independent literals within 0.0005 m, the half-step of the legacy three-decimal output, and asserts the selected angle. Doubling the calculator's horizontal distance is rejected by this regression.

Method and public sources

  • Engineering basis E1–E4: vertex catenary geometry and annular weight balance.
  • Catenary Curve (2019), equations (1), (4), (9), (10), (14): geometry, force and angle conventions.
  • University Physics Volume 1 (2016), §14.4: buoyant force equals displaced-fluid weight. Solving the concentric-annulus balance gives D²=d²+4U/[πg(ρwater−ρfoam)]; no empirical multiplier is supplied.
  • NIST SP 811 (2008), Appendix B.8: international inch=0.0254 m exactly.

Limits and verification

Numeric fatigue-bin probabilities are preserved as caller weights without normalization. Their interpretation as percentages, annual exposures or a measured spectrum is not established. Negative and nonfinite weights are refused. Zero bins consume no seeds. Nonintegral and locale-formatted seeds are refused. Archived input selection is tested without external workbook access; external script dependencies and report production remain unqualified.

The accompanying pull-request text records offline tests and structure counts. A complete module and adjacent-folder run requires the declared dependencies. Plot-origin tests exercise coordinate arrays with the plotting callback suppressed. Declination-grid tests establish fractional-angle selection and the cited angle/depth example within the output-rounding tolerance; generated mesh validity is not established. No commercial solver was run.
