# Subsea connectors

The [trees and connectors module analysis](../../../../docs/reports/modules/subsea_trees_connectors/index.html)
documents public section, stress, thermal, fatigue, catalogue and offline-export
interfaces and their connection boundary with tree flow data. The worked case
checks synthetic annular geometry and elastic curvature only; physical response
and a standards acceptance basis are not established.

The [report README](../../../../docs/reports/modules/subsea_trees_connectors/README.md)
provides rebuild and independent arithmetic-check commands. Normal package
imports reach the fatigue dependencies even for the static helpers; use the
existing x86 calculation environment.
