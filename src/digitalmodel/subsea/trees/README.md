# Subsea trees

The [trees and connectors module analysis](../../../../docs/reports/modules/subsea_trees_connectors/index.html)
documents the public rating, catalogue, liquid pressure-control and port-flow
interfaces, their units and their connection boundary with connector mechanics.
Only the stated synthetic static case is executed; equipment qualification,
fatigue, dynamic response and network coupling are not established.

The [report README](../../../../docs/reports/modules/subsea_trees_connectors/README.md)
provides rebuild and independent arithmetic-check commands.
