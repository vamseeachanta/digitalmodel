Materials database: scope and gaps

This slice projects the existing reconciled grade records into validated, immutable metadata. grades.py remains the strength authority; no separate grade matrix or dimensional table is introduced. No external numerical inputs or source downloads are included. Scope is limited to issue #1204.

database_schema.py defines designation, specification, nullable edition, nullable product level, MPa strengths, provenance and nullable foreign keys. database.py supplies load_database(), database.lookup(name, psl=...) and dictionary lookup by record.key. Keys comprise specification, edition, designation and product level; unknown edition and inapplicable level use explicit key tokens.

Product-level selection follows grades.smts_mpa: stored PSL1 minima receive separate records. A PSL1 request without a stored PSL1 minimum returns the PSL2 record, retaining the repository helper's value fallback. This does not establish PSL1 product qualification. Non-API product levels are null. Aliases, including the distinct API and hull Grade A names, follow grades.get.

Each record retains its existing citation and the inspected source revision, repository-relative locator, SHA-256 and UTC retrieval date. The pinned source digest is checked at load time; a changed grade module requires inspection and refresh of the provenance constants. API edition metadata is extracted from the existing citation; editions not recorded there remain null. Repository LICENSE states MIT License for software. That licence does not establish original standards reuse rights. The source was inspected on 2026-10-11 UTC at revision f21a12af5349c1656137a7b9daa091ec8f968738; no original standard was fetched.
