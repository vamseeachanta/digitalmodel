## 1. Purpose and scope

Rainflow cycle counting, spectral analysis and time-series processing are exported by the package; fatigue and filter interfaces are separate subpackages. [src/digitalmodel/signal_processing/signal_analysis/__init__.py:L18-L27] [src/digitalmodel/signal_processing/signal_analysis/fatigue/__init__.py:L10-L13] [src/digitalmodel/signal_processing/signal_analysis/filters/__init__.py:L10-L12]

The routing registry assigns beta maturity to the containing signal-processing domain. [docs/registry/module-routing.yaml:L297-L302]

`TimeSeriesAnalyzer` reads exported time histories, validates mappings, processes columns and optionally writes results; its input route is a file reader, rather than a solver launch.
