Evidence and use

The machine-readable companion is provenance.hand_check_provenance(). It returns a fresh JSON-compatible sidecar. Numeric functions retain their existing outputs; callers may store this sidecar beside them. Its empty citations list means that no resolved standards Citation is supplied, rather than that standards applicability has been established.

API RP 16Q and ISO 13624-1 occur as context in hang_off.py and events.py. The parent stackup.py names ABS Guidance Notes on Drilling Riser Analysis (2017) and an API edition for a separate minimum-tension method. That parent reference does not establish a clause mapping for these hand checks. The earlier first-edition assertion in the pinned agent pack is not evidence of the current parent implementation.

Missing evidence comprises the governing edition, clause title, exact equation applicability, source rights and a resolvable digitalmodel.citations.schema.Citation. Those fields remain unverified. Standards-derived methods will require that evidence and fail-closed Citation resolution before a standards-compliance statement can be made. This contribution introduces no standards factor, allowable or licensed table value.

Reproducible beam reference

MIT OpenCourseWare, Mechanics and Materials II (2004), Lecture 2, Applications: Beam Bending, Buckling and Vibration, page 15, supplies v'''' = β⁴v with β⁴ = m′ω²/EI and its sine, cosine, hyperbolic-sine and hyperbolic-cosine solution. Page 16 supplies the pinned/pinned conditions and period relation. The following fixed/fixed extension is derived here; it is not claimed to be a published worked example.

Set b = βL and impose v(0) = v′(0) = 0:
v(x) = A[cosh(βx) − cos(βx)] + B[sinh(βx) − sin(βx)].

Then v(L) = v′(L) = 0 requires:
(cosh b − cos b)² − (sinh b − sin b)(sinh b + sin b)
  = 2(1 − cosh b cos b) = 0.

Exclude b = 0. Bisect cosh b cos b − 1 on (3π/2, 2π).
ω = b² √(EI/m′) / L²; P = 2π/ω.

The test helper performs bisection without calling the finite-element implementation or using a tabulated root. A separate residual assertion checks the boundary determinant. The existing finite-spring comparison retains its synthetic dimensions, stiffnesses, mesh and numerical tolerance; that tolerance is not a design acceptance limit.

The element matrix coefficients can be reproduced algebraically, without attributing them to a standard. With ξ = x/L, take H = [1−3ξ²+2ξ³, L(ξ−2ξ²+ξ³), 3ξ²−2ξ³, L(−ξ²+ξ³)]. For constant element properties, Kb = ∫ EI H″ᵀH″ dx, Kg = ∫ Tmean H′ᵀH′ dx, and M = ∫ m′ HᵀH dx over the element. These polynomial integrals define the implementation identity; the present contribution does not independently qualify every assembled model case.
