## 1. Purpose and scope

The public pipeline is JSON or a schedule-assembly adapter → `StackupDrawingSpec` → SVG text → a reconciliation report. [src/digitalmodel/drilling_riser/stackup_drawing/__init__.py:L1-L16]

`render` produces a self-contained SVG with piecewise vertical elevation scales, condensed repeated-joint zones, exaggerated horizontal diameters, component rows, design-data references and a band for open conflicts and gaps. [src/digitalmodel/drilling_riser/stackup_drawing/render.py:L3-L29]

`reconcile` checks SVG structure and data against the specification; its documented limit is that SVG checks do not compare rendered pixels or guarantee readability of every allowed shape or long text line. [src/digitalmodel/drilling_riser/stackup_drawing/reconcile.py:L35-L69]

The containing routing domain has maturity `development`; the drawing workflow is registered as `offline`. [docs/registry/module-routing.yaml:L98-L104] [docs/registry/workflows.yaml:L423-L432]

The schedule adapter covers the tensioned string, omits subsea equipment outside that string, leaves diameters missing, and requires an explicit ordering assertion before assigning component elevations. [src/digitalmodel/drilling_riser/stackup_drawing/adapters.py:L59-L78]

This pack covers all six Python files in this package; it excludes the parent calculation modules and the separately registered global-model and postprocess packages. [src/digitalmodel/drilling_riser/stackup_drawing/__init__.py:L21-L42] [docs/registry/module-routing.yaml:L105-L114]

## 3. Method and governing standards

| Method | Implementation and basis |
| --- | --- |
| Assembly conversion | Drill-floor elevation = floor above mudline − water depth; mudline elevation = −water depth; ordered stacking starts at string base − water depth and accumulates count × joint length upward. Missing length stops further stacking. [src/digitalmodel/drilling_riser/stackup_drawing/adapters.py:L79-L99] [src/digitalmodel/drilling_riser/stackup_drawing/adapters.py:L149-L183] |
| Elevation transform | Per zone, `y = y_top + (z_hi - z) * px_per_m`; build selects true-scale outer zones and a condensed middle zone for repeated runs. The reconciler separately implements the forward map and validates embedded zones. [src/digitalmodel/drilling_riser/stackup_drawing/render.py:L171-L250] [src/digitalmodel/drilling_riser/stackup_drawing/reconcile.py:L637-L674] [src/digitalmodel/drilling_riser/stackup_drawing/reconcile.py:L1012-L1042] |
| Horizontal geometry | Layout has separate pixels per metre vertically and pixels per inch horizontally; drawn width tries envelope width, buoyancy OD, OD, then frame drag diameter, otherwise a nominal fallback. This is drawing geometry. [src/digitalmodel/drilling_riser/stackup_drawing/render.py:L146-L161] [src/digitalmodel/drilling_riser/stackup_drawing/render.py:L520-L521] [src/digitalmodel/drilling_riser/stackup_drawing/render.py:L540-L563] |
| Units and number grammar | The code uses `1 / 0.3048` for m→ft and `1 / 0.0254` for m→in; printed numbers use ASCII digits, comma thousands groups and a decimal point, with field-specific precision. [src/digitalmodel/drilling_riser/stackup_drawing/render.py:L60-L61] [src/digitalmodel/drilling_riser/stackup_drawing/render.py:L315-L328] [src/digitalmodel/drilling_riser/stackup_drawing/reconcile.py:L191-L194] [src/digitalmodel/drilling_riser/stackup_drawing/reconcile.py:L718-L743] |
| Table placement | `_relax` merges colliding row clusters and centres each on its mean anchor, subject to row pitch and band bounds; design-data width is rounded upward in fixed steps from the widest cell. [src/digitalmodel/drilling_riser/stackup_drawing/render.py:L1514-L1522] [src/digitalmodel/drilling_riser/stackup_drawing/render.py:L1925-L1954] |
| Drawing reconciliation | Six checks cover mapping, positions, printed numbers, totals, missing-value rendering and design-data provenance; XML/zone parsing errors become failed reports. [src/digitalmodel/drilling_riser/stackup_drawing/reconcile.py:L159-L175] [src/digitalmodel/drilling_riser/stackup_drawing/reconcile.py:L1610-L1686] |
| Length and datum closure | Per-component `int(count) × joint_length` is compared with top − bottom; chain adjacency, explicit landing overlaps, summed lengths, source totals and depth + air gap are checked separately. [src/digitalmodel/drilling_riser/stackup_drawing/reconcile.py:L2677-L2860] |
| Provenance and missing evidence | Design-data fields use scalar or per-field register values with unit conversion; missing verifiable values produce open items. An adapter-derived closure residual cannot independently establish closure. [src/digitalmodel/drilling_riser/stackup_drawing/reconcile.py:L1508-L1565] [src/digitalmodel/drilling_riser/stackup_drawing/reconcile.py:L2815-L2848] |
