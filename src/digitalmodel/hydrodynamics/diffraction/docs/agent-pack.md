## 1. Purpose and scope

The main path converts canonical geometry, inertia and environment inputs to diffraction preparation workflows, then represents motion RAOs, added mass, damping and optional hydrostatics for export. `[src/digitalmodel/hydrodynamics/diffraction/input_schemas.py:L127-L215]` `[src/digitalmodel/hydrodynamics/diffraction/output_schemas.py:L372-L391]`

The preparation examples select `convert_spec` for AQWA and OrcaWave; the solve example selects `run_orcawave` and requires a licensed interface. `[examples/workflows/aqwa-diffraction-deck-prep/input.yml:L1-L8]` `[examples/workflows/orcawave-input-prep/input.yml:L1-L8]` `[examples/workflows/orcawave-diffraction-solve/input.yml:L1-L15]`

The parent hydrodynamics routing row declares `production`; this is registry metadata, not demonstrated diffraction qualification. The README production and completeness statements remain README claims, unverified (U4). `[docs/registry/module-routing.yaml:L117-L122]` `[docs/domains/diffraction/README.md:L3-L21]`

The cylinder reference applies to a vertical circular cylinder with positive radius and draft below water depth; it computes heave radiation, rather than all six motion responses. `[src/digitalmodel/hydrodynamics/diffraction/analytical_cylinder.py:L15-L21]` `[src/digitalmodel/hydrodynamics/diffraction/analytical_cylinder.py:L73-L99]` `[src/digitalmodel/hydrodynamics/diffraction/analytical_cylinder.py:L288-L318]`

## 3. Method and governing standards

Tiered acceptance is implemented by `category_for`, `convergence_from_self_study` and `evaluate`; thresholds are engineering policies with rationales in code, not limits attributed to a licensed standard. `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L84-L138]` `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L156-L187]` `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L205-L240]`

| Quantity          | Difference limit (%) | Denominator and coded basis                                               | Evidence                                                                            |
| ----------------- | -------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Hydrostatics      | 0.5                  | reference program term; same-mesh closed-form integral                    | `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L84-L90]`   |
| Excitation        | 5.0                  | mode peak over solved frequency grid; well-conditioned diffraction result | `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L82-L96]`   |
| Added mass        | 5.0                  | mode peak; well-conditioned radiation result                              | `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L82-L96]`   |
| Radiation damping | 10.0                 | mode peak; mesh and formulation sensitivity                               | `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L97-L101]`  |
| Motion RAO        | 5.0                  | mode peak; excitation, added mass and stiffness basis                     | `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L102-L106]` |
| Resonant roll RAO | 10.0                 | mode peak; damping-sensitive potential-flow response, not a design value  | `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L107-L112]` |

The category router assigns every roll motion-RAO request to the resonant-roll tier; it does not locate resonance. Each own-mesh residual must be ≤ 0.25 × its tier for comparable convergence. Inside-band differences without that evidence return PASS_CONDITIONAL; outside-band differences return FAIL. `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L125-L138]` `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L149-L187]` `[src/digitalmodel/hydrodynamics/diffraction/cross_solver_acceptance.py:L216-L240]`

Abscissa alignment requires increasing source axes, coverage and gap screening; signed matrix interpolation preserves signs and propagates non-finite coefficient columns. The nested numeric policy validates its domains before checking the justification. `[src/digitalmodel/hydrodynamics/diffraction/benchmark_abscissa.py:L62-L102]` `[src/digitalmodel/hydrodynamics/diffraction/benchmark_abscissa.py:L157-L180]` `[src/digitalmodel/hydrodynamics/diffraction/benchmark_matrix_alignment.py:L45-L80]`

The cylinder implementation records Yeung, “Added mass and damping of a vertical cylinder in finite-depth waters”, Applied Ocean Research 3(3), 1981, as its matched-eigenfunction source. Its potential convention is Re(φ exp(−iωt)), with unit heave velocity. The paper itself was not opened; independent source confirmation is U4. `[src/digitalmodel/hydrodynamics/diffraction/analytical_cylinder.py:L15-L21]` `[src/digitalmodel/hydrodynamics/diffraction/analytical_cylinder.py:L49-L51]`

The equilibrium screens use caller-supplied tolerances, mass versus ρ∇, horizontal CoG–CoB separation, and signed component force balance; they do not establish GM or perform implicit unit conversion. `[src/digitalmodel/hydrodynamics/diffraction/equilibrium_checks.py:L1-L7]` `[src/digitalmodel/hydrodynamics/diffraction/equilibrium_checks.py:L31-L91]`

AQG r0 §8 supplies the required diffraction gate criteria in section 5. Its panel-size guidance names DNV-RP-C205 with edition and clause still to be confirmed; no DNV tabulated value is reproduced here.
