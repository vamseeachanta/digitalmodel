Squat and under-keel clearance screening

This guide describes unrestricted-channel squat estimates, under-keel clearance budgets and evaluation of supplied speed grids.

Method and provenance

Bow and stern squat are evaluated using the Römisch (1989) method as reproduced in PIANC On Course 142 (2011), Appendix A4, printed page 22, equations (7)-(10). The original 1989 publication has not been directly verified.

r = speed relative to water / critical speed
Cv = 8 r^2 [(r - 0.5)^4 + 0.0625]       (8)
Cf,bow = (10 B Cb / Lpp)^2; Cf,stern = 1 (9)
K = 0.155 sqrt(h/T)                     (10)
Sb = Cv Cf,bow K T; Ss = Cv K T         (7)

Critical speed in m/s and lower and upper h/T applicability bounds are required cited inputs. Bounds are inclusive. The routine rejects h ≤ T, V ≥ Vcr, negative speed, nonfinite values, invalid dimensions and out-of-envelope cases. The supplied interval does not establish hull/channel qualification.

The existing depth classifier and citation getter retain the prior boundary convention. The deep-water turning guard is not applied to this shallow-water formula. Depth classification does not establish navigability.

Clearance and speed grid

Under-keel clearance is calculated using the geometric accounting identity, introducing no empirical factor:

static clearance = h - T
residual clearance = h - T - max(Sb, Ss) - allowance
margin = residual clearance - supplied minimum clearance

Depth includes the applicable water level; draft is static even-keel draft. Allowance is an explicit nonnegative aggregate deduction for effects not already accounted for. Zero must be explicit. The optional minimum is a CitedValue in metres. Equality meets that supplied minimum; no minimum gives NOT_EVALUATED. Negative residuals are retained. budget_exhausted includes allowances and is not a claim of bottom contact.

A supplied speed grid is evaluated in order. Any invalid row fails the call. No row is silently dropped; no limiting speed is interpolated or approved.

API and citation records

from digitalmodel.hydrodynamics.parametric_hull_analysis.squat import (
    clearance_budget, romisch_squat, squat_speed_sweep,
)

# Supply reviewed CitedValues and an explicit citation_root before this call.
inputs = dict(
    length_bp_m=100.0, beam_m=12.5, block_coefficient=0.8,
    draft_m=10.0, water_depth_m=14.4,
    critical_speed=critical_speed,
    minimum_depth_ratio=minimum_depth_ratio,
    maximum_depth_ratio=maximum_depth_ratio,
    citation_root=citation_root,
)
result = romisch_squat(speed_ms=4.0, **inputs)
budget = clearance_budget(result, allowance_m=0.5,
                          minimum_clearance=minimum_clearance,
                          citation_root=citation_root)
grid = squat_speed_sweep([0.0, 2.0, 4.0], **inputs)

The result retains geometry, input provenance, coefficient CitedValue sidecars and the depth citation. Clearance evaluation rechecks inputs, result values and current citation metadata. Altered results are rejected.

The citation root must contain wikis/marine-engineering/wiki/standards/romisch-squat.md, with YAML frontmatter code_id: PIANC-ROMISCH-SQUAT, publisher: PIANC, revision: 2011, and the existing wikis/marine-engineering/wiki/standards/pianc-depth-bands.md (code_id PIANC-DEPTH-BANDS, publisher ITTC, revision 2002). Input criteria require their own matching records. Missing or mismatched records fail closed. Live provisioning is left to the maintainer; test fixtures only exercise resolution, and do not establish a live engineering basis.

Navigation status always remains NOT_EVALUATED. Metadata matching does not validate an input's technical basis or source section. Wave response, initial trim, heel, bathymetric uncertainty, channel qualification and allowance completeness are not evaluated. The hand calculation verifies arithmetic, not measured squat. Operational acceptance requires a reviewed hull/channel basis and all relevant clearance contributions.
