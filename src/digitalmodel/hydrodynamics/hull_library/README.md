# Hull library

The [module report index](../../../../docs/reports/modules/hull_library/README.md)
links the interface evidence map and synthetic panel scaling analysis.
The [knowledge pack](docs/agent-pack.md) describes the wider module and its
evidence boundaries. The [standalone panel scaling example](docs/worked-panel-scaling.md)
preserves its executable example and hand derivation.

The report checks only its bounded in-memory numerical comparison. Physical
hull suitability, hydrodynamic responses, response-table provenance, mesh
convergence and solver qualification remain NOT_EVALUATED.
