## 1. Purpose and scope

The main path converts station offsets to wetted panel meshes, declares symmetry, and propagates outward winding; the separate line-generation path interpolates a surface before panelisation. [src/digitalmodel/hydrodynamics/hull_library/mesh_generator.py:L90-L170] [src/digitalmodel/hydrodynamics/hull_library/line_generator/panelizer.py:L165-L175]

The catalog also computes spectral motion responses and point accelerations from supplied RAOs; these are calculations using existing response data, with nearest-heading selection and zero interpolation outside the supplied frequency interval. [src/digitalmodel/hydrodynamics/hull_library/catalog.py:L260-L315] [src/digitalmodel/hydrodynamics/hull_library/catalog.py:L321-L378] [src/digitalmodel/hydrodynamics/hull_library/catalog.py:L440-L457]

The routing registry describes the encompassing hydrodynamics domain as production; this does not establish qualification of every geometry or optional backend. [docs/registry/module-routing.yaml:L129-L134]

The cutout path supports flat-keel, uncapped wetted geometry and expands only full or `y`-symmetric meshes; column/pontoon geometry has explicit layout and non-overlap restrictions. [src/digitalmodel/hydrodynamics/hull_library/mesh_cutouts.py:L110-L168] [src/digitalmodel/hydrodynamics/hull_library/column_pontoon_form.py:L62-L110]

## 3. Method and governing standards

| Method | Implementation and limits |
| --- | --- |
| Station lofting | `_shape_preserving_interp` sorts/deduplicates samples, uses linear interpolation for two points and PCHIP otherwise, with constant extrapolation; grid resolution uses an approximate count and aspect-based quadratic. [src/digitalmodel/hydrodynamics/hull_library/mesh_generator.py:L33-L66] [src/digitalmodel/hydrodynamics/hull_library/mesh_generator.py:L204-L231] |
| Surface alternative | `HullSurfaceInterpolator` uses PCHIP through sections and B-splines or linear interpolation longitudinally; its paneliser subdivides the flat bottom and computes minimum angles separately from the main refiner. [src/digitalmodel/hydrodynamics/hull_library/line_generator/hull_surface.py:L104-L124] [src/digitalmodel/hydrodynamics/hull_library/line_generator/panelizer.py:L55-L73] [src/digitalmodel/hydrodynamics/hull_library/line_generator/panelizer.py:L100-L157] |
| Parametric forms | Analytic section areas and three-part sectional-area curves feed a Brent solve using analytic first moments; generated sampling is a separate approximation. [src/digitalmodel/hydrodynamics/hull_library/parametric_form.py:L121-L170] [src/digitalmodel/hydrodynamics/hull_library/parametric_form_ends.py:L10-L80] |
| Column/pontoon union | Convex clipping subtracts overlapping solids, welds patch boundaries and converts triangles to convex midpoint quads; primitive reports compare mesh integrals with analytic dimensions. [src/digitalmodel/hydrodynamics/hull_library/column_pontoon_mesh.py:L14-L67] [src/digitalmodel/hydrodynamics/hull_library/column_pontoon_mesh.py:L102-L145] [src/digitalmodel/hydrodynamics/hull_library/column_pontoon_quality.py:L27-L61] [src/digitalmodel/hydrodynamics/hull_library/column_pontoon_form.py:L203-L219] |
| Local quality helpers | `refine` bisects triangle edges and invokes coplanar diagonal flips; `_profile` preserves circular section area; these are used implementation details, not separate hydrostatic references. [src/digitalmodel/hydrodynamics/hull_library/column_pontoon_patches.py:L41-L70] [src/digitalmodel/hydrodynamics/hull_library/column_pontoon_flip.py:L25-L80] [src/digitalmodel/hydrodynamics/hull_library/column_pontoon_primitives.py:L14-L36] |
| Refinement | Four midpoint children per quad, shared-edge cache, coordinate deduplication and removal of children with fewer than three unique vertices; only the two named panel-aligned metadata lists receive explicit mappings. [src/digitalmodel/hydrodynamics/hull_library/mesh_refiner.py:L58-L98] [src/digitalmodel/hydrodynamics/hull_library/mesh_refiner.py:L118-L184] |
| Decimation | `coarsen_mesh(auto)` selects QEM at up to 50,000 source panels, vertex clustering above that; `max_aspect_ratio` is accepted but does not implement quality-gated stopping. [src/digitalmodel/hydrodynamics/hull_library/coarsen_mesh.py:L88-L147] |
| QEM | `decimate_mesh` triangulates, accumulates vertex quadrics, contracts edges with a topology link test, then merges triangles; the code cites Garland and Heckbert, *Surface Simplification Using Quadric Error Metrics*, 1997. [src/digitalmodel/hydrodynamics/hull_library/decimation.py:L1-L19] [src/digitalmodel/hydrodynamics/hull_library/decimation.py:L141-L178] [src/digitalmodel/hydrodynamics/hull_library/decimation.py:L227-L251] |
| QEM helpers | `quads_to_tris` uses a fixed diagonal and `compute_plane_quadric` derives the plane matrix from its triangle; these feed decimation, not the curvature adapter or an independent reference. [src/digitalmodel/hydrodynamics/hull_library/_decimation_helpers.py:L22-L69] |
| Optional decimation | VTK triangulates and decimates; Gmsh remeshes via temporary STL; backend availability is explicit, and neither is an independent analytic comparator. [src/digitalmodel/hydrodynamics/hull_library/decimation_vtk.py:L118-L165] [src/digitalmodel/hydrodynamics/hull_library/decimation_gmsh.py:L162-L198] |
| Cutout geometry | Shapely triangulation must recover constrained area/boundary and meet its generated-triangle aspect limit; source geometry checks and generated-fragment checks require separate interpretations. [src/digitalmodel/hydrodynamics/hull_library/_cutout_geometry.py:L92-L140] [src/digitalmodel/hydrodynamics/hull_library/mesh_cutouts.py:L142-L168] |
| Scaling and lookup | Scaling recomputes derived geometry; dimension ratios set independent axis factors; lookup ranks normalized Euclidean dimension distances using an exponential similarity score, with built-in fallback candidates. [src/digitalmodel/hydrodynamics/hull_library/mesh_scaler.py:L52-L82] [src/digitalmodel/hydrodynamics/hull_library/mesh_scaler.py:L133-L157] [src/digitalmodel/hydrodynamics/hull_library/lookup.py:L116-L153] [src/digitalmodel/hydrodynamics/hull_library/lookup.py:L171-L181] |
| Curvature screening | Optional HullProd assessment records reference length, reliability, triangulation policy and version; creased column/pontoon forms are annotated as paneling metrics. Its named reference is Serani and Maki, *Geometry-Based Metrics for Early-Stage Hull-Form Producibility Screening*, 2026, arXiv:2609.27544. [src/digitalmodel/hydrodynamics/hull_library/curvature_screen.py:L12-L24] [src/digitalmodel/hydrodynamics/hull_library/curvature_screen.py:L320-L397] |

    points = mesh.vertices[panel]
    for i in range(1, len(points) - 1):
        a, b, c = points[[0, i, i+1]]
        vector_area = np.cross(b-a, c-a) / 2
        axis += (a+b+c) / 3 * vector_area
        signed += np.dot(a, np.cross(b, c)) / 6
    for a, b in zip(panel, np.roll(panel, -1)):
