Corrected interfaces

External-force execution requires explicit opt-in and the optional server dependency. Launch-only mode returns the process handle before callbacks are served. A callback failure terminates and waits for that process. Saved external-force CSVs carry aq_04_decision=NOT_RUN; exit code zero alone does not qualify completion.

Each FDRn block retains its own frequency and direction grid. FILE, CSTR and CPDB references do not become inline grids. All 50 committed deck-6 examples parse; the validators accept zero examples for LDRG and 49 for the default CoG. A validator may reject a malformed CoG during shared inspection before its own criterion is checked.

AQ-01 through AQ-03 retain per-gate evidence and input digests. AQ-01 distinguishes configured and defaulted CoG nodes. Native completion evidence includes DAT and fresh LIS digests and the observed body count; the heading scan tolerates non-UTF-8 listing bytes while the digest covers the original bytes.

AQ-05 through AQ-11 use identity, timezone-aware date and digest-bound signature records. YAML datetime values are normalized to ISO text for retained JSON records. These are manual attestations, not identity authentication; reviewer authority requires independent confirmation.

Limits and way forward

The model uses motion-only harmonic linearisation, declared peak wave amplitude and rotational RAO units. Resonance must be unique and inside the supplied grid. No stochastic sea-state result or extrapolated resonance is inferred.

Multibody displacement reads require an explicit structure selector; omitted selectors now raise. The damping workflow remains single-body because its matrix and hydrostatic readers do not select a body. Configured searches preserve continuation rows and reject empty extractions.

Native qualification and manual hydrostatic/mesh checks remain required before engineering use. Missing external evidence remains NOT_RUN. Maintainer review and a second-provider review of the revised change remain pending.
