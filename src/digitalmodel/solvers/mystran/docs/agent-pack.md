## 1. Purpose and scope

The package exports a BDF writer, F06 parser, optional OP2 reader, structured cantilever mesh/solve chain, convergence study and Richardson extrapolation. [src/digitalmodel/solvers/mystran/__init__.py:L3-L20] [src/digitalmodel/solvers/mystran/result_parser.py:L166-L180]

`BDFWriter` emits free-field cards and defaults to SOL 101; the chain constructs that default writer, so modal or buckling capability mentioned in the domain documentation is not demonstrated by the chain's setup route. [src/digitalmodel/solvers/mystran/bdf_writer.py:L41-L51] [src/digitalmodel/solvers/mystran/fem_chain.py:L193-L203] [docs/domains/fem/nastran/nastran.md:L37-L40]

Supported element-name mappings are Line 2, Triangle 3, Quadrilateral 4, Tetrahedron 4/10 and Hexahedron 8/20; unsupported names raise an error. [src/digitalmodel/solvers/mystran/bdf_writer.py:L26-L39] [src/digitalmodel/solvers/mystran/bdf_writer.py:L277-L283]

The enclosing solvers domain is beta; no separate MYSTRAN maturity is assigned in the pinned domain entry. [docs/registry/module-routing.yaml:L348-L378]

Scope includes every Python file in this package, with no nested implementation package; solver execution and vendor imports are excluded from this pack's offline evidence, while the existing tests guard four integration cases on executable availability. [src/digitalmodel/solvers/mystran/__init__.py:L7-L20] [tests/solvers/mystran/test_fem_chain.py:L15-L17] [tests/solvers/mystran/test_fem_chain.py:L174-L216]
