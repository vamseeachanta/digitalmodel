## 1. Purpose and scope

`WellboreHydraulics` calculates steady Bingham-plastic annular velocity, frictional pressure loss, equivalent circulating density (ECD) and a capped cuttings-transport indicator for one pipe-in-hole section. [src/digitalmodel/well/drilling/hydraulics.py:L8-L24]
`SwabSurge` adds steady tripping pressures and speed inversion; it excludes transient acoustic propagation. [src/digitalmodel/well/drilling/swab_surge.py:L14-L37]
The package also provides ROP prediction and fitting, time-series dysfunction flags, bore-design lookups, pore-pressure ensembles and dual-gradient window/casing screening. [src/digitalmodel/well/drilling/rop_models.py:L8-L14] [src/digitalmodel/well/drilling/dysfunction_detector.py:L8-L25] [src/digitalmodel/well/drilling/well_bore_design.py:L8-L17] [src/digitalmodel/well/drilling/pore_pressure.py:L17-L59] [src/digitalmodel/well/drilling/dual_gradient.py:L20-L63]
The registry classifies the parent `well` domain as stable; this classification does not establish engineering validation of every calculation. [docs/registry/module-routing.yaml:L376-L382]
Scope includes all eight Python files in the package; tubulars, wellpath and the parent workflow adapter are interface context only. [src/digitalmodel/well/drilling/__init__.py:L1-L29] [src/digitalmodel/well/workflow.py:L13-L20]

## 3. Method and governing standards

| Method | Implemented relation / limit | Reference status and implementing definition |
|---|---|---|
| Annular velocity | Flow divided by annular area, using the documented field-unit conversion | Code names the SPE textbook, chapter 4; `WellboreHydraulics.annular_velocity` [src/digitalmodel/well/drilling/hydraulics.py:L82-L101] |
| Friction and ECD | Laminar slot approximation multiplied by TVD; ECD adds pressure divided by hydrostatic depth conversion | API RP 13D is named without edition or clause; `pressure_drop_annulus`, `ecd` [src/digitalmodel/well/drilling/hydraulics.py:L1-L2] [src/digitalmodel/well/drilling/hydraulics.py:L103-L156] |
| Cuttings transport | Velocity divided by a fixed cleaning threshold, capped at unity | Code labels the threshold industry consensus; no qualified inclination, solids or particle-size model is provided by this expression [src/digitalmodel/well/drilling/hydraulics.py:L158-L170] |
| Tripping | Effective velocity combines displacement and clinging; separate friction expression; linear inversion with yield offset | Code names Burkhardt (1961), JPT, and API RP 13D without edition/clause; `displacement_factor`, `pressure`, `_speed_for_pressure` [src/digitalmodel/well/drilling/swab_surge.py:L1-L2] [src/digitalmodel/well/drilling/swab_surge.py:L150-L212] |
| Exponential ROP | Eight factors for formation, depth, overbalance, WOB, speed, wear and jet enhancement | Code names Bourgoyne–Young (1986), SPE textbook chapter 5; actual intercept uses `exp(2.303*a1)` although the class docstring says `exp(a1)`; issue pending (1) [src/digitalmodel/well/drilling/rop_models.py:L1-L14] [src/digitalmodel/well/drilling/rop_models.py:L29-L34] [src/digitalmodel/well/drilling/rop_models.py:L105-L134] |
| Power-law ROP | Empirical power law; fitting by log-linear normal equations and Gaussian elimination | Code names Warren (1987), SPE-13919; `WarrenROP.predict`, `fit_from_data`; this is the coded model, not a verified reproduction of the publication [src/digitalmodel/well/drilling/rop_models.py:L175-L189] [src/digitalmodel/well/drilling/rop_models.py:L225-L297] |
