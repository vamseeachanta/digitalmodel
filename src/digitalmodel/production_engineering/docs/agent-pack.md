## 3. Methods, equations and public basis

Sources read on 2026-10-22: [open university thesis, *Inflow Performance Relationships (IPR) for Solution Gas Drive Reservoirs — a Semi-Analytical Approach* (2010), §§1.2.1–1.2.2, printed pp. 3, 5–6](https://blasingame.engr.tamu.edu/0_TAB_Grad/TAB_Grad_Thesis_Archive/MS_044_NASS%2CMaria_Thesis_TAMU_%28May_2010%29.pdf). This is secondary evidence of the equations, not an original-paper worked example. Repository companion: `docs/domains/production/production-engineering-literature.md`, “Open IPR equation passage ledger” and “Composite join derivation”.

| Method | Equation / constants / implementation | Basis and status |
|---|---|---|
| Linear PI | q=J(Pr-Pwf); inverse Pwf=Pr-q/J | Thesis (2010), Eqs. (1.7), (1.9); arithmetic anchored below. Original-example qualification UNVERIFIED. |
| Vogel (1968) | q=qmax(1-0.2r-0.8r²), r=Pwf/Pr; quadratic inverse | Thesis (2010), Eq. (1.12); both coefficients read from public text. Factory qmax=JPr/1.8 follows slope at r=1, since 0.2+2×0.8=1.8. Original-example qualification UNVERIFIED. |
| Fetkovich (1973) | q=C(Pr²-Pwf²)^n, C=qmax/Pr^(2n); inverse sqrt(Pr²-(q/C)^(1/n)) | Thesis (2010), Eq. (1.16), normalized form. C,n are caller calibration inputs, not constants inferred here. Original-example qualification UNVERIFIED. |
| Composite | qb=J(Pr-Pb); q=qb+A f(Pwf/Pb), A=JPb/1.8 below Pb; linear above | Independent continuous-slope join of the preceding public equations: f(1)=0, f′(1)=-1.8; -1.8A/Pb=-J. Historical attribution and field accuracy UNVERIFIED. |

## 7. Ownership and review

Maintainers of the production-engineering package own the API and the evidence gaps. Engineering review must supply parameter provenance, applicable regime and a pressure/rate basis before relying on a result. Pack changes must update inventories, locator checks and arithmetic evidence together; the code pin remains historical unless deliberately revised. No individual assignment or approval is asserted.

## 8. Dependencies and execution boundaries

Runtime: standard library, SciPy Brent root finding, and production modules imported by the package. JSON routers create output directories/files. Tests require pytest; structural registry tests also require PyYAML. No licensed solver or external dataset is needed. The method selector's literature references are conditional screening evidence, not installed numerical models.

## 9. Coverage and evidence limits

Existing domain tests cover IPR forward/inverse behavior, VLP alias warnings and method-name errors, nodal intersections, test-quality policies, diagnostics, reconciliation and marginal economics. New tests add four IPR literal cases and a three-method VLP branch case, plus public inventory, locator mutation, citation collection, registry and ten-section checks. ESP is exercised only as a branch of `tests/workflows/test_durable_workflows.py::test_workflow_registry`; no dedicated ESP unit test file was found in the pinned tree. That engine-wide test is not claimed as newly run by this pack. No new ESP numeric qualification is claimed. All function outputs without an original published example remain UNVERIFIED; all unsourced physical constants/settings above remain NOT_EVALUATED. Existing self-consistency tests do not change that status.
