## 1. Purpose and scope

The structural package supplies curve objects, histogram damage, diagnostic rainflow, spectral damage, scatter integration, reliability calculations and HTML reporting; these exports coexist with the separate `fatigue` package. [src/digitalmodel/structural/fatigue/__init__.py:L133-L204] [src/digitalmodel/fatigue/__init__.py:L18-L88]

Canonical here means the implementation actually supplying the named public entry point; it does not assert one repository-wide numerical implementation. [src/digitalmodel/fatigue/__init__.py:L73-L88] [src/digitalmodel/structural/fatigue/sn_curves.py:L1079-L1102]

The README assigns 221 curves, 17 standards and 808 tests to structural fatigue; the catalog assertions verify 221 records and 17 standards in the separate package, while the structural factories expose different groups. Recount at the pin: the catalog has 221 unique IDs across 17 standard names; structural factory groups contain DNV 14, API 5, BS 8, AWS 8, multislope 2, revised BS 1, ISO 3 and tubular 2, with no default custom entries; the executable recount used `get_catalog()` and `StandardSNCurves.list_curves()`. [src/digitalmodel/fatigue/sn_library.py:L977-L1011] [src/digitalmodel/structural/fatigue/sn_curves.py:L715-L737]

Offline collection recorded 801 structural cases (797 passed, four expected failures) and 744 separate-fatigue cases (739 passed, five expected failures), rather than 808 structural cases; section 10 records the documentation gap. ## 3. Method and governing standards

`PowerLawSNCurve` computes the configured power law and optional second segment; `LinearDamageAccumulation` sums applied cycles divided by allowable cycles, and the example wrapper applies SCF to ranges before evaluating damage. [src/digitalmodel/structural/fatigue/sn_curves.py:L152-L184] [src/digitalmodel/structural/fatigue/damage_accumulation.py:L160-L179] [src/digitalmodel/structural/fatigue/worked_examples.py:L405-L415]

The C203 source distinguishes a stored value basis of 2011 from an implemented label of 2021; the manifest also names 2021, whereas the structural environment factory explicitly names 2011, so these editions are retained separately. [src/digitalmodel/fatigue/c203_editions.py:L19-L37] [src/digitalmodel/structural/fatigue/manifest.yaml:L1-L13] [src/digitalmodel/structural/fatigue/sn_curves.py:L572-L579]

Standard reference: DNV-RP-C203, *Fatigue Design of Offshore Steel Structures*, 2011, section 2.4; environment table locators are recorded in the code, and clause text not checked against the licensed copy. [src/digitalmodel/fatigue/c203_sn_tables.py:L3-L24]

### Spectral and probabilistic methods

The structural Dirlik implementation numerically integrates its configured range PDF against `get_allowable_cycles`, with clamped coefficients and a finite normalised grid; Tovo-Benasciutti combines a narrow-band rate and a Wirsching-Light correction with a clamped weight. [src/digitalmodel/structural/fatigue/frequency_domain.py:L254-L337] [src/digitalmodel/structural/fatigue/frequency_domain.py:L409-L438]

Dirlik, *Application of computers in fatigue analysis*, PhD thesis, University of Warwick, 1985; the institutional record was opened, but agreement of the structural coefficients with the thesis has not been demonstrated.
