## 1. Purpose and scope

The package contains module-level plate stress, buckling resistance and utilization calculations, with a separate stiffener/girder section-property and Euler-stress route. [src/digitalmodel/structural/plate_capacity/plateBucklingCal_G.py:L26-L67] [src/digitalmodel/structural/plate_capacity/plateBucklingCal_G.py:L269-L274] [src/digitalmodel/structural/plate_capacity/StiffnerBuckling_Cal/StiffnerBuckling_Cal.py:L30-L108] [src/digitalmodel/structural/plate_capacity/StiffnerBuckling_Cal/StiffnerBuckling_Cal.py:L220-L243]

Scope includes `DataProvision`, `PlateBuckling_Plots`, `StiffnerBuckling_Cal`, `calculations` and `z_superseded`; no nested pack is excluded. The structural domain is marked stable; this is domain metadata, not evidence that these scripts are validated. [docs/registry/module-routing.yaml:L423-L428] [src/digitalmodel/structural/plate_capacity/__init__.py:L1-L1]

The main plate route handles simply supported and side-clamped uniform loading, longitudinal and transverse stresses, shear and combined utilization; the stiffener main script ends at a resistance heading with no implemented final check below it. [src/digitalmodel/structural/plate_capacity/plateBucklingCal_G.py:L36-L119] [src/digitalmodel/structural/plate_capacity/plateBucklingCal_G.py:L261-L274] [src/digitalmodel/structural/plate_capacity/StiffnerBuckling_Cal/StiffnerBuckling_Cal.py:L220-L243]

`PlateBuckling_212.py` and the individual plate scripts execute statements at module scope and use absolute `DataProvision` imports; this pack does not establish them as a supported import API. [src/digitalmodel/structural/plate_capacity/PlateBuckling_212.py:L10-L43] [src/digitalmodel/structural/plate_capacity/plateBucklingCal_G.py:L10-L27]
