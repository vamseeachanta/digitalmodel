# Pipe cross-section

The [module analysis](../../../../docs/reports/modules/pipe_cross_section/index.html)
documents public interfaces, explicit synthetic inputs, annular geometry,
mass per length and sealed dry-bore displacement. Its
[rebuild instructions](../../../../docs/reports/modules/pipe_cross_section/README.md)
link deterministic evidence and independent arithmetic tests.

The [worked example](docs/worked-layered-pipe-buoyancy.md) provides the input
basis and exact polar integrals. Physical material defaults, flooding behavior
and installation acceptance remain NOT_EVALUATED.
