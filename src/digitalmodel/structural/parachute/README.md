# Parachute methods

The [module analysis](../../../../docs/reports/modules/parachute/index.html)
inventories the existing drag, geometry, linear frame solver and member-check
interfaces. It includes synthetic drag and elastic cantilever calculations,
independent arithmetic checks, source bindings and explicit qualification limits.

The [synthetic canopy drag example](docs/worked-synthetic-canopy-drag.md) gives
the assumed drag inputs and exact unit definitions. Neither example establishes
physical or operational qualification.
