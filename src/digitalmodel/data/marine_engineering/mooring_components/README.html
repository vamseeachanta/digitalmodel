Public mooring component seed: schema and gaps

Scope: issue 1200, component properties only. The authoritative computational owner is digitalmodel. Source catalogue identity: nrel-iea-reference-turbines. Readiness is partial: these computed examples are for offline loader and coefficient verification. Manufacturer qualification, certified breaking strength, valid size ranges and engineering selection readiness are not established.

The production loader resolves its default directory to src/digitalmodel/data/marine_engineering/mooring_components/ and expects chain_properties.csv, wire_properties.csv and line_properties.csv. Chain and wire columns and units are inherited from the production dataclasses. The prior production line table has no declared column schema or query method; the line schema below is additive. Both pre-existing test copies contain independent fixture implementations, so the additional tests exercise the production module directly.

Source and derivation

The retained source excerpt is sources/moorpy_coefficients.json. It records the exact wire, polyester and nylon property coefficient lines from MoorPy's old default coefficient file, commit 1fb29f8eca2618543b2df7056adfdfce0265737b, retrieved 2026-10-11 UTC. The upstream file digest, line locators, sampling-size fixture references, conversion basis and formula-source digest are retained. No drag, added-mass or paid-standard-derived chain coefficients are retained.

The licence is BSD 3-Clause License. The stated grant begins: “Redistribution and use in source and binary forms, with or without modification, are permitted provided that the following conditions are met:”. The complete copyright notice, conditions and disclaimer accompany the excerpts. The licence was read from the pinned repository licence in this run.

Diameter is converted from mm to m. Air mass is mass_d2 × d²; breaking load is the source quadratic plus its supplied cubic term. EA is the source quadratic plus its supplied multiple of breaking load. Forces are converted from N to kN. Submerged mass is derived from the source getLineProps/loadLineProps implementation: density-based buoyancy for fibres and volume-equivalent-diameter buoyancy for wire. The nylon cubic coefficient's local unit comment is inconsistent with the polynomial; the general cubic-coefficient definition and helper implementation govern the derivation. Every generated row is labelled computed with its coefficients and formula. No catalogue rows are present. Sampling diameters are recorded with the repository fixture commit, file digest and MIT License terms; the root repository licence accompanies the work. The provenance getter exposes this sampling citation alongside the property coefficient citation.

provenance.json exposes schema, units, source blocks, row identities, derivations, source-excerpt digest and CSV digests. ComponentDatabase.get_provenance(component_type, diameter, **specification) returns a copy of a unique row's evidence; absent or ambiguous evidence raises a clear error. Sidecar-present libraries fail closed on malformed properties or incomplete provenance. Custom libraries without a sidecar preserve legacy loading and return an explicit unverified provenance error. A missing sidecar therefore does not establish engineering input readiness.

Regeneration is offline: PYTHONPATH=src python scripts/data/generate_mooring_components.py. The committed CSVs and manifest are exactly its output. Original research downloads remain in the job scratch area on the data disk of the Linux workstation; the manifest records the relative location, size and digest of the large revision-discovery response. Local retention does not establish backup.
