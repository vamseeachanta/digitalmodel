## 1. Purpose and scope

The engine entry `run_cathodic_protection(cfg)` dispatches galvanic-anode calculations and returns the same configuration with route-specific results; deprecated legacy paths carry use status without the new routes' full verdict contract. [src/digitalmodel/cathodic_protection/engine_adapter.py:L1245-L1301]

The routing registry records `maturity: beta` and client use subject to an engineer-of-record check for B401 offshore and F103 only; the newer domain use-status table and executable mapping also include rebuilt ABS ships, so approval metadata is inconsistent (issue pending (1)). [docs/registry/module-routing.yaml:L53-L62] [docs/domains/cathodic_protection/_index.md:L30-L58] [src/digitalmodel/cathodic_protection/engine_adapter.py:L168-L186]
