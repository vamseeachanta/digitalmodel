# Repository implementation map

The map lists implementations of method families for module knowledge packs. Its revision records the checkout used for regeneration. Existing paths and exact qualified Python symbols are required in the current checkout; line coordinates, file digests and identical-body digests describe the snapshot and are reported as staleness diagnostics when they drift.
