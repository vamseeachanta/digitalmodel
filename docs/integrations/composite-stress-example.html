Composite material stress example

The concrete-filled circular hollow section example exports stresses calculated by sectionproperties under synthetic axial strain and bending. Separate steel and concrete stresses are retained at the shared interface. This example extends the composite stiffness demonstration; it establishes no operating load or design capacity.

Basis and loads

All inputs are arbitrary synthetic demonstration values. Outside diameter is 80.0 mm and wall thickness is 8.000 mm. Elastic moduli are 210,000 MPa for steel and 35,000 MPa for concrete. Perfect bond, plane sections and uncracked linear elasticity are assumed. Poisson ratios, strengths and densities supplied to the material objects are synthetic placeholders; this axial and bending calculation depends on the geometry and elastic moduli.

For this concentric section, the elastic centroid is at the origin. The imposed centroidal strain is ε0 = 10−4, and curvature is κ = 10−6 mm−1. Positive curvature raises the normal stress at positive y. The independent oracle is σi(y) = Ei(ε0 + κy).

section, stiffness = run_cft_case(...)
post = section.calculate_stress(
    n=epsilon0 * stiffness["EA_N"],
    mxx=kappa * stiffness["EIxx_Nmm2"],
)
material_arrays = post.get_stress()
post.plot_stress(stress="zz", render=False, colorbar_label="Normal stress (MPa)")

Raw EA in N and EI in N mm2 define N and Mxx in N and N mm. Steel-transformed I = EI/Es in mm4 is recorded separately; it is not used as flexural rigidity. All shear and torsion actions are zero, so geometric analysis suffices. Warping and plastic analysis are not run.

The stress jump follows the modulus ratio while interface strain remains continuous. Library nodal stresses are checked at both material sides using 32-sided polygons with maximum triangle area 16.0 mm2 and 64-sided polygons with area 4.0 mm2. The coordinate allowance is 10−8 mm. Relative stress tolerance is (2π/n)2/3 + 10√(machine epsilon), with a separate absolute allowance of 10−6 MPa. This is a demonstration tolerance tied to the polygon stiffness bound, not a design criterion. Negative curvature and zero actions are also tested.

Execution and retained outputs

python -m scripts.integrations.composite_stress_example --output-dir RESULTS

The output directory is supplied explicitly. The default mesh has 64 polygon sides and maximum triangle area 4.0 mm2. Importing the module performs no meshing, stress calculation, directory creation or output writes.

CSV membership is derived from each material group's element connectivity, rather than nonzero stresses. Both material rows at a shared node and true zero stresses are retained. Tests compare all exported values with the library's returned arrays and read back all four files to verify the receipt and payload digests.

Bond transfer, slip, cracking, nonlinear response, local connection behavior and member capacity are outside this example. The nodal field is the library result; the hand equations are used only as an independent test oracle. The dependencies declared by the repository are required; the tests exercise version 3.10.2. Compatibility with every permitted dependency version is not established.
