API RP 2A tubular check development

The interface calculates elastic tubular normal stresses and compares them with supplied, citation-validated allowables. Eight requested check records are returned. With no allowables, all eight remain NOT_EVALUATED. API RP 2A compliance and spreadsheet equivalence are not established.

Inputs and method

The interface is digitalmodel.subsea.structural_checks.api_rp2a_check. Dimensions use mm, forces N, moments N mm, and stresses and pressure MPa. Axial force is positive in tension and negative in compression. Bending moment is the signed resultant about any centroidal axis of the circular tube; its magnitude determines peak elastic stress. Pressure is nonnegative external gauge pressure. Shear force is signed. Wall thickness satisfies 0 < t < D/2.

For inner diameter d = D − 2t, direct circular integration gives A = π(D² − d²)/4 and I = π(D⁴ − d⁴)/64. With Z = I/(D/2), normal demand is σ = N/A and peak bending demand is σb = |M|/Z. Geometry factors follow integration; no standard coefficient is introduced. Axial force is the effective section force supplied by the caller. Pressure end thrust is not calculated or added. Yield strength is a required positive input retained as metadata; no API 5L grade or allowable is selected from it.

Each result records calculated stress, allowable stress, unity ratio, a three-state disposition, a nullable pass/fail value, reference and reason. Missing stress or capacity is None, distinct from a true zero. For a supplied allowable, unity is demand/allowable and the comparison passes when demand ≤ allowable. A failed comparison makes the aggregate FAIL. Otherwise any missing check makes it NOT_EVALUATED, with passes=None. The maximum unity ratio describes evaluated checks only and cannot establish full acceptance.

Supplied allowables and citation sidecars

The optional allowables mapping accepts axial_tension, axial_compression and bending keys. Each value is a digitalmodel.citations.schema.CitedValue with positive finite value, units MPa and a Citation. Citations are validated against their wiki source through the existing resolver, or the explicit citation_root. A missing page or mismatched source identity raises CitationResolutionError, including when the demand is zero.

The result carries citations separately from the numeric check records. Citation identity validation does not establish the supplied allowable's correctness, clause applicability, effective length, buckling qualification, load combination or code edition. Those require engineering review. The unit tests use an explicitly illustrative source fixture, not a qualified API source.

Worked example

The example inputs are invented to permit independent arithmetic; they are not an issued design or material data. D = 10 mm, t = 1.000 mm and supplied yield strength = 100 MPa. For N = 90π N and M = 369π/2 N mm, with no pressure or shear:

  1. d = 8 mm; A = 9π mm²; I = 369π/4 mm⁴; Z = 369π/20 mm³.
  2. σ = 90π/(9π) = 10 MPa.
  3. σb = (369π/2)/(369π/20) = 10 MPa.
  4. No allowable is supplied, so acceptance remains NOT_EVALUATED.
PYTHONPATH=src python examples/subsea/api_rp2a_tubular.py

The JSON output includes area 28.274 mm², second moment 289.812 mm⁴, section modulus 57.962 mm³ and both demands 10 MPa. The aggregate remains NOT_EVALUATED. An independent compression vector uses D = 6 mm, t = 1.000 mm, N = −100π N and M = −325π/2 N mm: A = 5π mm² and Z = 65π/12 mm³, giving compression 20 MPa and bending 30 MPa.

Validation and artifact review

The tests were written before implementation. The initial run failed because the package was absent. Hand calculations supply expected stresses and geometry; illustrative allowables supply the comparison boundaries. Artifact review found that malformed allowable containers could be converted silently and missing citation objects could raise an incidental error. Regression tests reproduced those defects before validation was added. Tests also cover invalid finite domains, floating-point overflow, incomplete aggregate disposition and the executable example.

Known limits and way forward

The source workbook and its input/output vectors were not found in this checkout. The standards catalog and domain index were unavailable in the adjacent workspace, and no authoritative API clause text was available for this implementation. Requested clause locators are recorded as unverified; an edition is not inferred from existing code. The existing jacket/topside package is not used as an authoritative source or altered by this module.

Further work requires an authorized workbook copy and versioned digest, cell/formula mapping with an extraction tool, two or three verified workbook vectors, and eligible API RP 2A and API 5L source records. Qualified capacity and interaction equations, applicability checks and resolved Citation sidecars can then replace the corresponding NOT_EVALUATED records. Hydrostatic stress alone cannot establish collapse capacity. This module performs no licensed solver calls and introduces no new runtime dependency.
