Riser model-data appendix interface

Summary

The appendix builder converts explicit SI property snapshots into native C.1–C.3 tables suitable for JSON and report builders. Each table caption carries the SHA-256 of the supplied model bytes. A matching snapshot digest establishes binding to those bytes; extraction from a solved model is not established. The output therefore retains model_extraction_status=NOT_EVALUATED.

Inputs and output

Import ComponentSnapshot and build_appendix from digitalmodel.drilling_riser.model_data_appendix. A snapshot contains a generic component identifier, top and bottom elevations, the model digest, an elevation source, a property mapping and a source mapping. Each supplied property requires a non-empty source reference. Omitted or null properties remain null and NOT_EVALUATED; a true zero is retained.

The builder requires model bytes, snapshots, water density and its source. It accepts optional screening limits keyed by the transition metric names. The returned dictionary contains tables, units, field status, sources, screening limits, limitations and the digest. Serialize it with json.dumps(result, allow_nan=False). Input mappings are copied; the builder performs no file writes.

The component list represents one continuous line. Elevations increase upward; top elevation exceeds bottom elevation. Exact adjoining elevations are required; no unreported closure tolerance is applied. Component length and target segment length remain explicit inputs: neither is inferred from the elevation difference, which can differ from arc length.

Source: Orcina, Morison’s equation, online help retrieved 2026-10-19, HTTP 200. The help page has no stated edition. It identifies Morison et al. (1950); the original paper was not independently retrieved.

No environmental density, hydrodynamic coefficient or engineering screening limit is supplied by the implementation. The added-mass diameter is independent of hydrodynamic drag diameter and is never inferred from it. The normal Ca and its reference diameter must describe the same displaced-area convention.

Screening and limitations

A screen flags only strict exceedance of the supplied limit; equality does not flag. Both adjacent values must be positive to form a ratio. A zero or missing comparator leaves the ratio and screen NOT_EVALUATED. A valid ratio without a limit remains calculated, but the screening verdict remains NOT_EVALUATED. Screening is not an acceptance criterion.

The transition metrics are stress OD, stress ID, supplied section modulus, EI, EA, hydrodynamic diameter, dry mass per length, added mass per length and Ca·Da². No equivalent tube section or stiffness is reconstructed.

Wet mass is buoyancy-adjusted mass per length and may be negative; it is retained in C.1 and never substituted for inertial mass. Marine growth, buoyancy modules, auxiliary lines and trapped water are not automatically added. The supplied mass, diameters and coefficients must already represent their intended inclusion. A field source is recorded, not independently qualified by this builder.

Axial, non-circular, partially submerged and lumped-body loading, flex-joint curves, tensioners, stroke limits, composite sections, VIV suppression, node positions, design-basis reconciliation and graphical profiles are not evaluated. These remain later parts of issue 2153. The existing stack-up reconciler checks drawing-to-spec agreement; it is not used as a model-to-basis check.
