Offline and native test coverage

The inventory describes the immutable snapshot_revision in the register, rather than the current working tree. Later test additions, edits and deletions do not refresh this historical record; inventory links identify paths within the recorded commit. Run python docs/domains/risers/reconcile_qualification.py --check to check its consistency, or --write to reconcile source digests, the test inventory and Table C. Selecting a later committed snapshot requires --write --revision REF and review of the associated evidence gaps; reconciliation does not qualify engineering results.

The following inventory is obtained by parsing test source as syntax, without importing the riser package or collecting these tests. Counts denote named test functions, not parametrized cases, executed tests or qualified results. Solver-marked tests are distinguished from other tests; an unmarked test is not thereby established to be solver independent.

A module-level availability call or skip-condition decorator is evaluated during collection, before marker deselection. Consequently, -m "not solver" alone cannot guarantee that a binding is not queried. MIXED_WITH_COLLECTION_PROBE identifies files with other helper tests and such a call. NO_DIRECT_COLLECTION_PROBE_FOUND describes this limited syntax check, not proof of safe transitive imports or fixtures. Splitting collection-safe helpers from native tests remains follow-up work.
