The bounded section-arc-length candidate does not qualify as a repair. Coarse native metrics report valid, but the represented surface violates geometric limits. Finer fits lose the planar keel. Item 2 remains open. Existing default sampling, screening rules and catalog signatures are unchanged.

What was tested

The reviewed plan was authorized by the owner's continuation instruction after its approval checkpoint. One candidate family resampled the immutable fixed-z/PCHIP reference by section arc length, fitted one C2 side face, and constructed the optional bottom using the side's actual keel edge. No poles were flattened, geometry strips removed, statuses coerced or thresholds widened.

Both synthetic forms use L=100 m, B=20 m, T=8 m and D=12 m. Rounded uses Cb=.70 and default section parameters; transom uses Cb=.72, transom fraction .90 and LCB fraction −.10. Full parameters are in the linked plan baseline. Native results below are archived-run comparisons, not measured validation. Geometry comparisons use the specified source-reference surface; they do not establish agreement with a real hull.

Evidence and limits

Sanitized machine-readable evidence preserves native per-metric statuses, signatures, quadrature/regularity records, offending coordinates and all six geometry records. The baseline RED tests exercised the existing exporter and native screen before any fitting change. Subsequent tests preserve default invalid statuses, inspect coarse necessary native gates, verify the sampler against the reference, and retain six strict expected failures for the rejected geometry. A closed-form plane checks the diagnostic's derivative and bound calculations.

Ten allocated diagnostic slots were used: four baseline slots and six candidate slots. Six reached native assessment; four finer candidates were rejected during geometry construction. The limit was twenty. Remaining quadrature refinement, analytic candidate controls, hydrostatic/area qualification and full acceptance sampling were not run after decisive geometric rejection. Existing sphere/cylinder/Wigley regression controls remain unchanged. No three-level convergence or hydrostatic-fidelity success is claimed.

The source calls OpenCascade's global C2 GeomAPI_PointsToBSplineSurface approximation. Its observed coordinate drift establishes loss of source geometry in this candidate. Whether a constrained fitting representation can also cure the original native integration failures remains a hypothesis.
