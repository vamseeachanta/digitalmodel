Offshore technical safety screens

Screening only. The bundled 1996 criteria are superseded, unverified regression inputs and are refused unless allow_test_criteria=True is supplied. No current design values are bundled. A citation identifies a claimed source; it does not verify the value against that source.

Ship-impact energy

The vessel's available kinetic energy is calculated as E = 0.5 m (1 + C_a) v², where displacement mass is in kg, speed in m/s, added-mass coefficient is dimensionless and energy is in J before conversion to MJ. The coefficient requires its own citation and has no default. The target is assumed stationary. Absorbed energy, force, structural resistance, collision frequency and fatalities are not calculated.

from digitalmodel.foam_system.sizing import Citation
from digitalmodel.technical_safety import (
    ShipImpactInputs, get_criteria, screen_ship_impact,
    FireScenario, screen_fire_heat_load,
)

historical = get_criteria("s_dp_001_1996_rev2")
vessel = ShipImpactInputs(
    mass_kg=5_000_000.0, speed_m_s=2.0,
    added_mass_coefficient=0.4,
    added_mass_citation=Citation(
        "Synthetic worked case", "example-1", "assumed added mass"),
)
impact = screen_ship_impact(vessel, historical, allow_test_criteria=True)
# a = 2,000,000 kg; E = 0.5 * 7,000,000 * 4 = 14,000,000 J.
assert impact.energy_mj == 14.0
assert impact.margin_mj == 0.0
assert impact.within_design_energy  # comparison only, not structural acceptance

release = FireScenario(
    inventory_kg=1000.0, release_rate_kg_s=2.0, phase="gas",
    pressurised_release=True, liquid_pool_possible=False,
    enclosure="open", ventilation="fuel_controlled",
)
fire, = screen_fire_heat_load(release, historical, allow_test_criteria=True)
assert fire.fire_type == "jet"
assert fire.heat_flux_kw_m2 == 250.0  # historical test input only

ShipImpactInputs.from_units accepts explicit mass units kg, tonne, lb, slug, long_ton, short_ton and speed units m/s, ft/s, knot, using the shared Pint registry. The ambiguous unit ton and pound-force are refused. For 10,000 lb at 10 ft/s with Ca = 0.2, the energy is 0.02528406605628288 MJ.

The optional impact_screen argument of assess_vessel_collision retains this result. Missing QRA probability or consequence remains NOT_EVALUATED. Energy does not fill either input. The energy evidence is held on the result; the MAH CSV format does not serialize it.

Fire selection and fire-water credit

The scenario describes a sustained ignited release. Inventory and release rate must be finite and positive. Pressurised gas, liquid spray and two-phase releases select a jet case. Caller-established liquid accumulation adds a pool case. Mixed releases retain both cases. Pool ventilation control is required as an explicit input; a ventilation-controlled pool requires an enclosed area. No universal pressure, inventory or release-rate threshold is assumed.

Each result retains the selected edition, citation, scenario and water evidence. Peak and average flux are separate inputs. No wall heat absorption, exposed area integration, fire duration or total power is inferred.

Passing FireWaterEvidence requests credit. All its conditions default to false: directional spray coverage, coverage of every target surface, protected supply, prompt detection and activation, assured availability, scenario-specific demonstrated effectiveness, and an equipment/piping target. This is a module screening policy; verified NORSOK compliance is not established. General area deluge alone does not establish protection against an impinging jet. Primary partitions and load-bearing structure are excluded from credit.

Credit selects a separately cited absolute reduced-average flux only when all conditions hold and flux_basis="average". Any missing condition retains the unreduced load and is listed on the result. Peak flux is never reduced. Missing reduced criteria cause an error when credit would otherwise apply; no reduction factor is invented.

Supplying criteria

get_criteria(key, path) reads an exact edition key from YAML. No latest-edition fallback or merging across editions occurs. The root contains schema_version: 1 and an editions mapping. Every edition contains standard, edition, status and values. Use status: project for caller-supplied, independently checked governing inputs; that label does not authenticate them. Use superseded for historical regression inputs.

Each value contains a positive finite value, a unit and a citation with nonblank standard, edition, clause and optional note. Citation standard and edition must match the selected header. Direct construction uses CitedValue and EditionCriteria with the same validation.

Basis and limits

  • RISP JIP report, version 2, October 2023, part ST-16725-2 "Ship collision risk", section 3.4, p.11: collision-energy equation. Added mass remains a cited scenario input.
  • Fire and Explosion Guidance, issue 2, March 2018, sections 2.10.1–2.10.2, 3.4.2.2 and 8.7.4: release modes and the need to establish water effectiveness and reliability.
  • NIST SP 811, 2008, appendix B.8: unit-conversion basis.
  • NORSOK S-DP-001 Rev. 2 (1996), 7.8, 8.1 and 11.3 step 3: the supplied historical regression values. A public primary copy of this edition was not verified. No private library was accessed and no original standard text or table is included.

Current NORSOK S-001, N-003, DNV-RP-C204 and applicable API 521 criteria require licensed-source verification before design use. Pool and water-reduced flux values are not inferred from the historical jet peak. Blowdown, rupture, flare, move-off, pump redundancy, CFD and company standards are outside scope. Explorer and website integration in other repositories remain follow-up work.
