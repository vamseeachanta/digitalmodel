Materials database: scope and gaps

This slice projects the existing reconciled grade records into validated, immutable metadata. grades.py remains the strength authority; no separate grade matrix or dimensional table is introduced. No external numerical inputs or source downloads are included. Scope is limited to issue #1204.

database_schema.py defines designation, specification, nullable edition, nullable product level, MPa strengths, provenance and nullable foreign keys. database.py supplies load_database(), database.lookup(name, psl=...) and dictionary lookup by record.key. Keys comprise specification, edition, designation and product level; unknown edition and inapplicable level use explicit key tokens.

Product-level selection follows grades.smts_mpa: stored PSL1 minima receive separate records. API 5L 46th-edition 9.3.1/Table 6 SI minima apply through X70. A PSL1 request without a stored PSL1 minimum, or an unknown API product-level token, raises ValueError. Licensed-text verification by the maintainer remains required before #2726 closure; this correction does not establish product qualification. Non-API product levels are null. Aliases, including the distinct API and hull Grade A names, follow grades.get.

Each record retains its existing citation, repository-relative locator, normalized SHA-256 and UTC retrieval date.
