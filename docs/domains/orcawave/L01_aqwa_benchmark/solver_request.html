RAO scales and phase floors contain one positive value per DOF; matrix scales contain one positive value for every matrix cell. The scale units must match the corresponding normalized export, including mixed rotational/translational matrix units. The criteria citation must justify each scale and limit. The ladder uses 4 frequencies by 4 headings, 10 by 9, and 20 by 9, giving 16, 90 and 180 cases, for each supplied thread count and each DivideNonPlanarPanels state. Normalized export and QA

python scripts/benchmark/l01_investigation.py compare config.json comparison.json --aqwa aqwa.json --orcawave orcawave.json

Each JSON export requires solver exactly AQWA or OrcaWave, source exactly solver, a native artifact's native_sha256, native_readback: true, the exact declared basis, and the following complete arrays. Readback and provenance declarations are supplied attestations, not authenticated by the offline script.

raos: [{frequency_rad_s, heading_deg, values: [[real, imaginary], ...]}]
matrices: [{frequency_rad_s, added_mass: [[...], ...], damping: [[...], ...]}]

RAO rows contain six complex pairs. Each matrix is six by six, including couplings. Source for dimensions: API execution summary, Hydrodynamic Data. Duplicate keys, incomplete grids, nonfinite values, placeholder provenance, incompatible declarations and malformed dimensions are refused. Reordered complete arrays are paired by frequency and heading value.

Exports must carry the request grid's exact frequency_rad_s and heading_deg values. Coverage uses exact numeric keys; converting a native period back to angular frequency may differ in the last bit and will be refused. The normalizer must record the native-to-request mapping, including native values, units, conversion and the corresponding exact request values, with evidence that each native sample represents its requested grid point. Do not independently round or infer missing grid points.

The requested AQG-style band is a caller-specified pointwise envelope: for each response or coefficient, the absolute difference divided by its predeclared positive engineering scale must not exceed max_normalized_error. The scale and limit together define the allowable absolute difference in that component's units. This is an explicit request-specific acceptance definition, not a published AQG classification or the repository comparator's RMS policy. Every failing cell is reported; an average cannot hide a governing failure. Complex RAO differences include phase.

Phase difference is circular and diagnostic-only, consistent with src/digitalmodel/hydrodynamics/diffraction/multi_solver_comparator.py phase statistics and ComparisonPolicy. Samples at or below either declared amplitude floor are counted as NOT_EVALUATED for phase. The numerical band check can say WITHIN_BAND or OUTSIDE_BAND, but engineering qualification always remains NOT_EVALUATED until independent evidence review. Identical or fabricated data cannot be authenticated by agreement alone. The output records canonical JSON digests of the configuration and exports, not raw-file byte digests.

Exit status is nonzero for refused inputs or an OUTSIDE_BAND comparison. Existing output files are preserved. A successful prepare or compare exit does not establish native readiness, solver completion or engineering acceptance.
