Structure model preparation

Preparation plan for the structure installation study, under the OrcaFlex initiative. User authorization: prepare inputs now; schedule analyses after the jumper campaign.

  1. Original native input and design workbooks will be retained with digests in the private original-data owner. Reusable prepared inputs will reside in private digitalmodel-data.
  2. The source AHC model will remain unchanged. A separately named fixed-winch diagnostic master will change only the selected controller payout reference to zero and remove its now-unused external-function definition. Static length, connection geometry and physical properties will remain unchanged. A semantic difference receipt will enumerate the changes.
  3. The existing sea-state generator will prepare one master with 156 small changes at 0.25 m Hs and 1 s Tp increments. Native load/save checks will verify inputs and one standalone irregular-wave pilot. Neither statics nor dynamics will be called.
  4. Result objects and available channels will be checked. Load-independent operability screening will not be presented as a qualified structure envelope. Physical and capacity discrepancies will remain in the private readiness register.
  5. Smaller and larger dry-mass targets will remain design requirements until realistic geometry and associated hydrodynamic/rigging properties are established.
  6. The package will carry a scheduling hold, not an asserted software interlock. No automatic launch will be configured. Subsequent scheduling will require verified completion of the intended jumper cases and review of the first structure case.

Tests will precede helper implementation and cover immutable source bytes, permitted differences, residual references, invalid control configurations and output preservation. An independent review and native input readback will precede closeout. Input readability will not be described as equilibrium, numerical convergence or engineering acceptance.
