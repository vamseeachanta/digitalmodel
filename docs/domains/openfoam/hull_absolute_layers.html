Absolute hull layer sizing

The case builders accept an explicit absolute first-layer thickness, expansion ratio and minimum overall stack thickness. Requested lengths are recorded per patch. Achieved coverage and y+ remain NOT_EVALUATED until native mesh and flow output is available. These inputs do not establish a remedy for layer collapse.

Inputs and equations

The source is the OpenFOAM v2312 (2023) snappyHexMesh layer guide, keyword sections relativeSizes, expansionRatio, firstLayerThickness, minThickness and nSurfaceLayers, accessed 2026-10-19.

For first thickness h, expansion ratio r and layer count n, layer k has thickness h rk, starting at k = 0. Summing gives H = h(rn − 1)/(r − 1); for r = 1, H = nh. These equations follow directly from the guide's adjacent-layer expansion definition. No empirical coefficient is used. Zero requested layers give a zero stack and undefined first and final thicknesses.

minThickness denotes the minimum overall stack. A request below that minimum is flagged in provenance. It is not compared against the first layer alone. Inputs are positive finite scalars; layer counts are nonnegative integers. A stack outside the supported floating-point range is refused before case files are created.

Case construction

from digitalmodel.solvers.openfoam.hull_layers import AbsoluteLayerSpec

spec = AbsoluteLayerSpec(
    first_layer_thickness_m=first_layer_m,
    expansion_ratio=adjacent_layer_ratio,
    min_thickness_m=minimum_overall_stack_m,
)
configured = config.replace(absolute_layers=spec)
# Pass configured to build_hull_case or build_double_body_case.
diagnostic = spec.sizing(layer_count, outside_cell_size_m=measured_normal_cell_m)

The configuration sets relativeSizes false and emits firstLayerThickness with no finalLayerThickness. Existing per-patch counts are retained. Omitting absolute_layers retains the inherited relative dictionary settings. Both builders record mesh.layers in case_provenance.json.

The optional diagnostic cell length is the local undistorted cell size normal to the patch. Cell/first-layer and cell/stack ratios are reported only when that length is supplied. The case builders do not substitute an estimated in-plane cell length for a measured normal length. No universal ratio cutoff is established.

Verification and remaining qualification

Tests use synthetic hand calculations. For h = 0.002 m, r = 2 and n = 3, the expanded stack is 0.002 + 0.004 + 0.008 = 0.014 m. A caller-supplied cell length of 0.028 m gives cell/first = 14.0 and cell/stack = 2.0. These are arithmetic examples, not mesh acceptance limits. Emission tests read back both dictionaries and provenance without running a solver.

Native coverage above the stated criterion, achieved y+, and the cause of stack collapse are not established. The existing background refinement sequence and surface refinement levels are retained. Additional background refinement or replacement with snappyHexMesh-managed refinement will require separate native comparisons on qualified inputs. Increasing an absolute first-layer thickness will also require a justified wall-treatment criterion.
