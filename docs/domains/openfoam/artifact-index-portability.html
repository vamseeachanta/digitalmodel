OpenFOAM artifact index portability

Summary

The artifact index imports without optional Unix open flags. Portable digest, framing and metadata helpers remain available on Windows. Filesystem snapshots require no-follow, descriptor-relative operations; an unsupported platform receives ArtifactIndexError before tree access. Missing protections never select a path-based fallback or produce an empty valid index.

Capability contract

descriptor_walk_supported() reports the conjunction of the capabilities below. The checks follow the Python 3.11 Library Reference; operating-system names alone do not establish API support.

RequirementPurpose and source
O_DIRECTORY and O_NOFOLLOW exist Retain directory-only and no-follow opens. os.open constants.
os.open and os.stat belong to os.supports_dir_fd Resolve entries relative to an opened parent. Directory-descriptor support.
os.listdir belongs to os.supports_fd Enumerate the opened directory. File-descriptor support.
os.stat belongs to os.supports_follow_symlinks Inspect entries without following symlinks. Symlink-control support.

The gate covers snapshot_tree, verify_unchanged, select_roots and build_index. On a supported platform, descriptor identity checks, symlink rejection, content hashing and mutation detection retain their existing behavior. Digest formats and artifact identities are unchanged. No engineering equations, coefficients or limits are introduced.

Worked example

Input: an existing empty temporary directory supplied as root: pathlib.Path, and one file named field containing the six ASCII bytes sample. The directory is supplied by the caller so the example has no fixed storage location.

Method: check descriptor capabilities, snapshot the directory, and compare the record directly with the input byte count and its independent hashlib.sha256 digest. When a capability is missing, require the documented exception instead of an artifact record.

from hashlib import sha256

from digitalmodel.solvers.openfoam.artifact_index import (
    ArtifactIndexError,
    descriptor_walk_supported,
    snapshot_tree,
)

payload = b"sample"
(root / "field").write_bytes(payload)
if descriptor_walk_supported():
    records = snapshot_tree(root)
    assert [(item.path, item.size_bytes, item.sha256) for item in records] == [
        ("field", len(payload), sha256(payload).hexdigest())
    ]
    print("one file; six bytes; digest matches input")
else:
    try:
        snapshot_tree(root)
    except ArtifactIndexError as error:
        assert "this platform is unsupported" in str(error)
        print("snapshot unsupported; no index emitted")
    else:
        raise AssertionError("an unsupported snapshot produced a result")

Answer: supported execution reports one file; six bytes; digest matches input. Unsupported execution reports snapshot unsupported; no index emitted. Regression tests execute this exact example in both capability conditions.

Collection and verification

The regression suite launches fresh Python processes with each optional flag removed before importing the existing artifact tests. It also removes both flags and descriptor capability sets together, then executes that module: its nine portable tests run and its twelve descriptor-dependent tests skip with an explicit capability reason. No module-wide skip is applied.

Separate tests remove each required capability and check that every public tree operation refuses a nonexistent input with the unsupported-platform error. On supported systems the existing tree tests continue to exercise real files, symlinks, FIFOs and content changes. An additional Linux snapshot test has no capability-based skip, so an incorrectly false capability result cannot silently remove Linux coverage.

The configured solver-smoke gate already includes the containing test directory, so no CI exclusion or gate change is required. New solver-smoke regressions remain in that gate.

Limits and next check

The capability-removal tests run on Linux and reproduce the missing-API contract; they do not establish native Windows execution or successful collection of the entire solver-smoke shard. Native Windows collection remains a follow-up under issue 2086. A Windows snapshot implementation would require a separate design that preserves the descriptor walk's protection contract. No licensed solver is required by this example or these regression tests.
