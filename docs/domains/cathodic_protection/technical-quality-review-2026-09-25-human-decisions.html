Cathodic protection: technical quality review and the decisions it requires

Decision boundary. This page records what the 24 September review established, what it could not establish, and the twelve decisions that only the repository owner can take. It launches nothing, files no issues, changes no code and grants no approval. Decisions recorded on this page are a local note until the owner restates them in the GitHub issue or plan that governs the work.

1. Verdict and what the evidence supports

The cathodic protection domain is not release-grade. The test suite is green and the newer package is well structured, but the numbers it produces cannot yet be handed to a client. Four independent adversarial reviewers covered the B401 anode modules, the pipeline/ICCP/corrosion modules, the workflows and legacy solver, and the tests and documentation. Every blocker below was re-checked by the orchestrating session against the code and, for DNV-RP-B401 constants, against the repository's own dataset CSVs in llm-wiki/wikis/engineering-standards/wiki/datasets/dnv-rp-b401/.

  • DNV-RP-B401 Table 10-1 final current densities and Table 10-4 coating constants are wrong in the new package and inverted in the legacy solver; tests lock the wrong values in.
  • The edition argument ("2017"/"2021") is accepted everywhere and changes no value anywhere.
  • The YAML engine routes every CP workflow to the legacy solver; the new package is unreachable from python -m digitalmodel. Four of six shipped demos return adequate: false and exit 0.
  • Eight physics or unit errors of blocker class exist in the corrosion-rate, onshore pipeline, ICCP, fuel-system and stray-current modules.
  • Sound and edition-stable: the B401 core relations, F103 Eq. 14 protected length, the Dwight rod formula, NACE SP0169 criteria, and dnv_rp_f106.py, which is the one module that meets the full repository bar.

4. Claude discussion and limitations


The review did not open the DNV-RP-B401, DNV-RP-F103, ISO 15589 or NACE PDFs; constants were checked against the repository's own B401 dataset CSVs (2005 with 2008 amendments) and the reviewers' recollection of later editions. Three items therefore remain to be confirmed against the PDFs before they are treated as defects: the 2021 edition date carried in _edition.py ("May 2021"; reviewers recall September 2021), the legacy F103 Table 5-1 temperature bands, and the FBE breakdown constant (code 0.010, reviewers recall 0.030).


Rows marked "reviewer probe" in Table 2 were demonstrated by one reviewer's scratch script and read by the orchestrator, but not re-executed. The doc-verified tally in Table 1 is an estimate from reading the test files, not a tool count. The local checkout is 181 commits behind origin/main; every CP path was confirmed byte-identical, but the local quality-gate file and pytest collection rules are older than the ones on main.


No comparison was made with the rds02 machine's copies of these files; SSH from this session was blocked by a known-hosts permission error in the sandbox. Nothing in this review was committed, pushed, or filed as an issue.
