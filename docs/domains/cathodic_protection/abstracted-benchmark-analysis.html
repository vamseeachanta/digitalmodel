Cathodic protection analysis — abstracted benchmarks

Executive Summary

Three complete abstracted configurations are checked through the cathodic protection engine adapter against independent arithmetic. The selected installed count meets mass and initial/final current-output criteria; one fewer anode fails at the governing criterion. The results establish computational agreement for the represented scope. They do not establish agreement with the complete legacy designs.

Basis and limitations

All abstracted inputs and legacy values are assumed, based on previous experience. Records 004, 009 and 010 are selected from the existing abstracted calculation examples. Their configuration dictionaries are read as literals; source code blocks are not executed. The constants and citation sidecars are read from the existing edition-aware table API without copying licensed table values. DNV-RP-B401, Cathodic protection design, editions 2005, 2017 and 2021, is the edition basis recorded by the repository API. Table 3 uses ABS Guidance Notes on Cathodic Protection of Ships, December 2017 edition. The existing citation metadata identifies individual anode resistance as a relevant locator. The current-density, coating-breakdown, mass and output equations are reproduced from the public repository API documentation; exact clause-title concordance is not independently established here.

The arithmetic reference sums area × phase density × capped coating breakdown; required mass is mean demand × design life × hours per year divided by utilization and capacity. Required counts are rounded upward independently for mass, initial current and final current; the largest governs. Stand-off resistance uses the documented logarithmic formula. Long-flush resistance uses resistivity divided by length plus width. Depletion retains length and scales equivalent radius by the square root of the remaining mass fraction.

The table API is shared by the reference arithmetic and the engine. These tests cannot detect an incorrect table value. No qualified jacket-area dataset is established by the inspected issue records. The temporary-service case replaces that incomplete case so three complete end-to-end checks can ship; a complete jacket benchmark remains open.

The initial current matches. Mean and final demand differ because the current route uses the configured initial and maximum coating factors and their arithmetic mean; the workbook develops the coating factor with time. Required net mass follows the mean-demand difference. The final-current count also depends on depleted geometry. The unchanged configuration selects more anodes than the calculated minimum and passes its reported scope, which does not evaluate special stern, propeller or opening geometry. Agreement with the legacy workbook is therefore not established; the coating and depletion bases must be reconciled before these outputs are used as equivalent designs.

Sacrificial-anode resistivity sensitivity

Record 010, Input Parameters and Environment — Seawater Resistivity vs Salinity, supplies the three-point envelope. It spans 210.0 to 5076.0 mΩ·m, including the design point of 587.5 mΩ·m. This is an assumed environmental envelope from the existing record, not a newly measured salinity relationship. No plot is digitised and no additional public-source value is introduced.

Way forward

Retain the three arithmetic benchmarks. Reconcile legacy coating development and depletion geometry before asserting workbook equivalence. Complete zone inventories and anode-family allocation before evaluating physical designs. Qualify the environmental envelope and review the current-output requirement before selecting an installed count.

Reproduction

tests/cathodic_protection/test_abstracted_design_benchmarks.py contains three parametrized end-to-end checks and a record-001 case that produces and asserts every rounded Table 3 current-route value. Floating demand uses a relative tolerance of 1e-12; rounded mass and resistance use half the last stored decimal unit. Integer counts and PASS/FAIL boundaries compare exactly. No production numerical setting or licensed table is changed.
