Aboveground tank-bottom cathodic protection

digitalmodel.cathodic_protection.api_651_tank_bottom provides preliminary ribbon-grid sizing in the context of API RP 651, fifth edition (2024). It calculates independent checks, not a protection or standard-compliance verdict. Every design rating and acceptance limit is supplied by the caller.

ribbon_grid clips each row to the circular boundary using exact chord geometry. The number of rows is rounded up and pitch adjusted down. Optional orthogonal rows double the active length; uncoated busbar length is excluded. Installed length is checked against current capacity, and nominal pitch is checked against the supplied spacing limit. Neither check establishes curved-edge coverage.

conductor_voltage_drop uses I × resistance-per-metre × length for a lumped end load. Uniform discharge gives half that drop for a one-end feed and one eighth for equal-voltage feeds at both ends. The tank calculation uses current per installed ribbon metre for the specified longest feed span and a separate, supplied busbar path current. Current sharing, unequal feed voltages, joints, cable losses, electrolyte resistance and rectifier sizing require a project circuit model. The reported drops are not added into a predicted polarization or rectifier voltage.

An HDPE barrier can shield the bottom from anodes below it. Dry sand, oil-contaminated sand and voids can interrupt electrolyte contact even when enough ribbon is installed. The resistivity warning uses a project threshold; there is no universal resistivity pass criterion. The example assigns 100 Ω·m and a 200 Ω·m warning threshold solely for demonstration.

check_center_edge_polarization compares supplied IR-corrected local readings with an explicit criterion and reports their signed difference. Missing readings remain unassessed. Synthetic readings of −0.900 and −0.950 V CSE both meet a supplied −0.850 V CSE criterion, with a +0.050 V centre-minus-edge difference. This does not establish protection elsewhere, polarization shift, or an overprotection limit.

Reference electrodes and survey criteria

The shared reference_electrodes utility is exported at package level for all CP calculations. Survey, assessment-report, monitoring and potential-check entry points use that utility. Existing design modules retain the electrode of their governing native criteria; conversion alone does not change a criterion.

The selected 25 °C offsets vs SHE are CSE +0.316 V, nominal Ag/AgCl/seawater +0.250 V, Ag/AgCl/saturated KCl +0.197 V and saturated calomel +0.241 V. SHE is zero by definition. Each lookup returns electrolyte conditions and a validated public citation sidecar. The alternative +0.256 V Ag/AgCl value is not interchangeable with the selected nominal seawater table value; it differs by 6 mV and requires its own electrolyte/construction basis. The selected SCE value differs by 3 mV from +0.244 V; the selected CSE-to-SCE offset is 0.075 V, rather than 0.072 V.

Conversion follows Etarget = Esource + Ereference,source − Ereference,target. Bare Ag/AgCl is rejected. Temperature correction is not implemented; the utility rejects temperatures other than 25 °C. Nominal seawater values do not replace calibration for the actual chloride activity, temperature and junction arrangement.

check_center_edge_polarization, analyze_cis_survey and compliance_check_potential accept the keyword temperature_c, defaulting to 25.0. Tank and survey checks forward it to the shared converter, which rejects other temperatures and nonfinite values, including when both electrodes are the same. Reporting applies this guard when converting an omitted criterion. An explicit reporting criterion remains in its supplied electrode and bypasses conversion; its suitability at the measurement conditions requires a separate basis.

check_center_edge_polarization(
    -0.90, -0.95, criterion_V=-0.85, temperature_c=25.0,
)
# temperature_c=35.0 raises ValueError; no temperature correction is inferred.

The temperature dependence is discussed in CEOCOR Rev 11, sections 3.1, 3.2 and 3.4. The public source was checked on 5 November 2026. This change adds no electrode offsets or temperature coefficients.

Zinc is a pseudo-reference and requires a finite zinc_potential_she_V supplied from calibration. Using −0.800 V solely as an illustration gives a CSE-to-zinc offset of +1.116 V and converts −0.850 V CSE to +0.266 V zinc. No universal zinc offset is embedded. Legacy monitoring zinc/MMO offsets are now unassigned; zinc alarm thresholds require calibration and MMO alarm thresholds require a separately calibrated criterion.

analyze_cis_survey and compliance_check_potential accept reference_electrode. Omitted criteria are converted from their existing CSE defaults; explicitly supplied criteria are already in the measurement electrode. Results show that electrode and its numeric criterion. Existing CSE calls retain their behavior. Survey ON/OFF selection retains its previous behavior; ON readings alone do not demonstrate an IR-free protection criterion.

Public method sources

  • API RP 651, fifth edition (2024), public scope: application context only; paid text and proprietary design values are excluded.
  • DoD Electrical TP-16 (March 2017), section 5.11, printed pp128–131: tank area, current requirement, ribbon quantity, liner arrangement, multiple feeds and foundation resistivity. The printed ribbon multiplication sign is dimensionally inconsistent with its numerical example; this implementation uses I/q.
  • CEOCOR Rev 11 (November 2018), section 3.4, Table 1, p12: selected CSE and Ag/AgCl offsets. Only selected values are implemented.
  • ASTM G215-17 public distributor preview, Table 1, sections 6.2.3 and 7.1.1: SCE/SHE, sign convention and zinc drift. Sources retrieved 2 November 2026.
