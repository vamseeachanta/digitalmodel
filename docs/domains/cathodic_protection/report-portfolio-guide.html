Review a report

  1. Open the current supplied review index, then the case. Read the question, recommendation, evidence and missing-fact HOLD.
  2. Select report text, click Comment, type a note and Add. The fixed review panel provides editable notes, Save comments, Copy, Load and Export JSON. Choose next-step decisions beside the relevant sections; comments and decisions export together. Save the matching JSON beside the HTML. Browser folder selection requires permission; downloads must be saved or moved to that location. Drafts persist in the same browser when available.
  3. Reopen the same case and load saved feedback when needed. Preserve prior rounds and conflicting decisions; reject a different source digest or revision.

Historical numerical reports retain their original controls and artifacts. Their manual HTML/sidecar selection is a compatibility path, not the default for current decision planning packs. Current five-case planning-copy checks exercised the actual index, input-draft reload, comment/decision save, downloaded file readback, saved-file load, conflicts and stale rejection. This does not certify the historical numerical reports, hosted recipient delivery or engineering acceptance.

Prevent stale-entrypoint and draft-loss failures

Reuse the existing human-decision review pattern: selection-linked comments, visible in-place choices and notes, immediate browser draft persistence, and a retained JSON export. Verify the current source digest, delivered archive version, extraction index links, actual browser address and foreground window together. Opening a new window or inspecting an accessibility tree does not prove the reviewer sees that page. Exercise Save and reopen through the delivered index. Keep old source reports and comments; make archived-source links explicit downloads so they cannot silently replace the current review surface. Verify final delivered file bytes against the receipt after all transformations.

Make a decision from the same review pack

Each decision-ready draft states the question, viable options, preparer recommendation, evidence, tradeoffs and the exact missing-fact HOLD. Give competing options distinct section IDs. Record the selected option ID, acceptance scope, conditions and reason in the existing comment panel. A recommendation or agent artifact review is not engineering acceptance. Accepting a proposed next step does not establish a missing installed fact or clear a source-rights, numerical or intended-use gate.

The engineering reviewer and client receive the same human-facing HTML; only permissions and the comment-return transport differ. Reuse Save JSON, return the file through the already authorized channel, reconcile the retained round and supply the revised report from the same approved surface. Bind decisions to the exact HTML digest and revision. A changed report needs a new revision and matching pending sidecar; preserve earlier rounds and do not silently transfer acceptance.

Offline packs prepare the review. External delivery additionally requires verified cloud-hosted HTML, actual recipient access, selected assets and durable comment return; a file-transfer or private-repository link alone does not prove that journey. Do not assume mandatory GitHub or ChatGPT signup. Hosting and return integration remain with the canonical viewer owner. Show the reviewer the report, options, comments and revised report; keep custody and technical receipts in the supporting evidence.

Reproduce the reports

Use the repository Python environment, repository src on the import path, and LLM_WIKI_PATH pointing to an authorized wiki checkout containing the matching standards metadata. No new paid standard is downloaded. The original released packs retain their historical numerical source baseline bf638ed1f6ad0b3fba12f0e6caf8eb4f5f004dd4. New builds record the full commit of the clean checkout actually executed; dirty checkouts and missing Git provenance are rejected before calculation. Known lazy routes are preloaded and checked; imported digitalmodel and CP reporting-helper module origins and committed source bytes are checked before and after report-file output. One source revision is pinned for the whole build; direct calls without the internal CLI revision pin reject preloaded implementation code. These checks cover repository source, not Python environment injection, ignored resources (including stale bytecode) or the private citation wiki's revision. Tracked non-Python resources are covered by the clean-checkout check; hidden-index flags are rejected under src and scripts/reporting, and frozen input fixtures have separate SHA-256 checks. These guards do not qualify a new engineering input or authorize a new numerical run.

Run PYTHONPATH=src python scripts/reporting/build_cp_review_portfolio.py --output outputs/cp-review-candidate with a new empty output directory. Windows environments whose editable installation shadows a worktree must run with the worktree source first and the conflicting editable finder removed.

The frozen input and document registers live beside the builder. Changed input bytes fail closed. Generation validates cited wiki frontmatter, preserves raw results, writes comments and checksums, and checks fixed S09/S10 component/phase coverage. The source adapter's B401:2021 citation-page mismatch is normalized only in this portfolio; original records remain in each pack. The reusable fix is tracked in issue 2284.

Agent review and privacy/fidelity checks precede an exact-artifact release register. Publication requires --publish-candidate and --release-register; an incomplete portfolio additionally requires the explicit --partial-review option. Publication revalidates the matrix, pack receipts, comments and child evidence. Existing changes or unlisted files stop replacement. Prior generations are preserved for recovery.

Known boundaries

S09's sequential wet-storage/operating ledger covers its sea family; the other installed families have their own component/family calculations. Compatibility aliases are edition variants, deprecated keys without report builders are excluded, and experimental ICCP/stray-current/galvanic and survey/depletion assessments are outside this structure-design portfolio.

The standalone packs repeat embedded Plotly to retain offline portability. Their combined size is about 30 MB. The proposed reporting conventions apply only to this requested portfolio; shared engine/template adoption is not implied.
