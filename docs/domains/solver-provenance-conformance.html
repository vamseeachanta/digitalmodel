Solver builder provenance conformance

Summary

The shared offline helper provides bounded traversal, strict bounded JSON loading and exact verification of caller-declared payload inventories. Synthetic adversarial tests establish refusal or explicit non-evaluation for the mutations below. Existing builders are inspected but are not migrated. No solver is invoked, no dataset is published, and no engineering result is qualified by this deliverable.

Sources and numerical basis

RFC 8259 (2017), sections 4, 6, 7, 8.1 and 9, supplies the JSON uniqueness, finite-number, string-escape, UTF-8 and implementation-limit basis. The public text was retrieved on 2026-10-19 with HTTP status 200. The implementation adopts refusal of duplicate names as a stricter interoperability policy.

No engineering equation, standards-derived coefficient or numerical design acceptance limit is introduced. All resource budgets are required caller inputs. Synthetic fixture counts are derived in test docstrings; they are not operating defaults. SHA-256 representation width is obtained from the digest implementation.

Trust boundary and later work

Verification establishes equality to the supplied pins and resolution of the supplied references at the time of the call. A consistently replaced package or a consistently omitted artifact can pass if the caller also changes its pins and reference map. Independent required-artifact selection and authentic pins remain mandatory caller responsibilities. Opaque payloads are not inspected for hidden references. Returned leaf containers are not retained snapshots.

The receipt explicitly marks inventory_completeness as NOT_EVALUATED; equality of supplied ID sets does not establish that every required source, derivative or emitted reference was supplied. JSON number spelling and arbitrary precision are not retained by decoding; raw source bytes must remain bound separately wherever lexical evidence is required.

Rights terms, including revocation, expiry and exclusions, remain NOT_EVALUATED, even when the rights record digest matches. Retention/reproducibility and engineering qualification also remain NOT_EVALUATED. No unknown rights field is interpreted as permission.

Later adapters will apply format-specific YAML parsing limits, closed rights schemas, independent required-payload sets, source retention and source-ID resolution, runtime parent/entrypoint inventories and post-call import evidence. Builders will be migrated individually with their existing physics and criteria preserved. This helper does not establish continuous process observation.
