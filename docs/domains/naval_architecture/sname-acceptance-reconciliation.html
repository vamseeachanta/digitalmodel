Status definitions

  • IMPLEMENTED: a callable implementation and the named regression assertions exist; no accuracy claim follows.
  • PARTIAL_DOCUMENTATION: method descriptions and callable docstrings exist; a complete API reference is not established.
  • UNMET: the evidence required by the criterion is absent from the inspected inputs.
  • NOT_EVALUATED: independent method or published-answer qualification has not been completed.
  • REPOSITORY_REGRESSION_ONLY: the existing test passes; source-answer and tolerance qualification remain incomplete, even where inputs match.
  • ALTERED_INPUT_REGRESSION: the existing test uses inputs different from the cited published example and cannot count as its reproduction.
