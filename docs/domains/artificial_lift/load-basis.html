Dynacard load basis analysis

Summary

The Gibbs comparison solver propagates position and applies an affine transformation to surface load. The result records downhole_load_basis.method = affine_surface_load and validation_status = NOT_EVALUATED. These restrictions appear in serialized results, CLI summaries and HTML diagnostic reports.

Method and sources

The implemented arithmetic is F_d = (F_s - W_b) a, with W_b = sum(L A rho / C) b. Rod length L is in feet, area A in square inches, density rho in pounds per cubic foot, and C converts square inches to square feet. Load is in pounds-force. This equation describes the existing code; it is not a qualified wave-equation load solution.

The source is the repository's physics.py buoyant adjustment and constants.py unit-conversion, material-property and legacy-calibration blocks (2026). The legacy inputs are rho = 490.0, C = 144.0, b = 0.825 and a = 0.88. Their presence in the repository establishes the executed arithmetic, not independent calibration evidence. No new coefficient is introduced.

Synthetic worked example

The chosen rod length is 100.0 ft and its diameter is sqrt(4/pi) in, giving an area of 1.0 square inch. The chosen pump diameter is 1.0 in, depth is 100.0 ft and speed is 1.0 stroke/min. The chosen surface samples are shown below. These are arithmetic inputs, not field measurements.

Independent substitution gives W = 100 × 1 × 490 / 144, or 340.3 lbf, and W_b = W × 0.825, or 280.7 lbf. Each answer is calculated using the unrounded intermediate values.

Qualification and way forward

NOT_EVALUATED: independent physical validation of the load transformation, buoyancy, attenuation, damping and stroke calibration is not established. Load morphology and absolute loads are unqualified; derived fillage, pressure, production, buckling and diagnoses inherit this limitation. Matching the arithmetic above does not establish physical accuracy.

Existing results without the new metadata deserialize with a null basis; null means unknown provenance, not validated load. Other solvers do not acquire a Gibbs load basis. A qualified load-propagation implementation will require an independent reference and documented calibration conditions.

For the defects tracked in issue 1952, fillage delegation, derived mode counting and fallback abstention were already implemented. This change addresses the remaining approximation disclosure.
