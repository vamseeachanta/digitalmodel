Worked example: constant pressure on planar patches

All following values are synthetic inputs or independent hand calculations. They are not measured data, design allowables or source values from a standard. The input is input.json; the executable is run_example.py.

NASA, Aerodynamic Forces (updated 2025), Variation in Pressure, supports pressure-area summation. With an outward area vector S and positive compressive pressure p, the patch force is F = −pS. OpenStax, University Physics Volume 1 (2016), section 10.6, equations 10.22 and 10.24, gives M = Σ((r − O) × F).

Input: p = 2.0 Pa; S = (0.0, 0.0, 3.0) m²
       r = (4.0, 5.0, 0.0) m; O = (0.0, 0.0, 0.0) m
Hand calculation:
       Fz = −2.0 × 3.0 = −6.0 N
       Mx = 5.0 × (−6.0) = −30.0 N·m
       My = −4.0 × (−6.0) = 24.0 N·m
       Fx = Fy = Mz = 0.0
Split mapping: two 1.5 m² patches at x = 3.0 m and 5.0 m, both y = 5.0 m
       Fz = −3.0 − 3.0 = −6.0 N
       My = 3.0 × 3.0 + 5.0 × 3.0 = 24.0 N·m
Shifted mapping: original patch moved to x = 5.0 m
       Fz = −6.0 N; My = 30.0 N·m; difference My = +6.0 N·m

PYTHONPATH=src python examples/ansys/pressure-transfer/run_example.py

The API accepts uniform pressure on planar patches using signed pressure, outward oriented area vectors, centroids and an explicit moment origin. Comparisons require the same frame and instantaneous-case identifier. Absolute component limits avoid division by a zero reference. Numeric limits and their criterion source are required inputs. Missing loads or criteria produce NOT_EVALUATED; nonfinite numbers and incompatible metadata are rejected.

Verification and limitations

tests/structural/test_pressure_transfer.py provides independent hand calculations for signed pressure, all force and moment components, a pure couple, an origin shift, subdivision, wrong lever arms and threshold boundaries. Negative tests cover missing criteria/evidence and invalid input. The example's output is checked against those hand calculations.

The comparison can detect a changed resultant and still miss a changed local distribution with the same resultant. Centroid quadrature is exact here only for constant pressure on a planar patch. Curved faces, nonuniform pressure, unit conversion, coordinate rotation, harmonic reconstruction and phase-offset calculation are not implemented. The caller's metadata does not authenticate a load case. No native solver, stress, mesh-convergence or physical comparator is exercised; this is not a full-chain validation.

Qualification sequence for later work

  1. The hydrodynamic basis will specify source geometry, mass, gravity, units, governing wave theory, EDW method, phase convention, components and signed extremes.
  2. The transfer case will define applicable release, supported mapping interface, transforms, reference origin, sampling plan and sourced force/moment criteria.
  3. A native comparator will retain source and mapped pressure readback, all resultants, mass/inertia settings and the signed structural equilibrium balance.
  4. A global-to-local comparator will reapply interior loads and compare recovered stresses, moved boundaries and an independently solved fine model.
  5. Engineering review will bind acceptance to the governing case and criteria; passing the offline arithmetic will not substitute for those comparators.

Reusable review checks

Cardinality restrictions do not establish load-case restrictions. Agreement of imposed values does not independently validate the boundary that imposes them. Force conservation alone does not establish moment conservation. Missing limits shall remain visible as NOT_EVALUATED. These checks apply to future transfer interfaces as well as this definition.
