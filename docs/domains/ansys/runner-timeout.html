MAPDL timeout and text encoding

Summary

The runner defaults to shared-memory mode and applies a finite wall-clock budget to the owned process tree. A timeout produces failed, retains partial output and fresh result evidence, and terminates the owned tree. Explicit UTF-8 example reads and writers remain independent of a cp1252 default.

Configuration and method

run_ansys and ANSYSRunConfig retain the existing timeout_seconds setting. It must be finite and positive. The -smp flag is inserted unless extra_args contains an explicit -smp, -dis, -mpi or -machines, matched without case sensitivity. Shared-memory and distributed flags together are rejected. Arguments must be a list of strings. Distributed execution is opt-in through extra_args=["-dis"] in Python or ansys.extra_args: ["-dis"] in workflow configuration.

Binary file-backed capture avoids waiting for a descendant to close an inherited pipe. The existing supervisors use a Windows Job Object, assigned before process resume, or a POSIX process group whose leader remains unreaped until settlement. The execution budget covers launch, leader wait and descendant settlement. After the leader exits, descendants receive at most the lesser of the remaining budget and 5.0 s. Descendants remaining after that grace cause a distinct failed settlement result that preserves the observed leader return code and terminates the owned tree. Failure cleanup has a separate 5.0 s grace period with 0.01 s polling. Both runners share these execution settings; they are not engineering acceptance limits. If cleanup remains uncertain, the result carries a retained_supervisor_token. Retry the exact owned handle with digitalmodel.ansys.runner_process.settle_retained(token); a successful retry releases it, and a failed retry retains the same token. Tokens are local to the calling process. Cleanup errors preserve timeout context, and control exceptions propagate after cleanup.

Completed streams are decoded as UTF-8 with replacement for invalid bytes. Timeout streams are retained as partial bytes and decoded by the runner using the same policy. Result completion still requires a fresh readable log, a successful return code, and absence of solver error markers. Timeout always overrides log contents; no successful exit code is invented after a timeout.

Offline worked example

Input: a synthetic Python parent and child that sleep for 60 s, a fatal log, and a 1.0 s execution budget. These durations are demonstration inputs. Method: the real runner and supervisors are exercised with a substituted command and executable discovery. Neither a solver nor a license service is queried. No engineering equation, material property or design limit is introduced.

PYTHONPATH=src python examples/ansys/runner_timeout.py <new-output-directory>

Answer:

{
  "status": "failed",
  "timeout_observed": true,
  "fatal_log_retained": true,
  "partial_output_retained": true
}

The regression test independently specifies this result from the completion contract and asserts that the recorded child process has terminated on either platform. The example refuses to overwrite its synthetic input. Its output directory must be retained for inspection or a fresh directory used for another run.

Encoding coverage

The padeye, mudmat and pressure-vessel committed-deck guards and their writers already select UTF-8. Regression tests invoke those existing guards while emulating a cp1252 default and Windows newline translation. The two deck writers explicitly use LF newlines; their bytes are compared to explicitly encoded UTF-8 text. No deck or engineering result is regenerated.

Known limits and next checkpoint

The offline tests do not qualify native Windows MPI behavior. A licensed environment must separately run a deliberately fatal deck, record timeout and owned-process settlement, and retain the native log before that behavior is qualified. Fatal logs are inspected after execution or timeout, rather than triggering immediate cancellation. POSIX children that deliberately create a new session escape process-group containment. The current supervisors refuse platforms without the required unreaped-leader support.
