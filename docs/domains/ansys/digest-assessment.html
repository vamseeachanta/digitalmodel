ANSYS supported-load digest assessment

Summary

The production digest reader rejects incomplete, repeated and nonfinite evidence. An offline supported-load assessment compares stress, utilization and signed in-plane forces with explicit independent inputs. The synthetic worked case passes these content checks: utilization is 0.6 and the force residual is 0.0 N against a 1.0 N input criterion. Native qualification remains NOT_EVALUATED.

Scope and method

Issue 2094 records that matching a deck to its generator establishes reproducibility without establishing physical correctness. The existing base already removes the pressure-vessel radial restraint, replaces the inert mudmat foundation construction, captures CSV files and retains historical goldens. This change addresses the remaining permissive production reader and provides a callable assessment for the supported in-plane digest convention.

The API is assess_supported_digest(csv_text, criteria) in screening_validation.py. Every allowable, yield strength, applied force, tolerance and source is required. No standard-derived allowable or acceptance tolerance is supplied by the API. The source string declares the input basis; it does not authenticate that basis.

Field labels are normalized to lowercase. Each row contains complete label,value pairs. Blank fields, duplicate labels ignoring case, empty digests, invalid labels, nonnumeric values and nonfinite values raise ValueError. Unknown well-formed fields remain available to callers. Missing assessment quantities produce NOT_EVALUATED for the affected checks. A known failure takes precedence over missing evidence.

Independent calculation and answer

Utilization is defined by the screening deck as peak stress divided by allowable stress. The sub-yield and below-unity criteria follow the example requirements in issue 2094, recorded in 2026. The independent allowable is used in the calculation, so a changed digest allowable cannot silently redefine its own acceptance.

UC = 60.0 / 100.0 = 0.6
60.0 MPa < 100.0 MPa allowable and < 200.0 MPa yield
Applied-vector error = norm((300.0, 400.0) - (300.0, 400.0)) = 0.0 N
Force residual = sqrt((300.0 - 300.0)^2 + (400.0 - 400.0)^2) = 0.0 N
0.0 N <= 1.0 N criterion
Recorded residual = 0.0 N; difference from calculated residual = 0.0 N

Signed force equilibrium follows Engineering Statics: Open and Interactive, online edition consulted in 2026, section 5.3, equation 5.3.1: the vector sum of external forces is zero. The assessment uses the Euclidean norm of the two signed residual components. Recorded applied forces are checked separately against the independent case, so a wrong load balanced by a wrong reaction still fails. The recorded residual is checked against the independently calculated norm.

The executable example is build.py:

PYTHONPATH=src python examples/ansys/digest-assessment/build.py

The output contains five PASS content dispositions and native_qualification: NOT_EVALUATED. The example writes no files and does not start a solver.

Verification and known limits

The regression tests include independent hand answers for equilibrium, utilization and tolerance boundaries. Negative cases include a reversed reaction, a 3.0 N / 4.0 N component imbalance giving a 5.0 N residual, balanced wrong loads, changed allowables, duplicate labels, missing fields and nonfinite evidence. Golden readers share the production parser, while their independent physical comparators remain separate.

This assessment checks content only. It does not bind a digest to an executed deck, authenticate provenance, establish solver completion, prove mesh convergence, check moments or out-of-plane forces, or qualify padeye contact stresses. The pressure-vessel and mudmat self-balanced conventions are outside this API and continue to use their existing golden checks. No committed deck, retained native evidence, golden value or registry readiness is changed. Current native qualification and the outstanding physical comparators remain open under issue 2094.
