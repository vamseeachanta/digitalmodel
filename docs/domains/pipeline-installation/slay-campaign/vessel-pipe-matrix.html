Vessel and pipe-size matrix plan

Summary

A small anchor design will compare public-data vessel classes and pipe-size ranges before adding only the marginal native runs required by the next decision. The method choice will be a bounded, piecewise-linear response surface with held-out residual evidence and decision intervals. Capability results are Not Evaluated: public hull dimensions do not establish installation capacity, and missing support, tension or motion data will block the affected anchor.

Installation quantities and features

Each class will be modelled separately; vessel class will not be treated as a continuous size axis. Within each class, the features will be pipe outside diameter, wall/diameter ratio, submerged weight, water depth, effective tension/capacity, stinger radius and exit angle. Qualified motion inputs will be required before any environmental extension. LOA alone will not substitute for an RAO or a tensioner.

Error bound and marginal-run method

Method choice: within each qualified vessel class and fixed parameter slice, a piecewise-linear response surface will interpolate between solved anchors in diameter/depth/tension space. Cross-class interpolation and extrapolation will be prohibited. Every input, output, source revision, criteria revision and model digest will be retained so that source or criterion changes invalidate reuse. Contact-state changes will partition the response domain rather than be smoothed across.

For quantity j, the empirical error allowance E_j will equal the maximum absolute prediction residual on independent held-out cases in the same regime, plus the largest declared numerical and extraction uncertainty U_j: E_j = max |q_j − qhat_j| + U_j. The decision interval will be [qhat_j − E_j, qhat_j + E_j]. Leave-one-out residuals will diagnose anchor inadequacy but will not replace independent validation. With no held-out result or no U_j, the error allowance will be unknown and reuse will be refused. This will be an empirical allowance over the tested domain, not a certified global probabilistic bound.

If a decision requires a guaranteed bound, a validated bound L_j on the response gradient over the same regime will also be required. At distance d from a verified anchor, the nearest-anchor interval will be q_anchor ± (L_j d + U_j). L_j will require independent justification; it will not be inferred from a few observed slopes and called a guarantee. Without that evidence, a native run at the proposed decision point will be required.

A new decision will first check source freshness, feature-domain inclusion, regime, criteria, qualified input properties and the error allowance. Only ambiguous governing quantities will trigger new runs. The next native case will be selected at the candidate nearest the decision boundary with the widest uncertainty interval; unresolved contact transitions and missing equipment data will take priority over fitting more smooth points. The new result will be retained as an anchor only after native read-back, mesh convergence and held-out comparison; failure will remain visible.

Stopping rule and acceptance assessment

The stopping rule will be decision separation: stop adding marginal cases when every applicable upper-demand interval is below its declared limit, every required lower-demand interval is above its limit, input qualification is complete and the validated regime covers the next decision. An interval crossing a limit will require another native run or a documented unresolved decision. An interval wholly exceeding a criterion will reject that candidate, rather than seek favorable additional runs. A missing criterion or bound will yield Not Evaluated. No fixed run budget will override those conditions.

Way forward

Qualify missing capacities, supports and motion data before launching affected anchors; complete the generic topology and canary first. Run qualified anchors serially, reserve independent validation cases, compare the trend quantities and record the tested domain. The next pipe/vessel decision will then reuse only qualified evidence and will add the marginal cases dictated by the stopping rule.
