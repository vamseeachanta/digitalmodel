Method and comparison basis

Difference (%) = (computed frequency − published frequency) / published frequency × 100.

Pairing is by ascending frequency within the same direction class where recorded. Classified targets reserve matching modes first; remaining slots pair with remaining computed modes in ascending frequency. Missing published slots consume ranks. Equal computed frequencies use mode number as tie-break. Missing direction is not guessed. This rank-based convention is not mode-shape correlation or proof of modal identity.

A missing computed match is labelled “not computed”. A missing reference remains “not held in the repository”, with no percentage calculated. The full spectrum from mode 1 is required; gaps in the exported computed spectrum can invalidate rank pairing. Extra computed modes are outside the target table.

Canonical inputs: target table with citations, line locators and source digests. Source digests use UTF-8 text with LF newlines, so checkout newline conversion does not alter the comparison basis.

Preconditions and recorded execution

Request at least 4 modes for mj01, at least 1 for mj02 (extend until its first out-of-plane mode is captured), and at least 13 for mj03, with directions established from the jumper plane. Export all modes from the first, including those without published frequencies. The issue estimates about 6 solves: statics and modal analysis for each model.

The stored JSON interface is one object with model (mj01/mj02/mj03), synthetic (boolean), and modes (list of mode, frequency_hz, optional direction). The existing modal module records zero-based modeIndex and period. An exporter will provide positive mode identifiers and frequency in hertz from reciprocal period in seconds; raw DOF labels do not establish in-plane/out-of-plane direction without the model coordinate basis.

Rank-pairing caveat

Pairing is by ascending frequency within a direction class; a swapped pair of close modes is not detected. The closest target pair is mj01 modes 2 and 3, with relative spacing 2.094% ((2.194 - 2.149) / 2.149 * 100). Phase B therefore confirms each pairing from the mode shape and direction before a difference is read.
