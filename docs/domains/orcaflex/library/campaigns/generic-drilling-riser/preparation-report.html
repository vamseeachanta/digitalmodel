Analytical method and sources

The existing stack-up screen computes submerged column weight and an assumed top tension. The pinned constant-tension beam solves EI y'''' − T y'' = q with zero end moments and specified end offset. Axial-plus-bending stress is T/A + |M|D/(2I). Geometric extension is sqrt(L² + X²) − L. These are analytical screen equations; no new engineering constant or acceptance limit is introduced.

Orcina WebHelp, Line theory: Hydrodynamic and aerodynamic loads, Drag (accessed 2026-10-20): https://www.orcina.com/webhelp/OrcaFlex/Content/html/Linetheory,Hydrodynamicandaerodynamicloads.htm. The normal drag term reduces to q = rho Cd D U² / 2 per unit length for steady transverse flow. This source supplies the equation, not a drag coefficient.

Orcina WebHelp, General data: Statics (accessed 2026-10-20): https://www.orcina.com/webhelp/OrcaFlex/Content/html/Generaldata,Statics.htm. Static equilibrium is iterative; YAML validation cannot establish equilibrium or dynamic adequacy.

MIT OpenCourseWare, Structural Mechanics (2013), Lecture 6, equations (6.4)–(6.6): constant axial force, transverse equilibrium and moment-curvature relation give the tensioned-beam equation. Lecture 4, equation (4.30): sigma = N/A + Mz/I; set z = D/2 at the outer fibre for the reported stress screen. https://ocw.mit.edu/courses/2-080j-structural-mechanics-fall-2013/pages/lecture-notes/ (accessed 2026-10-20). Chord extension follows directly from the Pythagorean theorem, as written out in the worked example.

Input geometry, densities, stiffness and drag coefficient: docs/domains/orcaflex/library/templates/drilling_riser/spec.yml. Case coordinates and assumed load grid: case-table.yml, cases and basis. Numerical screen outputs: screens/column-screen.csv; identity: screens/basis.json. Equations and boundary conditions: src/digitalmodel/drilling_riser/riser_response.py, section.py and stackup.py; preparation adapter: generic_campaign.py. The constant-tension screen is an analytical model assumption, not a code criterion.

The connected drilling model and the running-BOP model were inspected as context. Running BOP is a different operation; its results are not a connected-mode reference. Unqualified drilling-model groups are excluded.
