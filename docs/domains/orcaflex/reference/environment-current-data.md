## Current models

Named current sets support load-case preparation, with one set active per model.
The variation-scheme model describes simple profiles; tabular input permits
more flexible fields, including acceleration. Ramping controls how current
enters statics and dynamic build-up. Vertical stretching maps a nominal-depth
profile onto the local water column; its applicability depends on the chosen
variation scheme. Consult the source before selecting these options.

See the [source topic](https://www.orcina.com/webhelp/OrcaFlex/Content/html/Environment,Currentdata.htm) for equations, figures and detailed procedures.
