## Sea properties

The sea-surface setting locates mean water level on the global Z axis.
Kinematic viscosity can be fixed or temperature-dependent; temperature can
be fixed or depth-dependent. These choices affect Reynolds number and any
line drag or lift coefficients defined as Reynolds-dependent.
Select the Reynolds-number convention to match the coefficient data source;
the help distinguishes nominal, cross-flow and flow-direction conventions.

See the [source topic](https://www.orcina.com/webhelp/OrcaFlex/Content/html/Environment,Seadata.htm) for equations, figures and detailed procedures.
