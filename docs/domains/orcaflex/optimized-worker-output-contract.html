Optimized worker output contract

The optimized V2 worker refuses native execution when the interface is unavailable. Regression artifacts require the boolean setting mock_mode=True and carry separate status, directory, filename and content markers. A regression completion does not establish that a native simulation has run.

Scope and sources

This contract applies to process_single_file_worker and OrcaFlexOptimizedParallelAnalysis in the optimized V2 module. The refusal criterion comes from issue 2521 (2026). The marking convention comes from core/mock_artifacts.py. The implementation is already present; this document and example do not change native execution.

The contract tests state expected paths, marker text and independent hand counts. No engineering equations, constants, coefficients or numerical acceptance limits are introduced.

mock_mode defaults to false and is checked as a boolean. Explicit true bypasses native execution even when an interface is available. save_sim defaults to true; save_dat defaults to false. With both disabled, a mock request can complete with an empty output list.

For input model.dat and configured output directory results, mock outputs are results_mock/model.mock.sim and, when enabled, results_mock/model_processed.mock.dat. Their content starts with Mock simulation for model.dat. Without an output directory setting, a sibling of the input directory receives the _mock suffix. The input and native output paths are preserved.

Batch successful counts only status success; mock_successful counts only status mock_success; failed counts failed or exceptional requests. Consumers that previously treated mock results as native successes shall read the separate mock counter.

Worked example: inputs, method and answer

The executable example creates two synthetic files, first.dat and second.dat, each containing Synthetic regression input; not a native model. and a newline. They are test fixtures and contain no engineering inputs.

A new directory is supplied by the caller. Existing directories are refused to preserve their contents. From the repository root, with dependencies installed and a new directory selected outside the checkout, the example is run as follows:

PYTHONPATH=src python examples/orcaflex/optimized_worker_contract.py "$EXAMPLE_DIR"

Before importing the worker, the example blocks the native binding with an isolated test double. A previously loaded native-enabled worker is refused. The first batch omits mock opt-in. The second batch explicitly sets mock_mode=True and enables both save types. Each batch uses one thread, selected only to bound demonstration resources. Every reported regression file is read back and checked for its marker.

Independent hand count: the two requests without an interface give zero native completions, zero mock completions and two failures. The two explicit mock requests give zero native completions, two mock completions and zero failures. Two inputs multiplied by two enabled output types give four marked artifacts. These counts follow the issue's software contract; no physical result is calculated.

The JSON payload is printed after RESULT:; timing and diagnostics are omitted from the answer. Paths in the answer are relative to the example directory.

Limits and next use

Native simulation validity is not established by these fixtures. Mock artifacts shall not be used as solver results. A native save returning without a file is rejected; file existence alone does not establish freshness, convergence or numerical validity. Native execution and process-pool startup require separate integration evidence.

The earlier optimized module without the V2 suffix is a separate implementation and is outside this document's coverage. These tests do not establish equivalent behavior for that implementation or other runner entry points.
