One-case installation reproduction

Engineering scope: Installation analysis end-to-end. The first workflow will reproduce one unchanged archival AHC-off model. The configuration will freeze the source by SHA-256 and will use existing digitalmodel solver, extraction, provenance and report components.

Execution

A Windows host with a licensed OrcaFlex installation and the digitalmodel environment will run the following from the repository root. The output directory will be new for each solver execution.

python -m digitalmodel.workflows.orcaflex_reproduce examples/orcaflex/installation_reproduce.yml --output OUTPUT_DIRECTORY

A failed extraction will be retried against the fingerprinted saved simulation, without another solver run:

python -m digitalmodel.workflows.orcaflex_reproduce examples/orcaflex/installation_reproduce.yml --output OUTPUT_DIRECTORY --postprocess-only

Engineering limits

The 21-second case will include 10 seconds of build-up and 11 seconds of subsequent response. The regular wave height will be 2 m, not significant wave height. AHC will remain off and payout will remain zero. The result will be a diagnostic reproduction; it will not establish steady-state statistics, a weather envelope, compensation performance or live operations readiness.

Allowable tensions, stress criteria and measured validation evidence are not established. Engineering acceptance will remain NOT EVALUATED. The next review will compare the source, solver warnings, completeness checks and demand plots before defining any longer run or recorded-measurement replay. No physics change or second solver case will be automatic.

Reproducibility

The run directory will retain request.yml, the source snapshot, generated batch input, solver.log, batch summary, saved simulation, run.json, provenance and extracted outputs. The receipt will identify the code and model. Outputs will remain local engineering evidence until their owning repository and publication scope are approved.

The workflow will run from a Git checkout with a standalone monolithic model; dependency-based models will require a separately reviewed flattened source. This version will extract line End A/B histories and range graphs in SI units. Requested history endpoints will fall on saved sample times. Each postprocessing retry will write a separate extraction directory and preserve the original report. Solver warnings will appear in the HTML.
