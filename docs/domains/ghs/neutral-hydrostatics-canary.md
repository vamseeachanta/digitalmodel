# Neutral GHS hydrostatics canary

[Issue 2089](https://github.com/vamseeachanta/digitalmodel/issues/2089) will remain open until a genuine licensed run and its independently reviewed comparison are retained.

## Milestone 1

The Milestone 1 library prepares a deterministic input packet, previews a separately supplied approval receipt, exercises capture with synthetic process doubles, and compares normalized assertions against an independent box oracle. A preview will not qualify geometry, authenticate an operator, launch GHS or parse an assumed native report format. Receipt preview will not issue approval or consume a run nonce.

## Independent analytical case

The synthetic hull is an ideal rectangular box: length 20 m, beam 10 m, depth 4 m. The normalized origin is at the aft end, centreplane and baseline; x is forward, y port and z upward. Actual native stations, closure and native-to-normalized transforms will require separate qualification before a licensed run.

The artificial density is 1000 kg/m3, a test parameter rather than a measured fluid property. It is not the numeric argument to GHS WATER: the command's specific-gravity reference will require version-matched qualification.

For immersion T: volume V=LBT; mass=rho*V/1000 tonnes; waterplane area A=LB; KB=T/2. Rectangular waterplane second moments are LB^3/12 about the longitudinal axis and BL^3/12 about the transverse axis. Dividing by V gives transverse and longitudinal BM respectively. These geometric integrals are independent of the native parser and existing stability-screening solver.

| T (m) | V (m3) | Mass (t) | A (m2) | KB (m) | BMT (m) | BML (m) |
|---|---|---|---|---|---|---|
| 1 | 200 | 200 | 200 | 1/2 | 25/3 | 100/3 |
| 2 | 400 | 400 | 200 | 1 | 25/6 | 50/3 |
| 3 | 600 | 600 | 200 | 3/2 | 25/9 | 100/9 |

LCB and LCF are 10 m in this normalized frame; TCB and TCF are 0 m. Native GHS signs must not be assumed to match. Native KM cannot be treated as BM; a KM-KB derivation needs qualified axis/unit semantics and locators for both operands.

The approved canary rule is absolute error <= max(0.001*abs(expected), absolute floor). Floors are 0.005 m for coordinates/BM, 0.01 m2 for area, 0.1 m3 for volume and 0.1 tonne for mass. These are canary tolerances, not regulatory limits or vendor accuracy guarantees. Unsupported output precision must reject rather than widen them.

## Evidence and conclusions

Comparison requires all three depths, all ten quantities, matching units/frame and source-hash/locator references. A normalized row remains an assertion until native source, parser profile and transforms are qualified. A hash establishes content identity, not engineering truth or employee authority.

Agreement with this oracle cannot establish equilibrium, GM/GZ criteria, damage stability, loading suitability, certification or applicability to a project vessel. A passing synthetic comparison cannot populate an approved engineering lookup table.

## Run the synthetic example

The [replay script](../../../scripts/review/results/issue-2089/replay-synthetic-example.py) exercises preparation, receipt preview, exclusive staging, injected capture events and comparison. It supplies independent fixed numerical assertions, not values generated by the production oracle. Its input geometry is explicitly a text placeholder, not a native hull.

From the repository root, use the project's configured environment, or this isolated rehearsal environment:

```bash
PYTHONPATH=src uv run --no-project --python 3.11 --with numpy==2.4.4 --with scipy==1.17.1 --with pyyaml==6.0.3 --with loguru==0.7.3 python scripts/review/results/issue-2089/replay-synthetic-example.py
```

The numerical implementation uses the standard library. These additional packages satisfy existing eager imports from the parent solver package; this command is not a claim to resolve the full project environment.

The script writes explicitly named synthetic evidence beside itself and an [HTML comparison](2026-09-11-m1-synthetic.html). It uses a temporary staging directory and removes it after capture simulation. The configured Windows argument paths are synthetic test values; portable staging does not prove those paths match a real executable's working directory.

The public API lives in `digitalmodel.solvers.ghs.contracts`, `.runner` and `.comparison`. `prepare_canary` binds request, runtime profile, output policy and supplied bytes. `validate_packet` rebuilds their identities; `preview_approval` only checks receipt consistency. `run_synthetic_capture` accepts a trusted injected test backend; `run_approved_capture` always raises while live prerequisites remain unqualified. `compare_normalized` accepts only synthetic evidence and returns an unreviewed comparison with explicit limitations.

A zero-return-code event is never native completion evidence. Capture remains `capture_unqualified` or `capture_failed`; even `comparison_passed_unreviewed` has `licensed_execution_verified=false`. No live approval receipt, atomic nonce reservation, Windows ACL verification, wall-clock containment or native parser is implemented by this milestone.

## Qualification limits of the synthetic seam

The containment_qualified field is always false. On Windows, the standard-library open path has no O_NOFOLLOW flag; before/after reparse and file-identity checks are observational, not an atomic hostile-writer race guarantee. The synthetic seam is for trusted, owned test directories. A qualified Windows open/ACL/Job Object implementation remains a live-execution prerequisite; no fallback promotes synthetic evidence to a contained run.

Runtime paths are validated lexically and compared after Windows case/path normalization. A trailing separator on a distinct directory is valid; the contract does not claim a unique canonical spelling or resolve every physical NTFS alias. Those physical identities require the later host preflight.

The box height of 4 m is a declared case assumption. All three test immersions are below that top; hydrostatics at those depths do not measure total height or certify closure. Source line references use a coarse maximum of byte_count+1 LF slots, allowing the final empty slot after a terminal newline. They do not verify actual line contents; native format qualification must ground each locator.

## Windows sentinel qualification

The separate containment addendum authorizes a fixed-purpose experiment with harmless Python processes. Its public entry point is qualification.qualify(output_root, profile=None); it accepts a fresh output directory and the fixed qualification timing profile, never a solver executable, arbitrary script or command string.

Qualification observes normal parent exit, timeout, controller death before and after resume, attempted breakaway, unrelated-process survival, a deliberately retained second job handle, and abnormal child exit. A successful experiment is labeled sentinel_containment_passed; it leaves licensed_execution_verified and ghs_launch_allowed false. It does not change the existing synthetic containment_qualified field or enable run_approved_capture.

The experiment persists a single-flight attempt marker in the current user's local application-data namespace, independent of output directory. An unresolved attempt blocks another invocation. Do not delete an unresolved marker to retry: establish the complete owned process identities and their termination first. A never-resumed process has no executing watchdog, and an incomplete identity record cannot prove that no process launched.

Native observations apply to the recorded helper/sentinel/interpreter hashes and Windows/account/job context. Linux injected tests do not qualify Windows, and a saved qualification result is not an approval credential. Vendor helper behavior, usable entitlement, diagnostic capture, trusted approval storage and reviewed geometry remain requirements of the later licensed capture packet.

Raw qualification evidence stays in the operator's private output location. Only the allowlisted public_summary representation is suitable for review as source-neutral evidence; raw paths, process identities and account details must not be copied into public reports.
