Scour screening analysis

Summary

The scour APIs assess a supplied sediment-motion basis and armour comparison criterion. A nonzero pipeline or monopile scour depth remains NOT_EVALUATED because a qualified depth model is not established. The worked example gives a critical mean current of 1.2 m/s and an armour velocity number of 1.5, above the supplied limit of 1.0. The armour comparison therefore fails; the grading or loading requires revision before a protection design can be assessed. Inputs are synthetic arithmetic examples, not design data.

Method and reference qualification

FHWA-RD-03-052, Field Observations and Evaluations of Streambed Scour at Bridges (May 2005), chapter 5, equation 3 gives the Neill/Shields mean-current threshold in SI: Ucrit = 31.08 sqrt(theta_cr) h^(1/6) d50^(1/3). Grain size is converted from millimetres at the API boundary to metres in this equation; depth is in metres and the answer in metres per second. The coefficient is tied to the published SI relation, not a universal material law. The Shields parameter is required input; no temperature-specific or sediment-specific default is supplied. The caller must qualify this steady, noncohesive approach-flow relation for the sediment and fluid being assessed. Cohesive sediment and wave motion are excluded.

The separate critical_sediment_motion helper returns shear stress and shear velocity using USACE, HEC-RAS 2D Sediment Technical Reference Manual, version 6.4.1 (2023), section 2.14.1 equation 132 and section 2.13.1 following equation 111. Its shear velocity is distinct from a depth-averaged current. Below-threshold approach flow does not exclude local clear-water scour at a pile or pipeline.

The public scope of DNV-RP-F107, Risk assessment of pipeline protection, edition 2019-09 amended 2021-09 addresses accidental interference. It does not establish the removed scour curves. DNV-RP-0618, Rock scour protection for monopiles, edition 2022-09 addresses rock protection design; its licensed calculation clauses have not been verified here. No DNV compliance, calibrated depth, universal rock limit or minimum layer thickness is claimed. No value from a licensed publication is reproduced.

Independent threshold calculation: sqrt(0.04) = 0.2, 64^(1/6) = 2 and 0.001^(1/3) = 0.1. Multiplying these factors by the cited SI coefficient gives a critical current reported as 1.2 m/s. The tests preserve the unrounded multiplication. Both approach currents are below the unrounded threshold, so current motion is BELOW_THRESHOLD. Pipeline KC = 0.2 × 10 / 0.5 = 4.0 and current fraction 0.8 / (0.8 + 0.2) = 0.8 are diagnostics only. Both scour depths are null, with NOT_EVALUATED status.

The dimensionless armour velocity is defined by Ns = U / sqrt(g d50 (rho_rock / rho_water − 1)). For the supplied values the denominator is sqrt(10 × 0.4 × 1) = 2, and Ns = 3 / 2 = 1.5. The comparison Ns <= stability_limit fails against 1.0. This limit is a synthetic input, not a recommendation. Nominal layer geometry is 3 × 0.4 = 1.2 m; it is reported even when the stability comparison fails and shall not be interpreted as a required protection thickness.

from digitalmodel.geotechnical.scour import monopile_scour_depth

result = monopile_scour_depth(
    pile_diameter_m=6.0, current_velocity_ms=1.0, water_depth_m=64.0,
    sediment_d50_mm=1.0, critical_shields_parameter=0.04,
)
assert result.sediment_motion_status == "BELOW_THRESHOLD"
assert result.scour_depth_m is None
assert result.status == "NOT_EVALUATED"

API changes and remaining qualification

Existing positional arguments remain accepted. Nonzero depth results now use None (JSON null) with a reason, replacing unsupported numbers. At zero current and zero wave velocity, the narrow hydrodynamic result is zero scour with NO_FLOW status; this does not establish historical scour or future loading. Missing motion inputs are named. Magnitudes, dimensions and supplied criteria reject invalid or nonfinite values before zero-flow handling.

The wave period is explicit when wave diagnostics are required. The optional armour inputs are gravity_ms2, stability_limit and layer_count. Omitted inputs remain unevaluated. A supplied limit compares only the displayed dimensionless velocity number on a matching velocity basis. Even stability_status=PASS leaves the full design status=NOT_EVALUATED. Filters, grading, placement, wave action, edge scour, geotechnical response and service loading are not assessed.

Further work requires a qualified pipeline and pile depth model with its calibration domain, independently transcribed published cases, and a protection design basis specifying the applicable stability criterion and layer geometry. Synthetic tests establish arithmetic and missing-basis behavior; agreement with measured scour is not established. Historical reporting examples containing the old depth values are not qualification evidence for this API.
