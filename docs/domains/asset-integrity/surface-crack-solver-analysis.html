Worked example: inputs, method and answer

The existing synthetic plate has a = c = 5 mm, thickness = 10.000 mm, half-width = 25 mm, half-length = 25 mm and tensile membrane stress = 100 MPa. These are research inputs from surface_crack_post.py, not measured data. The recorded material inputs are E = 210000 MPa and Poisson ratio = 0.3; K for this prescribed traction reference does not use those elastic constants. Bending is zero.

NASA TM-83200 (1981), pp. 4, 7, 12, Eqs. (2a), (10)-(11), (16)-(21), supplies the finite-plate surface-flaw tension solution. With a/c = 1 and a/t = 0.5, Q = 2.464, M1 = 1.04, M2 = -0.54 + 0.89/1.2, M3 = 0.5 - 1/1.65. The finite-width factor is sqrt(sec(pi*sqrt(0.5)/10)). The deepest-point K is 100*(M1 + M2/4 + M3/16)*fw*sqrt(pi*0.005/Q), giving 8.8 MPa sqrt(m). The surface multiplier g is 1 + 0.1 + 0.35*(0.5)^2, giving 10.4 MPa sqrt(m). The test docstring records the independent arithmetic with unrounded values.

The finest recorded deepest K is 7.7 MPa sqrt(m). Signed relative difference is defined as 100*(candidate-reference)/reference and is computed before rounding: -11.9%. The surface difference is -6.7%. Every front station is recomputed against the existing reference implementation; cached differences and reference columns in the old receipt are not trusted.

Recommendation and way forward

The present CalculiX extrapolation route should remain research-only. Code_Aster CALC_G should be investigated next using the identical geometry, loading, material and front-angle convention. Solver choice remains NOT_EVALUATED until native readback establishes front coverage, mesh refinement and integration-domain sensitivity against a predeclared research comparator. The free-surface endpoint requires separate interpretation from interior front points. J inferred from K would only be an elastic identity, not an independent contour check.

No API 579 qualification, plastic-J accuracy, mixed-mode validity, toughness margin, weld applicability or licensed-solver agreement is established. The linked licensed comparison is not a matching plate benchmark and requires a common case and input basis before comparison. No go verdict or follow-on issue is issued.
