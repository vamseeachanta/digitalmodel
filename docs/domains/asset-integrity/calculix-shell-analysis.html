CalculiX shell analysis interfaces

Summary

The writer, result parser and FEM chain provide shell input and output contracts for the shell extension tracked in issue 2173. Native tests compare an elastic shell patch with its hand calculation, read a nonlinear plastic patch through its final converged increment, and compare a beam buckling factor with both an analytical reference and the in-repository beam solver. These comparisons do not establish shell collapse capacity.

Inputs and method

Coordinates, section thickness, stress, modulus, pressure, density and gravity use one caller-selected consistent unit system. The writer performs no unit conversion. Connectivity and sets use dense zero-based indices; exported deck identifiers start at one. External geometry providers shall map their original node tags before calling FEMChain.set_mesh. Element IDs follow the insertion order of element families and connectivity rows.

Hydrostatic equilibrium is derived from the vertical force balance on a fluid column: dp/dz = -rho*g. With zero gauge pressure at the surface, p = rho*g*max(z_surface-z_centroid, 0). For synthetic inputs rho=2, g=5, z_surface=3, z_centroid=1, pressure is 20 consistent pressure units. A dry centroid at elevation 4 has zero pressure. No gravity constant is built into the interface. This discretization requires refinement at the free surface and is not an exact linearly varying face load. Elevations do not identify the fluid side: orient shell connectivity so the positive normal points away from the fluid, or reverse connectivity for the opposite side. Signed pressures can instead be supplied through add_pressure.

BCs and loads added after a step belong to that step's deck block. Calls before the first step are transferred into it. CalculiX retains loads and constraints between static steps according to its own replacement rules; an empty later step does not unload the structure. Geometric nonlinearity also persists until explicitly disabled (manual section 7.124, STEP NLGEOM clause); the writer emits NLGEOM=NO when a later static step requests nlgeom=False, including after an intervening buckling step. A buckling perturbation flag is explicit. The load multiplier applies to the buckling step load, with any preload treated according to manual section 7.5.

Worked example: membrane patch

The executable example is examples/calculix/shell_patch.py. The default input is a unit-square shell, thickness 0.100 mm, synthetic modulus 1000 MPa and zero Poisson ratio. Its left edge is fixed in x; its right edge is displaced 0.01 mm. Out-of-plane motion is restrained. No material grade or design allowable is represented by these inputs.

PYTHONPATH=src python examples/calculix/shell_patch.py ../analysis-output
cd ../analysis-output
ccx -i patch

The method is a small-strain uniaxial membrane patch. With zero transverse coupling, epsilon_x=delta/L and sigma_x=E*epsilon_x (linear elasticity, manual section 6.8.1). The independent answer is axial stress 10.0 MPa and axial strain 1.0 %. The native S4 result is 10.0 MPa at the display precision; the full-precision stress differs by less than the test's relative tolerance of 1e-4. That tolerance is a numerical test criterion.

A second native case sets displacement to 0.02 mm, enables NLGEOM, and uses synthetic plastic rows (10 MPa, zero strain) and (20 MPa, 0.1 strain). Its kinematic reference is the Green-Lagrange axial component E_xx = ((1+delta/L)^2-1)/2, obtained from E=(F^T F-identity)/2. The result is 2.0 % at the display precision; the test evaluates the unrounded expression. Plastic strain is positive and the final converged step time is 1.0. This verifies field and increment readback; it is not a constitutive-model or strain-limit qualification.

The existing FFS library supplies the plastic table without another material model: writer.add_plasticity("MAT", curve.plastic_table()), where curve is a TrueStressStrainCurve. Its modulus is in MPa; the analysis shall use MPa or convert the stresses before passing the table. Library applicability and source qualification remain the caller's responsibility.

Buckling overlap

The pinned-column test uses synthetic modulus 1000, square side 1, length 100 and compressive reference force 0.01 in a consistent unit system. Integration over the square gives I=b*h^3/12=1/12. Substitution of w=sin(pi*x/L) into EI*w''''+P*w''=0 gives P_cr=pi^2*EI/L^2. Dividing by the reference force gives the expected factor 5*pi^2/6. This is also the reference used by structural/fe/elastic_buckling_workflow.py.

The native 20-element B31 factor and the reference both round to 8.2. The unrounded comparison is within 1.0 %, the explicit numerical test criterion. The same deck is compared with the repository's beam eigen-solver within 1.0 %. This is a beam overlap check; no cylinder or ring shell buckling result is inferred from it.

Result meaning and limits

  • FRD fields include displacement, stress, TOSTRAIN and PE/PEEQ. Principal strains are eigenvalues of the symmetric tensor, sorted greatest first; shear components are tensor components, following manual section 6, equations (2)-(3): E_KL = (U_K,L + U_L,K + U_M,K*U_M,L)/2, with the quadratic term omitted in a linear analysis. Thus simple shear u_x=gamma*y gives E_xy=gamma/2. Section 7.51 identifies the output field. For incremental plasticity TOSTRAIN is total Lagrangian strain, not logarithmic strain or equivalent plastic strain.
  • FRD output is nodal extrapolated output. Each returned field is its latest complete block; fields are not asserted to share a time or increment. Truncated supported blocks and missing field labels raise ValueError. Expanded shell node IDs are retained and shall not be interpreted as indices into the original midsurface mesh.
  • DAT parsing preserves signed mode factors and excludes frequency eigenvalue tables. Multiple buckling tables are flattened in file order; no step association is supplied. Reaction data remain available.
  • STA parsing identifies unsuccessful attempts and the last converged increment. An empty history returns no converged increment. Its collapse status remains NOT_EVALUATED; neither convergence nor failure establishes physical collapse. FEM chain status includes parse_status=OK for a readable history. If STA parsing raises ValueError, status instead contains parse_status=ERROR, an error message and collapse_status=NOT_EVALUATED, with no convergence history. FRD and DAT fields remain available. A missing STA file still yields no status.

Riks/arc-length requests raise an explicit unsupported-feature error: no such procedure is documented in the cited manual. API 579 strain limits, collapse factors, imperfection sensitivity and acceptance are NOT_EVALUATED. No licensed-standard numerical values are introduced. Cylinder axial buckling, ring external-pressure benchmarks and native S8R qualification remain later slices. The two-solver crack comparison in the crack spike (issue 2178) and the alternative-solver evaluation (issue 253) remain open; this work makes no solver-selection verdict.

Sources and verification

The keyword and output basis is the CalculiX CrunchiX User's Manual, version 2.22, August 2024, section 6 equations (2)-(3), sections 6.8.1, 7.5, 7.43, 7.51, 7.105, 7.117, 7.122 and 7.124. The public manual was retrieved on 2026-10-20 with HTTP 200; its text was inspected rather than numerical allowables copied. Native tests were run with open-source CalculiX 2.21. Keyword support in other versions is not established by these tests. The cited pressure, strain and STEP clauses were inspected again from the public manual on 2026-10-22 with HTTP 200.

Reproduction: run python -m pytest tests/solvers/calculix -q with the package importable. Native tests skip explicitly when ccx is absent. The separate plate-with-hole tests require gmsh. No solver is started by the worked-example generator itself.
