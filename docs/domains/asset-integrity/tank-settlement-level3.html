Scope and executable plan

Scope is tracked by issue 2174. The implementation will prepare a validated component inventory, evaluate referenced load expressions, and render all four unevaluated failure checks through the existing FFS report and decision interfaces. Tests will precede the implementation and compare against independently derived answers. The registry will expose a standalone command; no external routing configuration will be modified.

The first slice will validate courses, bottom, annular ring, top angle, girders and an optional flat roof. The second slice will synthesize supplied settlement harmonics and prepare hydrostatic and self-weight loads. The third slice will retain missing criteria, render the report and write the durable JSON handoff. Later work will generate a connected mesh, run a qualified nonlinear solver and reproduce a published FEA case.

Input contract and method

Inputs use metres, kilograms, seconds, pascals and newtons. Angles are degrees measured counterclockwise from a caller-selected common reference. Radius is the shell mid-surface radius; z = 0 is the bottom; displacement is positive upward. Material references identify required evidence; they do not supply constitutive properties or qualification. All steel components use the explicitly supplied density.

Each course supplies height, thickness and material reference. The bottom is an inner disk of radius R − w; the annular ring occupies radii R − w to R, so plate weight is counted once. No overhang, stepped plate elevation, sloped roof, overlapping plates, foundation contact or weld topology is modelled. The top angle and wind girders supply section area for weight inventory only; their stiffness is not calculated. A flat roof is optional; when present, its type is required and is flat. Every supplied girder requires an elevation, including an explicit zero at the bottom. Mesh target and junction sizes describe intent, not generated elements.

Full bottom-edge displacement is uz(θ) = m + Σ[ancos(nθ) + bnsin(nθ)]. This is finite Fourier synthesis from NIST DLMF (2010), equation 1.8.1, with m = a0/2. Mean movement and the first harmonic are retained. Survey fitting and API 653 Annex B survey reduction are not performed; supplied coefficients require an upstream source reference. The angle list gives inspection samples, not a mesh or a convergence criterion; the complete coefficients remain in the handoff.

For a vented tank with constant product density, gauge pressure is p(z) = ρg max(h − z, 0), following OpenStax University Physics Volume 1 (2016), section 14.1, equation 14.4. Gravity, density and fill height are required inputs, with no default gravity or product properties. Pressure is reported at course ends and on the bottom; a solver must apply the continuous distribution.

Self-weight is W = ρsgV. Geometric volume is the sum of 2πRtH for each course, π(R − w)²t for the inner disk, π[R² − (R − w)²]t for the annulus, 2πRA for each circumferential section and πR²t for a flat roof. These expressions are direct mid-surface area-times-thickness derivations, not code acceptance equations. Wind pressure and its reference, when supplied, are retained as unevaluated intent; no circumferential wind law is invented.

The committed input is synthetic and does not represent an operating tank. All numerical geometry, loads, mesh sizes and coefficients are selected for arithmetic demonstration. They are not standard limits or measured data.

  examples/workflows/api579-tank-settlement-level3/input.json \

Replace {output_dir} with a retained calculation location outside the source checkout before running the command. Quote the substituted input and output paths when they contain spaces. Checks and review limits

The focused run on 2026-10-25 passed 42 preparation tests and two registry tests: 44 passed, with no failures or skips. The following command reproduces that scope:

uv run --no-project --with pytest --with pyyaml --with numpy \
  --with pandas --with pint --with scipy python -m pytest \
  tests/asset_integrity/test_tank_settlement_level3.py \
  tests/workflows/test_registry_versioning.py \
  -q -rA -p no:cacheprovider --basetemp="{temporary_dir}"

Replace {temporary_dir} with a new, disposable test directory outside the source checkout. These results establish only the arithmetic and handoff behaviour exercised by those tests. Cancelled hosted checks supply no passing-test evidence; aggregate validation remains unresolved until the required harness and selected domain tests complete successfully.

The tests exercise independent harmonic, pressure and weight anchors; invalid scalars and structures; optional roof, girder and wind intent; JSON serialization; missing-check escalation; and CLI output readback plus registry linkage. The input digest binds the handoff to its supplied configuration, not to source authenticity, material qualification or solver results.

Repeated JSON keys are rejected at every object depth before any output is written, even when their values agree or their spelling uses Unicode escapes. Reports and handoffs use UTF-8 with LF newlines. The report tables include load densities, gravity, fill height, harmonic coefficients, individual course fields and each missing-evidence item. Prepared loads and sampled displacements are displayed to three significant figures; input values retain their supplied precision. Applicability remains flagged as unevaluated, and returned evidence lists are independent between handoffs.

Local adversarial inspection identifies three required boundaries: sampled harmonics cannot be described as a solved mesh; reported collapse cannot govern acceptance for displacement-controlled settlement; and missing code evidence cannot be filled from memory. All three boundaries are retained in the handoff and tests. Separate-provider review remains required before merge.
