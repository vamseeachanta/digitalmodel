Campaign scatter and assessment check status

Summary

The campaign scatter interval uses chi-square quantiles at the actual sample degrees of freedom. The pressure helper rejects a non-positive or non-finite design pressure. Disabled fracture analysis emits a RuntimeWarning containing NOT_EVALUATED and returns the original configuration before calculation components are loaded.

Method and worked example

The example readings are synthetic arithmetic inputs, not measurements: [-1.0, 0.0, 1.0] mm. Their mean is zero, sum of squared deviations is 2 mm², and df = n - 1 = 2. The sample standard deviation is therefore s = sqrt(2 / 2) = 1.0 mm.

The two-sided 95 % standard-deviation interval is computed as [s sqrt(df / q(0.975, df)), s sqrt(df / q(0.025, df))], using the NIST/SEMATECH e-Handbook, section 1.3.5.8. Here q(p, df) is the inverse chi-square cumulative distribution. For df = 2, integration of the density in section 1.3.6.6.6 gives F(x) = 1 - exp(-x/2), hence q(p, 2) = -2 ln(1-p). The calculation uses full precision. The regression suite independently integrates the chi-square density and checks both endpoints at df 13 and 16, as well as df 1, 2, 20, 21 and 100. Numerical inversion through SciPy's chi2.ppf eliminates sparse-table rounding and the former missing interval above df 20.

Pressure and disabled-check behavior

Issue 2598 defines the positive-pressure API requirement. It is an input-domain rule, not a standards-derived acceptance limit. Zero, negative, NaN and infinite design pressure raise ValueError. A finite positive pressure retains the existing calculation and result keys.

For a separate synthetic arithmetic check, the existing helper's documented pressure relation gives P = 2 × SMYS × E × t / OD. With strength 12000 psi, efficiency 1.0, wall 0.500 in and diameter 12.0 in, the result is 1000.0 psi. At a design pressure of 1000.0 psi, the pressure ratio is 1.0. These inputs and this arithmetic do not establish compliance with an engineering standard.

When default.Analysis.fracture_mechanics.flaw_limits is false, the caller receives the message Fracture mechanics NOT_EVALUATED: flaw_limits is disabled. The configuration is returned unchanged, without importing, initializing or executing the analysis components. Python warning filters control delivery; callers requiring a strict stop can turn RuntimeWarning into an exception, as described in the Python 3.12 warning documentation. Enabled analysis retains its component order and propagates failures.

Limits and way forward

The statistical interval assumes independent, normally distributed differences and negligible real change between repeat readings. The example demonstrates arithmetic and control flow; no fracture assessment is performed. Enabled fracture calculations are tested with component doubles, so their engineering results are not qualified by these tests. A disabled check requires an enabled, independently qualified assessment before a fracture acceptance conclusion can be issued. The existing pressure and strength formulas receive no new standards qualification from this change.
