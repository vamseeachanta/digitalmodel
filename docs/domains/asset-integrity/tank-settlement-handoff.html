Tank settlement handoff guide

The adapter retains validated survey intake and diagnostic screening in an in-memory Level3Handoff. All four proposed structural checks remain NOT_EVALUATED with null values and margins. An ESCALATE screening decision establishes no structural failure or acceptance.

Synthetic input to handoff

from dataclasses import asdict
from digitalmodel.asset_integrity.tank_settlement_handoff import prepare_tank_handoff

block = {
    "tank": {"diameter_m": 10, "height_m": 12, "fill_height_m": 8,
             "course_thicknesses_mm": [8, 6], "material_grade": "unspecified"},
    "shell_survey": {"angles_deg": [0, 90, 180, 270],
                     "elevations_mm": [10, 4, 2, 8]},
}
handoff = prepare_tank_handoff(block)
payload = asdict(handoff)
assert payload["data_package"]["proposed_checks"]["buckling"]["margin"] is None

Dimensions are synthetic choices. Optional edge and bottom surveys remain missing when omitted. Invalid or nonfinite survey intake raises the screening validator's ValueError.

Evidence required before assessment

Confirm units (m, mm and degrees), positive-up elevation datum, angle origin and orientation, and a qualified imposed-displacement derivation. Measured elevations and fitted harmonics are retained as diagnostics; neither is automatically converted to imposed displacement.

Supply course heights, bottom, annular ring, roof, stiffener and weld details, boundary conditions, product density, self-weight and wind basis. Qualify material behaviour, limiting triaxial strain, buckling criteria, collapse load factors and weld service strain criteria. Plastic collapse requires a secondary interpretation for displacement-controlled settlement.

The API 579-1/ASME FFS-1 Annex B1 (2007) to Annex 2D (2016/2021) clause crosswalk, native-result qualification and a published comparator with justified tolerance remain open.

No solver, availability probe, file publication, registry activation, reporting integration or external routing is provided. Structural assessment requires a separately qualified workflow.
