Plate crack assessment: arithmetic validation record

Summary

The offline crack-fad-level2-handoff workflow composes the existing plate surface-flaw calculation, fixed-length critical-depth search and specialist handoff. The curve is labelled BS 7910:2013 Option 1 in the calculation output, report and handoff. Every case is escalated for specialist review, including a point inside the computed envelope. Published Annex-case validation is NOT_EVALUATED; arithmetic checks do not establish code-qualified service acceptance.

Method and source traceability

The existing crack_fad.py is reused without introducing new standard coefficients. Its documented sources are BS 7910:2013, Guide to methods for assessing the acceptability of flaws in metallic structures, Clause 7.3.2 (Option 1) and Annex P (reference stress), and the surface-plate stress-intensity solution documented there (1981). The existing method checks the surface and deepest points of a semi-elliptical flaw in a plate under membrane plus bending stress.

Kr is applied stress intensity divided by the supplied toughness; Lr is reference stress divided by yield strength. The computed point is compared with the cited curve and collapse cutoff. The depth search holds half-length, width, material and loading fixed. The finite-width correction is now propagated to every search trial, matching the point calculation.

The source documents were not opened for this change. The repository's existing documented equations are the calculation basis, not fresh independent source qualification. No licensed standard or its example values are copied.

Independent arithmetic and answer

The complete arithmetic is written out in the test docstrings in test_crack_fad_workflow.py. Expected values are calculated without calling the implementation under test. At the demonstration geometry, the Annex P expression gives alpha = 0.05, reference stress = 105.3 MPa and Lr = 5/19. The independently evaluated plate expression gives governing surface-point stress intensity = 9.4 MPa sqrt(m), Kr = 0.094 and curve height = 0.983. The point is inside the curve and below Lr_max = 1.250. These rounded values are display values; tests retain precision.

A separate collapse-governed synthetic case uses half-length and thickness 20.0 mm, membrane and yield stress 400.0 MPa, tensile strength 600.0 MPa, and artificially large toughness so fracture does not govern. Then alpha = a/40 and Lr = 1/(1-a/40). Setting Lr to the collapse cutoff gives a = 8.0 mm. The returned passing-side depth is checked against that hand solution at the supplied numerical resolution.

A finite-width regression checks that narrowing the plate lowers the searched depth. Report readback, JSON handoff equality, HTML escaping, registry routing, invalid-input rejection and retention of the qualification gap are also tested.

Limits and way forward

  • Published Annex plate-case validation: NOT_EVALUATED. An accessible example with source rights and independently regenerated values is needed before a published-case validation claim.
  • The catalog status is workflow; a live qualified assessment is not established by the presence of this record.
  • Only flat-plate surface flaws, positive tensile membrane stress and nonnegative bending are supported. Half-length and half-width conventions are explicit. Unsupported keys, missing toughness, nonfinite inputs, invalid geometry and unsupported curve selection are rejected.
  • Residual/secondary stress, weld mismatch, hydrogen, intermediate crack-front maxima, fatigue growth, service-temperature toughness and remaining life are not evaluated. The handoff asks the specialist to establish the missing basis.
  • SEARCH_BOUND_REACHED is a domain cap, not a failure depth. NO_ACCEPTABLE_DEPTH_FOUND denotes no passing point at the supplied resolution. A bracketed boundary assumes a single crossing; global monotonicity is not established.
  • API 579 Part 9 partial safety factors and cylinder-specific solutions remain under the Part 9 follow-up. No API 579 curve selection is exposed by this workflow.
  • Independent provider review remains required before merge. No advanced analysis or licensed solver is run by this workflow.
