Diffraction external matrix input contract

Summary

External stiffness and damping inputs require explicit canonical SI units and a reference point. Both adapters convert the declared input to native units and save applied matrix evidence. Missing metadata, unknown units, nonfinite entries, non-square matrices and asymmetric matrices are rejected.

Inputs and method

The optional external_stiffness and external_damping fields remain six-by-six lists. Each supplied matrix requires its own external_stiffness_units: SI or external_damping_units: SI and corresponding external_*_reference_point declaration. Only body_origin and centre_of_mass are supported. An absent matrix needs neither field; metadata without a matrix is rejected.

Here SI means N, m, s and rad, regardless of a backend's name for its unit system. Rows and columns follow surge, sway, heave, roll, pitch, yaw. Axes are parallel to body axes through the declared point. A positive coefficient produces a load opposing displacement or velocity: F_ext = -K q - B dq/dt. No hydrostatic replacement or target-restoring semantics are introduced.

OrcaWave SI uses kN, m and s, so K_native = K_SI / 1000 and B_native = B_SI / 1000 for every entry. Angular columns remain in radians. AQWA's generated kg, m, N deck uses an explicit identity conversion, followed by the existing four-significant-figure card formatting.

AQWA damping is written on FIDP cards; additional structural stiffness is written on documented SSTF cards. The former FISK spelling is replaced. Each body has its own WFS data block. AQWA accepts centre-of-mass matrices with zero body attitude, and body-origin matrices only when that origin coincides with the centre of mass. Other origins, free-floating mass mode and rotated body axes are rejected because no matrix shift or rotation is established. OrcaWave preserves either supported named origin.

Worked synthetic example

The complete input is external_matrices.yml. Every coefficient is a chosen synthetic input. The mesh name is a placeholder; panel geometry and hydrodynamic qualification are outside this example.

K_SI = B_SI =
[1000,    0,    0,  200,    0,    0]
[   0, 2000,    0,    0,    0,    0]
[   0,    0, 3000,    0,    0,    0]
[ 200,    0,    0, 4000,    0,    0]
[   0,    0,    0,    0, 5000,    0]
[   0,    0,    0,    0,    0, 6000]
units: SI
reference_point: centre_of_mass
centre_of_gravity: [0, 0, -2] m

Hand calculation: diagonal coefficients 1000 through 6000 divided by 1000 give native OrcaWave coefficients 1.0 through 6.0. Each coupling coefficient 200 divided by 1000 gives 0.2, in both transpose positions. AQWA retains the input coefficients. At a prescribed surge displacement of 1 m and zero other motions, the external surge restoring force is -1000 N in either deck, and the roll moment from the coupling is -200 N.m. At a prescribed surge velocity of 1 m/s, the same selected damping coefficients give -1000 N and -200 N.m. These are dimensional hand calculations, not solver results.

from pathlib import Path
from digitalmodel.hydrodynamics.diffraction.input_schemas import DiffractionSpec
from digitalmodel.hydrodynamics.diffraction.aqwa_backend import AQWABackend
from digitalmodel.hydrodynamics.diffraction.orcawave_backend import OrcaWaveBackend

spec = DiffractionSpec.from_yaml("examples/hydrodynamics/diffraction/external_matrices.yml")
cards = AQWABackend().build_deck7(spec)
path = OrcaWaveBackend().generate_single(spec, Path("output"))

Evidence and migration

Single and modular generation write external_matrices.aqwa.json or external_matrices.orcawave.json beside the deck when a matrix is supplied. The sidecar records input values, applied native and normalized values, per-entry units, DOF order, sign, reference coordinates and conversion revision. An empty matrix list replaces earlier evidence when matrices are removed. AQWA rounding is visible in the applied values. This is generated input provenance; it does not claim licensed execution or solver readback.

Legacy matrices require review of their original units and reference point before metadata is added. Native kN-based inputs are multiplied by 1000 for canonical storage. Values already in N are retained. The existing benchmark specification is migrated from its retained native input while preserving its generated native damping.

Restoring composition and target GM remain outside this input contract. Result-side matrix normalization also remains separate. User-specified origins, matrix frame transformations and licensed solver confirmation are not evaluated.
