Moonpool mesh-quality fix-up

Scope: PR 2324, owner card A01; B1/B2 and bounded R1–R5 fixes. The existing PR branch will be updated without merging or rewriting history.

The cut will use polygon differences and local triangulation with interior quality refinement. Source edges will acquire nodes only at actual footprint intersections. Seam conformity will inspect only affected bottom faces and shared source edges. Unrelated geometry will remain unchanged. New triangles will have a bounded longest-edge/altitude ratio; unsupported narrow remnants will be rejected explicitly.

A documented relative clearance tolerance will reject near-coincident vertices/edges before triangulation. Circles will use equal-area polygons with a minimum of eight segments. Reports will expose area, draft, removed volume and mesh-quality counts; wall metadata will carry a cutout index.

Regression tests will first reproduce each changed behavior. Tests will measure directed seam closure, untouched side quads and remote transitions, aspect bounds, polygon-volume agreement at 1e-9 relative, nominal-circle acceptance, near-mesh and near-cut clearances, repeated cuts and non-zero waterlines. Focused hull-library tests and changed-file checks will run through uv. The implementation will split into helpers to keep modules below 400 lines.

Risks: triangulation can fail to recover constrained boundaries or bounded quality near existing sharp corners; such cases will fail closed rather than emit slivers. Original mesh defects will not be globally repaired. An adversarial plan review will examine locality, topology, quality and validation before implementation; a frozen implementation packet will receive code review before publication.

Refined acceptance: clearance_tolerance will default to 1e-4, finite and strictly positive, relative to the shortest edge of each touched source panel. Positive near-distances below that threshold between footprint corners/source edges and source vertices/footprint edges will be rejected; exact coincidences and transverse intersections away from corners will be supported. The diagnostic will name clearance_tolerance. Previous opening boundaries will participate in the same check.

Every new bottom triangle will satisfy longest-edge divided by its altitude ≤ 50. Triangulation will preserve every polygon boundary node and segment, and conserve remnant area within 1e-9 relative. Quality refinement will introduce interior points; constrained recovery may subdivide hole edges without changing area, with bounded iteration and point counts; non-recoverable boundaries or quality will raise ValueError. Repeated-cut metadata will preserve prior wall IDs and allocate the next cumulative cutout index.

The touched bottom panels will be triangulated as connected polygon patches. Quality refinement will update one worst triangle per pass, coarsening interior short edges and placing new interior sites at centroids. Source boundary nodes and segments will remain immutable. Encroached hole segments may receive midpoint nodes without changing their area; boundary recovery and area acceptance will use that refined hole boundary. Refinement will stop after 512 passes or 10,000 sites and reject unmet quality. Conforming will inspect only keel faces whose bounds overlap actual cut-boundary candidates.

Before triangulation, selected-panel intersection area will cover the entire footprint within 1e-9 relative. Unsupported sub-resolution footprints will raise an explicit error rather than return unchanged geometry with a reported volume loss.
