# Plan: cited, edition-keyed DNV-RP-B401 / DNV-RP-F103 table modules (#2207)

> Issue: #2207 | Epic: #2206 | Owner decisions: D2, D6 (recorded 2026-09-25)
> Status: approved by owner instruction "continue with tasks" (2026-09-25); implementation in worktree `feat/cp-2207-b401-f103-tables`.

## Why
The review (`docs/domains/cathodic_protection/technical-quality-review-2026-09-24.md`, blockers B1–B3) found B401 Table 10-1 final current densities and Table 10-4 coating constants wrong in `src/digitalmodel/cathodic_protection/` and inverted in the legacy solver, with tests locking the wrong values in. The repository's sibling wiki already holds the tables as CSVs (`llm-wiki/wikis/engineering-standards/wiki/datasets/dnv-rp-b401/2005-with-2008-amendments/` and `.../dnv-rp-f103/2010/`).

## Source of truth and editions
- B401: the wiki page `wikis/engineering-standards/wiki/standards/dnv-rp-b401.md` carries `revision: "2011"` (the October 2010 edition, printed 2011) and lists the 2005-with-2008-amendments PDF as a second source. The dataset CSVs are labelled 2005-with-2008-amendments. Tables 10-1, 10-2, 10-4, 10-6, 10-7, 10-8 are identical across the 2005/2008 and 2010/2011 editions.
- 2017 and 2021 editions: no PDF or wiki page in this checkout. The table modules expose these edition tokens but mark every value `provenance="inherited-2011-unverified"` until a wiki page with a matching `revision` exists. `Citation.revision` stays `"2011"` because `validate_citation` fails closed on a frontmatter mismatch. This keeps the owner's client options open (D1–D3) without claiming verification that does not exist.
- F103: wiki page revision `"2010"`; CSVs for 2003 and 2010 (identical values). The 2016 edition is exposed the same way as B401 2017/2021.

## Deliverables
1. `src/digitalmodel/cathodic_protection/b401_tables.py`: enums for climate, depth band, paint category, anode material/environment, anode shape; lookups returning `CitedValue` for Table 10-1 (initial/final), 10-2 (mean), 10-3 (reinforcement), 10-4 (a, b by category and depth band), 10-6 (capacity, closed-circuit potential), 10-8 (utilisation); protection potential and design driving voltage; `climate_from_temperature`, `depth_band`. Table 10-7 formulas stay in `dnv_rp_b401.py` for now (#2211 moves them to a kernel).
2. `src/digitalmodel/cathodic_protection/f103_tables.py`: Table 5-1 mean current density by exposure and fluid temperature; Table A.1 linepipe coating a/b; Table A.2 field-joint a/b; bracelet utilisation 0.80.
3. `_edition.py`: accept `2005`, `2010` (alias `2011`), `2017`, `2021`; F103 `2010`, `2016`; `edition_provenance()`.
4. Fixtures: the 11 CSVs copied to `tests/fixtures/test_vectors/cathodic_protection/datasets/` with `PROVENANCE.md`; tests parse them and assert equality with the modules.
5. Wiring: `marine_structure_cp.py` (zone → climate × depth band; tidal row removed; splash stays 0 A/m² as a documented design choice; buried 0.020 A/m² per B401 §6.3), `coating.py` (paint categories I–III by depth band from Table 10-4; linepipe coatings from F103 Table A.1; uncited temperature/depth corrections removed), `dnv_rp_b401.py`, `anode_sizing.py`, `anode_depletion.py`, `marine_cp.py` constants; legacy `cp_DNV_RP_B401_2021.py` tables replaced by the same lookups (bare-metal density × f_c; initial/mean/final demand; coated/bare split removed; splash and atmospheric zones 0 A/m²).
6. Tests re-baselined from the tables: 59 legacy tests, `test_coating.py`, `test_marine_structure_cp.py`, `test_marine_cp.py`, `test_edition_divergence_baseline.py`, `tests/benchmarks/test_cp_benchmarks.py`.
