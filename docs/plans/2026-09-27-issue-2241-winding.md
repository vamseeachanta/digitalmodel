## Problem (measured in #2253)

`HullMeshGenerator._orient_normals_outward` decides each panel's winding by a per-panel centroid
test. On the open starboard half hull of a generated Wigley (L 100, B 20, T 8, 7 225 panels) it
flips 65 panels the wrong way. With consistently wound quads, exact analytic vertices give a
mesh `I_D` of 6.6 under every quad split (BRep 7.13); after the generator's orientation pass the
fixed split reads 38.3 and the shortest-diagonal split (now the default) still reads 7.9 with
36 % of the `|K| L_ref^2` sum in the end caps. The discrete curvature estimator treats a flipped
neighbour as a fold. The two mesh acceptance tests in `test_parametric_form.py` are strict
xfails for this reason.

## Scope

1. **Orientation by adjacency propagation** in `mesh_generator.py`: build the shared-edge
   adjacency of the panel list (quads and triangles, after deduplication and degenerate removal),
   breadth-first propagate a consistent winding across each connected component (flip a panel
   when its shared edge runs in the same direction as its already-oriented neighbour), then pick
   one global sign per component with the existing centroid/outward test applied to the
   component as a whole (sum of area-weighted normal dot centroid-to-panel vectors), not per
   panel. Keep the method name and signature; keep behaviour for closed meshes (mirrored,
   `symmetry=False`) identical in effect: outward normals.
2. **Diagnostics:** `PanelMesh.metadata["winding"] = {"components": n, "flipped_panels": k,
   "method": "adjacency_bfs"}` so screens can report it; no change to `PanelMesh` itself.
3. **Tests** (`test_mesh_generator.py`, additive; `test_parametric_form.py` xfail markers only):
   - conservation-class check: for the fixture `ship_profile` and `box_profile`, every shared
     edge is traversed in opposite directions by its two panels (no fold edges), on both the
     half hull and the mirrored full hull; all normals of the full hull point outward
     (dot(normal, centre-to-panel) > 0 for at least 99 % of panels, exactly as today's test
     expects if such a test exists; otherwise add it);
   - generated Wigley half hull: zero fold edges, and the count of panels flipped relative to
     the grid's natural winding equals either 0 or the total (a single global flip), never 65;
   - un-xfail the two mesh acceptance tests in `test_parametric_form.py` if they now pass with
     the default `quad_split="shortest"`: generated-Wigley mesh `I_D` within 10 % of the
     alternating-diagonal triangle reference (6.6) and end-cap share below 20 %. If one still
     fails, keep it xfail with the new measured number and explain in the PR body.
4. **Regression:** existing `test_mesh_generator.py`, `test_curvature_screen.py`,
   `test_hull_surface_brep.py`, `test_screen_inventory.py`, RAO/catalog suites unchanged in
   outcome; regenerate `curvature-signature-catalog.yaml` / table only if any inventory value
   changes (inventory hulls come from GDF files and do not pass through the generator, so no
   change is expected; state that in the PR body).
5. **Docs:** one paragraph in `docs/domains/hull_library/curvature-screening.md` under the
   triangulation finding ("winding") and this plan verbatim as
   `docs/plans/2026-09-27-issue-2241-winding.md`.
