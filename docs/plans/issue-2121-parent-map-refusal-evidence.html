Proposed change

The existing initial/final parent-table boolean predicate and refusal message will remain unchanged. Its refusal will use a local ParentMapChangeError(ValueError) defined in cylinder_parent_map.py, avoiding a new import dependency on PopulationError. Copied evidence will use rejected_parent_observation, disjoint from collector stage/completion keys, plus one fixed-enum events refusal summary naming the trigger identifiers. Tables will be sorted lists of [process identifier, parent identifier] pairs. Missing-side parent values in difference records will be null; actual table entries will remain integers, including zero.

Differences over the union of both table key sets will distinguish addition (absent initially), disappearance (absent finally) and parent change (present in both with unequal parents). Exact trigger identifiers will be separate: a process disappearing before construction may be outside the refusal predicate. unobserved_initial_pids will record every initial-table identifier skipped during construction, including those still present finally. That list alone will not trigger refusal.

Observed initial process identifiers will be retained as a sorted numeric list. No process-supplied strings, names, creation times or executable paths will enter this additional evidence. Numeric table records will not be described as complete process identities. Resource relevance will remain not evaluated; parent equality will not establish absence of identifier reuse with an unchanged parent. No extra process query, retry, fallback, exemption or success claim will be introduced.

The collector will retain the rejected observation alongside its failed stage, never as a completed inventory. Each table and initial observation list will have at most 65,536 entries, using existing input validation; difference and trigger lists will have at most 131,072. Entries will contain only bounded process integers, nulls and fixed enum strings. Busy-host additions may continue to cause refusal; this correction will not promise collection success.
