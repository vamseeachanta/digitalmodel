Jacket elevation and failure recommendations

The report generator will address the two requirements of issue 2445. Calculation inputs, numerical kernels, route statuses and existing result values will remain unchanged.

Resource intelligence

  • The report adapter will use the existing SVG FigureBlock and separate ReportSpec appendices defined in src/digitalmodel/reporting/spec.py.
  • The unmodified freshness test in tests/cathodic_protection/test_report_adapters.py compares the complete routed input. A sibling report-example YAML will therefore carry optional display geometry.
  • The initial-design recommendation will use counts from engine_adapter.py and edition citations held by b401_tables.py and b401_structures_phases_schema.py.
  • Missing installed condition and depletion evidence will be identified in the appendix; no retrofit year or quantity will be inferred.

Implementation and verification

Tests will precede implementation. A validated display schema will define finite coordinates, member diameters and zone bounds. One length scale will govern both SVG axes. Cylinder lateral surface areas will be clipped to zones and compared with the stated calculation areas as percentage differences. Each failed check and the overall failure will have an associated initial-design, installed-structure and retrofit recommendation, with a summary in the existing adequacy section. Caveats will be collected in Appendix A.

The original input, JSON fixture, engine goldens and report packs will be compared byte for byte with their saved baseline copies. The jacket golden will be regenerated using UPDATE_GOLDENS=1 and every difference will be accounted for. All routed result leaves will be compared, with zero differences required. Existing cathodic-protection and reporting suites will run before and after the change.

Boundaries and review

Only the adapter, two report modules and their tests, the sibling example, the jacket golden, this plan and one changelog line will change. Explicit repository contradictions, numerical changes, unexplained fixture differences, unavailable bound-artifact regeneration or conflicting adapter work will stop the affected requirement. Printed-page and narrow-screen rendering will remain unverified. Second-provider review will be required before merge.
