V3 (was AC 6) — set at the grid-uncertainty scale, with an escalation rule

r2's objection is arithmetically correct and revision 3 accepts it in full. The closest published analogue at the same refinement ratio produces a level-to-level difference of ε12%S1 = 0.807% at rG = √2. Revision 2's 3% threshold is 3.7× that. The consequence is not merely looseness — it is that a passing pair can imply a fine-grid error larger than the uncertainty V1 was built from:

Richardson estimate of the fine-grid error from a level-to-level difference:
    delta_RE = eps / (r_G^p - 1)  ,  r_G = sqrt(2)

  observed order p = 2.813 (Wu):  r^p - 1 = 1.651   eps = 2.9 %  ->  delta = 1.76 %
  formal second order p = 2.0  :  r^p - 1 = 1.000   eps = 2.9 %  ->  delta = 2.90 %

  Either way a 2.9 % pair -- which PASSES a 3 % gate -- implies a fine-grid error
  at or above the 1.41 % V1 floor.  The gate would certify a result whose own
  discretisation error exceeds the budget the tolerance was derived from.
Decision: V3 is set at 1.5%, AND a near-miss re-opens the tolerance. r2 offered these as alternatives; revision 3 adopts both, because each covers a case the other does not. The threshold prevents a mesh-dependent result being certified silently. The escalation rule handles the band between the two thresholds honestly instead of turning a 1.51% pair into a hard failure of work that may be sound.
V3:   eps = |Ct_fine - Ct_coarse| / Ct_fine     between the production mesh (~1.5 M
      half-domain) and a companion coarser by r_G = sqrt(2) (~0.53 M).

      eps <= 0.015                 PASS.
                                   At formal p = 2 this bounds delta_fine at 1.50 %,
                                   at Wu's observed p = 2.813 at 0.91 %  -- i.e. at or
                                   below the 1.41 % V1 floor either way.
                                   Margin: 1.5 / 0.807 = 1.86 x the closest analogue.

      0.015 < eps <= 0.030         ESCALATE, do not silently pass and do not silently
                                   fail.  U_SN is replaced by the delta_RE MEASURED on
                                   our own two levels, the V1 budget is re-derived, and
                                   the V1 verdict is re-evaluated against it.  If the
                                   re-derived budget exceeds 3 %, V1 is not claimed and
                                   a third level is required before any validation claim.

      eps > 0.030                  FAIL.  The answer is mesh-dependent; no validation
                                   claim stands regardless of which level matches EFD.

V1 is deliberately not required on both levels. On a two-point study the coarse level's agreement with the experiment is not the property under test — self-consistency is. A coarse level that misses EFD while tracking the fine level is informative; a pair that disagree with each other means the answer is mesh-dependent.

Execution — the runner, and the preflight/detachment contradiction resolved

AC 8 in revision 2 demanded a fail-closed wall-clock preflight and a detached production run. Those are mutually exclusive as written. runner.py:92 drives each stage as one subprocess.run(...) with timeout=timeout_seconds, default 7200. Once the command is wrapped in setsid nohup the parent returns immediately and that timeout no longer bounds the solve at all. Raising it to ~300,000 s makes the preflight trivially satisfiable and protects nothing. As written it is a configuration-consistency check wearing the language of a safety property.
