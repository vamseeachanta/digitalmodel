Plan-lite

The scope will cover page lookup, file-stat and page-read failures in src/digitalmodel/orcaflex/mooring_design_fowt.py, their regression cases, and the dependent atlases/fowt_mooring/ artifact and default pointer. Equations, engineering factors, caller-supplied cable limits and acceptance limits will remain unchanged.

Error oracle

Calculation Output Citation Contract section 4.1, in workspace-hub:docs/standards/calc-output-citation.md, will govern configured-wiki resolution errors: failure will abort the calculation with CitationResolutionError carrying the code_id. The regression cases will also require suppression of raw read-error paths and contents in displayed exceptions, across standalone and overlay wiki layouts. Existing unconfigured-wiki behavior will remain unchanged.

Verification plan

  1. The citation-resolution and mooring-design tests will check missing, unreadable and mismatched pages, lookup and stat errors, and existing geometry behavior using synthetic citation metadata.
  2. python -m pytest tests/orcaflex/test_fowt_citation_resolution.py tests/orcaflex/test_mooring_design_fowt.py tests/parametric will exercise the affected modules, atlas queries and committed-atlas staleness gate.
  3. The shipped fowt-mooring-atlas-query workflow test will require an in-range utilisation. The atlas grid and complete holdout record will be compared with the prior artifact.
  4. Repository structure, applicable file checks, whitespace, publication text and LFS attributes will be checked before handoff. Hosted failures will be inspected and their evidence gaps will be recorded.

Qualification limits

Synthetic citation metadata will serve only as resolver test input. Authoritative standards metadata will remain unconfirmed until its source page is available. Inherited standards labels will remain assumed, based on previous experience. Neither this error change nor atlas freshness will establish standards compliance or qualify the geometric screen for final design.
