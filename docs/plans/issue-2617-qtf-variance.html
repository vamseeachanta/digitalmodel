Proposed calculation and scope

For fixed-amplitude random-phase waves, a_i=sqrt(2 S_i dw) and a Hermitian difference-frequency QTF, the two ordered terms will combine into a real sinusoid of amplitude 2 a_i a_j |Q_ij|. Its phase-ensemble variance will be 2 a_i^2 a_j^2 |Q_ij|^2 = 8 S_i S_j dw^2 |Q_ij|^2. Summation will therefore visit only i<j. The diagonal will contribute mean load, not slowly-varying variance.

full_qtf_slowly_varying will use the unique-pair sum, retain its scalar standard-deviation API and document the derivation. newman_approximation will retain its array API and positive-lag values, with its zero-lag bin set to zero to exclude mean load. Its documentation will specify mu=k*dw and discrete variance sum(S_sv)*dw, including full endpoint-bin weights. This discrete interpretation will be explicit; the positive-frequency continuum limit will remain the usual factor-eight convolution.

Uniform increasing frequency grids and Hermitian full QTF matrices will remain the stated supported physical case. Nonuniform quadrature, directional seas, QTF interpolation and nonlinear/mooring qualification will remain outside this correction. Input validation will not be expanded; unsupported non-Hermitian/triangular-only matrices and nonuniform integration grids will be identified as limitations. A single component will return zero fluctuation. The existing positive-std fixture will use a complete QTF on a uniform grid.

TDD and acceptance

  1. A reproducible synthetic reference harness will call the actual public APIs before any production edit. The recorded baseline will precede implementation; random-phase force histories will be formed independently from wave amplitudes.
  2. Failing tests will cover a bichromatic known variance (including a complex Hermitian QTF), a single component/diagonal-only zero fluctuation, and Newman/full variance agreement within 1%. These will fail against the old implementation.
  3. A narrow-band JONSWAP ensemble will use fixed seed 2617 and independent records. The 95% confidence half-width of the mean time-history variance will be below 1%; full-QTF and Monte Carlo variances will agree within 1%.
  4. A linear surge oscillator will use synthetic mass, stiffness and damping. A time-domain ODE response will be compared to the repository full-QTF standard deviation using a QTF weighted by the oscillator transfer magnitude at each difference frequency. The case will use a bichromatic force with mass 10000 kN*s^2/m, damping 200 kN*s/m and stiffness 100 kN/m (natural frequency 0.1 rad/s, damping ratio 0.1). Four random-phase records will use 256 samples per beat cycle, discard 64 cycles and measure 128 complete cycles. Standard deviation will remove the static offset. Whole-cycle averaging will eliminate phase sampling error in this one-beat case, and standard deviations will agree within 5%.
