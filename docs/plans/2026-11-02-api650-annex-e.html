API 650 Annex E seismic screening plan

Scope: Seismic screening issue.

Engineering basis and design

The implementation will extend sloshing.py with a keyword-only SI calculation and a dataclass result. The existing convective-period helper will be reused. Public API 650 (2007) and NCREE load equations will support the two-mode weights, force heights, spectrum shape, SRSS shear, moments and hoop demands. API's public 12th-edition Addendum 2 (2016), E.7.2, will govern wave height and freeboard. These distinct revisions will be disclosed; full compliance with a current edition will not be claimed.

Project factors I, Rwi, Rwc, K, the governing impulsive coefficient floor, site design spectrum parameters, vertical acceleration, roof reaction and qualified annular resistance will be explicit inputs. Material allowables, site classifications and annular plate resistance will not be inferred. A J ratio will indicate no uplift, conditional self-anchorage or required redesign/anchorage without qualifying a completed design.

The anchorage limits, freeboard wave fraction and SUG II freeboard SDS trigger will become required caller inputs. API STD 650, Annex E, Table E-6 (anchorage ratio criteria) and Table E.7 (minimum required freeboard) will be cited by number and title without reproducing their values. Tests and the example will use labelled synthetic criteria; their dispositions will not qualify a design.

Verification

Tests will precede implementation and will establish a red result. A hand-arithmetic example will check each intermediate quantity. Regressions will cover both geometry branches, both spectrum branches, SUG freeboard rules, independent force/wave accelerations, J thresholds, depth-dependent hoop demand, dimensional scaling, nonfinite inputs and invalid geometry. Module tests, hydrodynamics and seismic folders will be run. A local defect review will inspect final equations, source versions, units, validation and public diff.

Additional regressions will isolate bottom weight from overturning demand, exercise the annular cap at nonzero vertical acceleration and hold annular resistance fixed when comparing vertical effects. Criterion validation will reject invalid bounds and nonfinite inputs. Source digests and symbol locations in the implementation map will be refreshed for the changed module.

Plan defect review

Defects sought: edition mixing, force-reduced wave height, slab heights above liquid treated as invalid, all roof weight used as shell reaction, J reported as final design acceptance, invented material factors, nonfinite input acceptance and wholesale standards reproduction. Controls will include explicit source revisions, separate Af and Ac, explicit roof reaction, conditional J language, required project factors and finite-value checks. A concise worked example and user guide will accompany the calculation. The external explorer and floating-roof dynamics will be identified as follow-ups.
