Tests and acceptance criteria

Tests will precede implementation. They will cover altered observation, native data (including bytes appended to originally empty streams), case, reference, runtime and parser source bytes; missing roles; unsafe locators; symlink and hard-link aliases; incomplete parser results; changed quantities or reaction total; changed assessment; and input dictionaries with insufficient attribution. Synthetic unit fixtures will be labelled and will not count as native evidence. The real private N4 test will run with unchanged original hashes and will establish COMPLETE replay, exactly 63 values and 22 criteria (21 PASS, one FAIL), CONTINUE, no writes and no qualification. Publication will require a captured non-skipped retained-corpus run; strict environment mode will fail rather than skip when its locations are missing. Existing recovery regression tests will pass.
