Tank-bottom CP implementation plan

Scope: tank-bottom CP and reference conversion. Implementation will remain in this worktree. Public sources and explicit design inputs will support screening; the calculation will not establish API 651 compliance.

  1. Tests will first specify the 40 m arithmetic, exact circular ribbon chords, feed topology, finite SI inputs, adverse foundation conditions, conversion signs, and survey/report equivalence.
  2. The existing current-demand kernel and validation helpers will be reused. A uniformly loaded conductor model will integrate Ohm's law; measured centre and edge potentials will be assessed separately.
  3. Electrode metadata will name electrolyte, temperature, source and approximation. Survey, monitoring, potential checks and reports will share one conversion utility; native criteria will retain their basis.
  4. The worked example and user guide will identify all synthetic inputs and distinguish minimum ribbon length from installed grid length. The local capability explorer will link the example.
  5. The CP test folder and nearest specialized CP tests will be run. The final diff, staged bytes, public-source rights and working-tree residue will be inspected before commit, push and a ready PR.

Adversarial plan review: default disposition will be changes required until sign reversal, ambiguous Ag/AgCl, zinc drift, ON-potential misuse, circular edge coverage and inferred polarization risks are addressed. Required inputs and explicit limitations will address these risks. No universal soil-resistivity threshold, ribbon discharge rating or maximum spacing will be inferred from API 651.

Independent provider review will remain unavailable under the task prohibition on calling other models. The referenced workspace review-packet builder, Windows preflight, memory and cleanup skills are absent from this checkout; manual scope, environment and cleanup evidence will be recorded here.
