The criterion for "complete" must be the declared body set, not the discovered one.

### MAJOR-2 — A hand-authored `benchmark_report.json` still produces ALL PASS

BC-1 closed the config-file channel; the artifact channel is open. `_case_summary_passes` never inspects `comparison_policy`, and `_build_results_from_config` never reads it. This is cheap to close without false negatives. A genuine export cannot be DECIDED with a null policy: `policy is None` adds `UNCONFIGURED_POLICY` at `multi_solver_comparator.py:1086-1087`, which forces `comparison_status = "REFUSED"` at `:1136-1138`. Requiring a non-null `comparison_policy` therefore rejects hand-authored and legacy artifacts only.

`test_decided_report_with_metadata_renders` (test lines 51-56) currently codifies the permissive behaviour: its report fixture has no `comparison_policy` key and the test asserts `"ALL PASS" in html`.
