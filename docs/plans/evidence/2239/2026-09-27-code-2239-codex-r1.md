1. **MAJOR — `mesh_hydrostatics.py:467–472`: Actual transom stations are rejected.**  
   Stations must lie strictly inside the mesh’s longitudinal bounds. A box’s transom at `x = -L/2` therefore cannot be evaluated; the test at `test_mesh_hydrostatics.py:325–328` moves the station inward and conceals the defect. Simply allowing equality is insufficient: `_section` clips toward decreasing x and returns zero at the aft boundary.  
   **Fix:** Support endpoint sections with a defined interior-limit convention or direct plane intersection. Test the actual aft face, forward endpoint, and a tapered transom against independent areas.

2. **MAJOR — `mesh_hydrostatics.py:159–166,185–201`: The checks do not establish manifold geometry or outward orientation.**  
   Two closed shells touching at one shared vertex pass edge counts despite a non-manifold vertex. A large outward shell plus a smaller, disjoint inward shell also passes because only aggregate signed volume is checked. Overlapping closed shells can pass and double-count displacement.  
   **Fix:** Validate vertex links and connected components; check component orientation against an explicit shell/nesting policy, and detect prohibited intersections. Add fixtures for vertex-only contact, mixed component orientation, and overlapping shells.

3. **MAJOR — `mesh_hydrostatics.py:376–383,386–410`: The signed fan cap is used as though it were a physical triangulation.**  
   A single centre shared across all boundary edges need not lie inside a concave waterplane or either component of a disconnected waterplane. Signed fan triangles can still integrate volume correctly, but may overlap, point downward, or extend outside the actual waterplane. Subsequent section clipping and `max(abs(y))` do not cancel geometrically overlapping signed contributions, so half-breadths can include artificial geometry.  
   **Fix:** Extract boundary loops and triangulate their interiors with support for holes and disconnected components, or compute section/grid boundaries directly from physical faces and the waterplane. Test concave and twin-body waterplanes, including stations through gaps. Retain independent volume checks.

4. **MAJOR — `mesh_hydrostatics.py:173–177,510–522`: Geometry can change while its input hash remains unchanged.**  
   `TriMesh.vertices` and `TriMesh.faces` are publicly writable. After construction, either can be modified without repeating validation or updating `source_digest`; subsequent results retain the original input identity. This defeats both the geometry contract and the required provenance.  
   **Fix:** Encapsulate immutable geometry or revalidate and hash the actual geometry at calculation time. Add a regression demonstrating that mutation is refused or produces a newly validated input hash.

5. **MAJOR — `friction_scaling.py:195–202,229,265`: Citation emission does not meet the acceptance criterion.**  
   Both transfer functions default to `cite=False`, producing empty citation lists. Even `cite=True` only requests the ITTC-57 wrapper; the transfer procedure is an unstructured string, and the supplied wrapper permits an empty sidecar when unconfigured. The monkeypatch test proves delegation, not citation resolution or fail-closed behavior.  
   **Fix:** Require the applicable resolved sidecars for the new engineering calculation API, including the transfer method, and test actual resolution failures. Preserve the legacy scalar API separately where compatibility requires it.

6. **MAJOR — `mesh_hydrostatics.py:340–345,540–544`: Accepted conditions can cause an uncontrolled division by zero.**  
   Any finite `x_midship` is accepted. For the supplied box, `x_midship=100` with zero trim leaves a valid clipped body but gives `A_M=0`, causing `C_P` to divide by zero. A section through a genuine gap can cause the same failure even within the bounds. Positive volume and waterplane dimensions are also not checked before normalization.  
   **Fix:** Validate the midship reference and all coefficient denominators. Return a specific contract error or explicitly unavailable quantities for unsupported conditions. Test an out-of-range midship, a dry midship section, and near-degenerate waterplanes.

7. **MINOR — `mesh_hydrostatics.py:251–252,284–288,379`: Clipping does not enforce the stated degeneracy contract.**  
   Snapping modifies signed distances without projecting coordinates onto the plane. Generated triangles are checked only for distinct indices; near-vertex cuts can produce arbitrarily small slivers, and a fan centre collinear with a boundary edge creates a zero-area cap triangle. No post-clipping topology or geometric validation follows.  
   **Fix:** Define a topology-preserving policy for on-plane vertices and slivers, then validate the generated surface. Add cuts through vertices, through edges, and just above/below them, checking closure, finite results, and integration agreement. Do not simply delete tiny faces and leave holes.

8. **MINOR — `friction_scaling.py:338–341`; `test_friction_scaling.py:158–165,177–199`: The CI test does not establish nominal coverage under its noise model.**  
   The Student-t interval assumes independent, constant-variance errors in `C_T/C_F`. Multiplicative noise in `C_T` instead gives variance proportional to `(1+k+c·Fn⁴/C_F)²`. The fixed seeds make this test deterministic, but the broad 90–99% acceptance band can accept materially miscalibrated intervals. Selecting a single seed because another missed the interval adds no statistical evidence.  
   **Fix:** Document the regression error model. Verify the ordinary interval using homoscedastic transformed-response noise and independent interval calculations; use an appropriate uncertainty method if proportional measurement noise is supported. Compute covariance through QR/SVD rather than explicitly inverting the normal equations near the permitted conditioning limit.

9. **MINOR — `mesh_hydrostatics.py:386–391,580–583`: Grid construction repeatedly processes the whole mesh.**  
   Each station copies/clips the complete submerged mesh and performs edge-membership work. A grid with many stations therefore repeats substantial allocation and sorting on potentially millions of faces. The supplied tests establish no performance envelope.  
   **Fix:** Use triangle x-bounds or a spatial index to select intersecting faces and cache repeated stations. Measure runtime and peak memory for representative `10⁵–10⁶`-face meshes before claiming that scale is supported.
