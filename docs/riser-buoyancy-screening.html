SLWR buoyancy screening analysis

The analysis ranks exact atlas configurations by maximum touchdown-zone stress range across supplied near, far and cross excursions. Every configuration is retained, including constraint violations and missing evidence. Optional stress spectra are passed to the existing narrow-band fatigue engine. The worked example is synthetic; no qualified physical optimum or certified fatigue result is established.

Validity and required evidence

SCREEN: static excursion stress range is a proxy. A scalar transfer from an excursion envelope to a stress PSD is an assumption, not a dynamic model. Narrow-band fatigue remains a screening estimate. CERTIFY: NOT_EVALUATED. Qualified dynamic stress extraction, at least two independent OrcaFlex candidate comparisons and held-out corpus evidence are required before a certified optimum or client-facing fatigue damage is established. Both tiers appear on every returned configuration, including incomplete rows.

The static geometry source for upstream response is marine_ops.marine_analysis.catenary.lazy_wave.LazyWaveSolver. The quarantined subsea.catenary_riser.lazy_wave.LazyWaveAnalyzer is excluded. This interface does not call either geometry implementation, generate excursion stresses or certify imported response. Existing kernel sign, closure, radius-binding, equilibrium and legacy-comparison tests provide regression evidence; they do not qualify dynamic stress response. Input source strings record a caller's basis and do not authenticate it.

Inputs and interface

Import rank_buoyancy_candidates from digitalmodel.riser_fatigue.buoyancy_screening. Supply an existing digitalmodel.parametric.atlas.Atlas, responses keyed by its case_id, caller criteria and an optional spectral basis. The atlas grid is the candidate set. Its surrogate response is ignored, no interpolation or new sweep is performed, and a minimum is established only among supplied feasible nodes.

Module distribution is uniform, set by starting position and clear gap. Irregular module arrangements, dynamic response generation, code-derived S-N curve selection, certification, automatic search refinement, and historical corpus ingestion remain outside this interface. A missing configuration response remains visible as NOT_EVALUATED; no synthetic fallback is used.

Method and sources

  1. At each material station s, the excursion envelope is defined as R(s) = max_case stress(s) − min_case stress(s). The screening objective is max_s_in_TDZ R(s). This is a defined proxy, not a fatigue equation. The complete R(s) profile, governing interval and controlling station are returned.
  2. Each observation is compared to its caller-supplied limit in every excursion. Any violation gives VIOLATED. Otherwise missing evidence gives NOT_EVALUATED. Only complete feasible nodes receive ordinal ranks; ties sort by case identifier. All excluded rows remain in the result with observations, limits and comparators.
  3. The optional scalar secant helper assumes H(s) = R(s)/reference_excursion_range and G_stress(s,f) = H(s)² G_excursion(f). This is the variance scaling of a scalar linear map. The reference excursion span and motion PSD are required inputs; near/far/cross multi-directional response is not reduced to a qualified transfer function by this operation.
  4. Spectral moments are integrated as M_n = integral (2πf)^n G_stress(f) df, for n = 0, 1, 2, 4, using the trapezoidal rule. This preserves variance M_0 and converts Hz moments to angular-frequency moments. Crossing rate is ν_0 = sqrt(M_2/M_0)/(2π). The public source is Application of computers in fatigue analysis (1985), section 3.3.1, equations 3.16–3.17. The source text was opened on 2026-10-19.
  5. The existing fatigue.spectral_fatigue.narrow_band_damage engine computes the Rayleigh narrow-band expectation: D = ν_0 T (2 sqrt(2 M_0))^m Γ(1+m/2) / A. The range assumption is supported by section 3.3.1 of the same public source; the repository implementation is reused rather than duplicated. A zero PSD gives true zero damage; absent spectra give NOT_EVALUATED. The unrounded engine damage rate is multiplied by the supplied duration; calendar-year conversion and rounded equivalent stress are not used. The caller's S-N coefficients, duration and source are retained in the exported spectral basis.

No coefficient or acceptance limit from a licensed publication is embedded. S-N data, stress transfer, geometry and constraints remain the caller's responsibility. A narrow-band assumption does not establish accuracy for a broad-band process.

Worked example: independent answer

The envelope profiles are A=(4,2,6), B=(2,1,3), C=(1,0.5,1.5) MPa. The TDZ maxima are 6, 3 and 1.5 MPa. B ranks first among feasible supplied nodes; A ranks second; C is retained without a rank. This does not establish a physical relationship between module count and stress; the profiles are deliberately supplied.

For the optional spectral screen, motion PSD ordinates (0,1,0) m²/Hz on frequencies (0,1,2) Hz integrate to variance 1 m² by trapezoidal quadrature. The reference excursion span is an invented 2 m. A's gains at TDZ stations are (1,3) MPa/m, B's are (0.5,1.5), and C's are (0.25,0.75). Stress variances are the squares of those gains. This discrete example has M_2=(2π)² M_0, hence ν_0=1 Hz.

Choose invented S-N inputs N=1000/S² and duration 10 s. For m=2, Γ(2)=1 and E[range²]=8 M_0; therefore D=0.08 M_0.

Reproduce and inspect

PYTHONPATH=src python examples/riser_fatigue/buoyancy_screening.py
python -m pytest tests/riser_fatigue/test_buoyancy_screening.py -q

The example prints JSON and creates no files. Its test reads back that JSON and compares ranking and damage to the hand calculation. The tests also cover constraint failures across excursions, missing evidence, layout identity, non-finite inputs, PSD validity, zero stress variance and deterministic ties.

Way forward

Qualified aligned stress profiles and stress spectra are needed to populate real atlas configurations. Extend the response producer before claiming a minimum for an SLWR design. Complete independent dynamic comparisons and held-out corpus validation under the buoyancy optimisation issue, with response extraction and corpus work tracked in its linked dependencies. Existing synthetic examples do not satisfy those criteria.
