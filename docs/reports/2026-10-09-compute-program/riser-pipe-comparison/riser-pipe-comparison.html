Program benchmarking analysis: riser pipe modules

Summary

Internal program benchmarking analysis for one public nominal pipe. The comparison covers repository-module outputs; standard conformity is not established.

API RP 2RD: governing returned check is collapse, case operating, utilisation 40.2% — within the module unity criterion. Dispositions use unrounded results.

API STD 2RD: governing returned check is combined, case operating, utilisation 172.8% — above the module unity criterion. Dispositions use unrounded results.

API RP 1111 is not compared because its recorded edition conflicts with the standards inventory.
