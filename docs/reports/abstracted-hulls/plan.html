X03: coordinate-only hull extraction

Scope: epic 2272, owner card X03 (decision:client). The exporter, tests and schema will be published in a draft PR; geometry publication will remain conditional on resolution of the unit and literal-match gates; raw DWGs will remain unchanged.

The exporter will decode each of six DWGs using the LibreDWG 0.14 build supplied by the A07 build script. DXF will travel through memory only. Decoder and parser diagnostics will be suppressed. An explicit entity allowlist will retain coordinates from LINE, POLYLINE, LWPOLYLINE, ARC and SPLINE only; no names, text, attributes, identifiers or block metadata will be serialized.

Only a verified unit declaration matching the source digest in the A07 probe will permit output. Five hulls will return units_unverified without writing an output. The 3D hull with INSUNITS=4 will retain coordinates in millimetres. Spatial modelspace POLYLINE, polymesh-grid and polyface-boundary coordinates will be retained without block expansion. Numerical intersections with 21 equally spaced planes in each native coordinate direction will be emitted as neutral plane_x/plane_y/plane_z offset groups; no semantic station labels will be assigned. Independent physical scale and hull axes will remain unverified. Owner confirmation of the declared-unit commit gate will be required before geometry publication. No engineering qualification of station positions, view mapping or scale will be claimed.

Tests will precede implementation and cover metadata exclusion, finite coordinate validation, unsupported entities, unit fail-closed behavior, source preservation and all six real drawings. Attribute values will be loaded from drawings at runtime and checked against committed geometry bytes using nonrevealing assertions; values will never be written to logs or files. A schema will describe approximation and qualification limits. Review will hunt for title-block geometry, unit and axis assumptions, parser failures and leaks through diagnostics.

Code review and cleanup audit will precede branch publication. The draft PR will carry decision:client, the dispatch attribution and a private-migration follow-up option. Claude review and owner merge will remain pending.
