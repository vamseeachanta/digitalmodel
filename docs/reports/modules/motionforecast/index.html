1. Executive Summary

Motion forecasting is the reconstruction of future rigid-body displacement from phased waves and a complex response amplitude operator. Analysis is performed to determine whether the implemented calculation reproduces its documented regular-wave example; key results are summarized below.

  • The synthetic heave example has a sampled peak absolute displacement of 1.040 m.
    • The result is a calculation demonstration; an installation sea-state limit is not established.
  • The supplied forecast interval is enforced by the reconstruction interface.
    • Use the calculation for software assessment within that interval; obtain independently qualified wave phases, response data and operating criteria before an installation decision.

2. Introduction

The main workflow is assessed from incident-wave components to heave displacement. The implementation also returns surge, sway, roll, pitch and yaw when response data are supplied. A response amplitude operator is the complex ratio of response to incident wave amplitude; its magnitude scales displacement and its argument adds phase.

The public example is the repository's documented regular-wave analytical check, not a measured installation or an externally published experiment. No actual structure, crane or rigging geometry is supplied. A dimensioned installation schematic is therefore not established.

3. Summary and use controls

The motion calculation is bounded by supplied input conventions and a supplied forecast interval. Operating acceptance is not inferred from a successful numerical calculation.

Specify the phase-reference position, common horizontal frame, propagation heading, time origin and response phase convention before use. Confirm the response grid covers every incident component. Supply equipment-specific limits and measurement-based forecast skill before setting a sea-state envelope. An orientation tolerance and a trigger for forecast support are NOT_EVALUATED because station-keeping data and installation criteria are absent.

5. Theory and methodology

Linear harmonic superposition is applied to the phased components. The implemented definitions are cited in section 9.2; no claim of conformity with a licensed standard is made.

For component i, θᵢ(t) = ωᵢt + φᵢ − kᵢ dᵢ·(x − xᵣ) + arg Hᵢ, and q(t) = Σ aᵢ |Hᵢ| cos θᵢ(t). Here t is absolute time in seconds, ω is angular frequency in radians per second, φ is incident phase in radians, a is wave amplitude in metres, d is the unit propagation vector, x is response position and xᵣ is wave-reference position in metres. H is the complex displacement response amplitude operator; q is the selected response. Translations are in metres and rotations in degrees.

Deep-water dispersion is k = ω²/g; finite-depth dispersion is ω² = gk tanh(kh). The wave number k is in radians per metre, depth h is in metres and g is the gravitational acceleration defined by the module. Finite-depth wave number is solved by bisection. Invalid depth can select deep water rather than reject the input; pre-validation remains necessary.

The derived rigid-body vertical displacement is z = heave − rₓ pitch + rᵧ roll, with angular terms converted to radians and horizontal offsets rₓ and rᵧ in metres. This small-angle extension is outside the computed example. The reported significant amplitude is twice the population standard deviation of the finite response record; it is not a maximum or an acceptance threshold.

For a narrow-band random process, the significant height relation is Hs = 4√m₀ and significant amplitude is Hs/2 = 2√m₀ = 2σ, where m₀ is the integral of the variance spectrum and σ² = m₀; see section 9.3. The present deterministic example evaluates 2σ from its finite sampled record. It does not estimate the highest-third wave statistic from a random sea.

The example is reconstructed through the public wave, analytical response and reconstruction interfaces. The signed history is checked separately against its closed-form cosine. The supplied interval is a software boundary, not a measured predictable zone. The bandwidth coherence proxy and aperture-based horizon functions require separate physical qualification.

6. Detailed results

The regular-wave heave history is calculated from the registered inputs. Its sampled peak absolute displacement is 1.040 m and its finite-record significant amplitude is 1.452 m; neither value is compared with an equipment limit because none is supplied.

No combined installation envelope or component capacity comparison is established. A monochromatic heave example supplies neither directional sea-state coverage nor equipment demand limits.

7. Validation evidence

The repository holds analytical checks and software regressions. Their evidence supports the stated identities and interfaces, not field prediction accuracy.

Regular-wave tests check signed amplitude and phase, reference-to-response spatial phase and heading projection. Finite-depth tests check the dispersion residual and the deep-water lower bound. Lever-arm tests check small-angle kinematics. Spectral tests compare component energy with spectral integration and a long realized record; the bookkeeping comparison shares spectrum and transfer definitions and is not an independent physical benchmark.

The response-file fixture is hand-authored adapter data, not independent solver validation. Measured-input tests use synthetic histories or local comma-separated-value files. A matched field record with phase-resolved waves, response measurements, equipment geometry and predeclared forecast-error criteria is not established by these tests. Current check results are recorded with the accompanying delivery record; historical pass counts are not represented as current execution evidence.

8. Findings, limitations and recommendations

The implementation provides a deterministic linear response calculation. Installation readiness remains conditional on evidence absent from the example.

8.1 Limits of use and recommendations

Restrict interpretation to linear wave response and small-angle rigid-body kinematics. Qualify incident phases and forecast lead-time error against independent measurements before operational use. Keep times inside the supplied interval; extrapolation is rejected but the interval itself is not qualified by that rejection.

Validate frequency, amplitude, depth, heading and sampling inputs before reconstruction. Grid response interpolation clamps outside its axes and does not wrap headings periodically; reject uncovered frequencies and headings during input preparation. Resolve the source-specific phase-sign uncertainty against matched physical response before using imported response data. These controls follow the implementation boundaries listed in section 9.2.

Supply an equipment-specific engineering basis for caution and limit values before issuing a go/no-go recommendation. Default criteria are indicative and lack edition-and-clause provenance in the inspected package; no default is adopted here. Nonlinear waves, forward-speed encounter effects and structural flexibility require an applicable model and separate validation.

8.2 Not covered

Directional spectrum generation, measured-motion reconciliation, affine correction, forecast-skill aggregation, operability fractions and lumped top-tension screening are catalogued but not demonstrated. Radar or lidar wave reconstruction and live sensor ingestion are not implemented by the synthetic sources. The lumped tension screen does not resolve distributed dynamics or snatch impact after slack. No licensed solver is used.
