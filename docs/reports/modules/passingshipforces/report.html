1. Executive Summary

The passing-ship forces module is a hydrodynamic load calculator for a stationary moored hull beside a parallel moving hull. Analysis is performed to determine surge force, sway force and yaw moment over a longitudinal passage; key results are summarized below.

  • Load histories are available for the documented public example.
    • The finite-depth sampled ranges are surge −34,484.7 to 34,484.7 lbf, sway −36,095.3 to 87,637.8 lbf and yaw −14,304,244.2 to 14,304,244.2 ft·lbf. The worked example supplies the inputs and both extreme locations; these are load demands without an acceptance limit.
    • Positive sway denotes attraction; attraction and repulsion are both retained in the plotted history.
    • Finite-depth images and the deep-water calculation are presented separately, using the same hulls and speed.
  • An operating decision remains NOT_EVALUATED.
    • No mooring capacity, allowable motion or port acceptance criterion is supplied. No load acceptance line is assigned.
    • Use the histories as loading inputs after hull geometry, separation, depth and numerical convergence are reviewed.

2. Introduction

The main workflow is assessed from configuration to the returned load history and comma-separated output files. The intended use is preliminary loading for a separate moored-system response assessment, rather than an installation sea-state envelope.

A documented public repository example is reproduced. It is an anonymised numerical demonstration, not a published field trial. The bibliography names the original formulation, but original-paper equations and applicability limits have not been independently read; the equations below are attributed to the repository implementation record.

3. Summary

The calculation is controlled by a consistent unit system, centreline geometry and a chosen stagger grid. The detailed actions for engineering use are stated here.

Supply immersed midship areas and hull lengths, mass density, relative passing speed, centreline separation and stagger values. Supply depth for the image calculation, or omit depth for the deep-water calculation. Refine stagger spacing before using sampled extrema as design loads.

The returned configuration contains the input particulars, depth mode, sampled signed peaks and their locations, and a row for every stagger containing surge, sway and yaw. The same history and summary are written to separate comma-separated files. An output folder is created when required; existing files with the same names are overwritten by the workflow.

Resolve forces and moments into the mooring model axes. Supply line properties, fenders, damping, pretension and motion criteria before assessing line loads or operating limits. No heading tolerance, wave-height limit or forecast threshold is inferred from this force-only calculation.

5. Methodology

The implementation is evaluated using closed-form inner integrals and numerical outer integration. The following expressions are transcribed from the calculator theory record, with all coefficients attributed to that record rather than inferred from an unread publication.

5.1 Hull representation and deep-water loads

For hull index i, Sᵢ is immersed sectional area, Aᵢ is midship area, Lᵢ is length and xᵢ is a longitudinal coordinate relative to midship. Index 1 denotes the moored hull and index 2 denotes the passing hull. The prime denotes differentiation with respect to xᵢ.

Sᵢ(xᵢ) = Aᵢ(1 − 4xᵢ²/Lᵢ²); S′ᵢ(xᵢ) = −8Aᵢxᵢ/Lᵢ²; −Lᵢ/2 ≤ xᵢ ≤ Lᵢ/2.

Let R = x₂ − x₁ + ξ, with longitudinal stagger ξ and centreline separation η. The kernels are F(x₁) = ∫ S′₂(x₂)R/(η² + R²)³ᐟ² dx₂ and G(x₁) = ∫ S′₂(x₂)/(η² + R²)³ᐟ² dx₂, each integrated along the passing hull.

X = ρU²/(2π) ∫ S′₁F dx₁; Y = ρU²η/π ∫ S′₁G dx₁; N = ρU²η/π ∫ (S′₁x₁ + S₁)G dx₁. The outer integrals span the moored hull. Here ρ is water mass density, U is passing speed, X is surge, Y is sway, N is yaw moment about midship and π is the circle constant. Positive sway denotes attraction. X > 0 acts toward +x. N is the first moment of the attraction-positive lateral load: N > 0 turns the +x end toward the passing hull. These senses follow the implementation axes and moment kernel; no nautical clockwise convention is assigned.

5.2 Finite depth and numerical integration

At uniform depth h, image separation is ηₙ = √(η² + 4n²h²). The finite-depth loads are Xₕ = ΣₙX(ξ,ηₙ), Yₕ = ηΣₙY(ξ,ηₙ)/ηₙ and Nₕ = ηΣₙN(ξ,ηₙ)/ηₙ. The sums span the chosen integer image indices. These equations and their coefficients are given in the calculator theory record.

Inner kernels are integrated analytically. Fixed-order Gauss–Legendre quadrature is used for the outer integral. An adaptive Gauss–Lobatto reference path evaluates the same mathematical kernels; agreement between them tests numerical implementation, not independent physical theory.

Consistent foot, square-foot, slug-per-cubic-foot and foot-per-second inputs yield pound-force and foot-pound-force. Consistent metre, square-metre, kilogram-per-cubic-metre and metre-per-second inputs yield newton and newton-metre. Unit conversion is not performed by the workflow.

7. Validation Evidence

Repository evidence is assessed as numerical reproduction, internal consistency and workflow behaviour. Field validation remains NOT_EVALUATED because no measured passage record is present in the assessed evidence.

The stored worksheet case supplies an abeam sway value, a nondimensional deep-water value and finite-depth histories. The rounded workbook table supplies deep-water and finite-depth histories. The corresponding tests compare these stored values against the calculator. Their underlying original calculation documents are not supplied with this report; physical accuracy is not inferred from their agreement.

The numerical tests also compare vectorised and adaptive integration, check the deep-water image limit, speed-squared scaling, stagger symmetry and attraction versus repulsion. Workflow tests compare the returned history with the library call, inspect sampled peaks, read the written files and exercise invalid configuration cases.

The report checks pin six displayed extrema, their labels and units to independent raw-kernel hand-calculation literals. The abeam finite-depth and deep-water chart values are also checked against the stored rounded workbook row. A separate library call checks workflow plumbing for every plotted coordinate and load; that internal consistency check is not independent calculation evidence. Rebuilt narrative is compared exactly, while parsed chart values are compared within serialization precision. Exact execution results belong to the accompanying check record; no field qualification follows from a successful rebuild.

8. Key Findings, Limits and Recommendations

Load generation is available for idealised parallel passage, while an operating envelope is not established. The recommendations are tied to the calculation boundary and the evidence gaps.

Complete hull and bathymetry inputs before a design assessment. The parabolic representation omits actual hull lines, free-surface wave effects, viscous separation, bank and quay interactions and transient moored-body feedback. No quantified speed, depth-to-draft or clearance validity range is established by the assessed records. Seek independent hydrodynamic evidence where these effects govern.

Demonstrate quadrature, image-count and stagger-grid convergence for each design case; the existing numerical tests establish agreement only for their stored cases. Use both attractive and repulsive parts of the history and retain the signed yaw moment when coupling to a mooring-response model.

Supply allowable line tension, fender reaction and motion limits before assigning an operating speed or separation. The returned summary label for maximum repulsion is the minimum signed sway; check its sign before interpreting it as a repulsive event. Positive-only input checks do not reject all nonfinite dimensions or densities, so input quality is assessed separately before use.

8.1 Not covered

The separate passing-ship package, its configuration interface and its heuristic depth treatment are not assessed here. Mooring dynamics, line loads, fenders, manoeuvring, multiple simultaneous hulls, wave response, crane operations and installation forecasts are not calculated by this workflow.
