Hydrodynamics module analysis

Spectral motion and operability

1. Executive Summary

The hydrodynamics module is a collection of wave, motion and hydrodynamic loading calculations. Analysis is performed to determine the capabilities and limits of its spectral motion workflow; key results are summarized below.

  • Use the spectral workflow to calculate motion from a supplied response function.
    • The public synthetic example returns 90.0 % weighted operability against an example significant single-amplitude limit of 2.0 m.
  • Keep the demonstration separate from an operating decision.
    • The example uses a unity response function and synthetic sea-state probabilities. Measured response data and an approved motion criterion are not established.

2. Introduction

The purpose, scope and status of the analysis are presented in this section. The main workflow is assessed from a wave spectrum and a response amplitude operator through motion variance, significant amplitude and weighted operability.

A response amplitude operator is the motion amplitude per unit incident wave amplitude at a specified frequency and heading. The present example represents heave, the vertical translation of a floating body. Public callable functions and existing tests are present, so the module is reported as an implemented workflow rather than as a readiness proposal.

Not covered

Coefficient storage and interpolation, environmental loading, diffraction adapters, hull geometry, passing-body interaction, propulsion, river currents, tank sloshing and response file conversion are outside the calculations assessed here. Resistance, effective power, trim sensitivity, appendage sensitivity and computational fluid dynamics are not evaluated.

3. Design Data

The input basis is taken from the public synthetic operability example identified in References. No hull dimensions, density, viscosity, draft or speed are supplied; no physical hull or mesh is inferred.

The angular-frequency grid extends from 0.1 to 2.0 rad/s with 100 equally spaced samples. The heave response amplitude ratio is 1.0 m/m throughout the band. The spectrum peakedness input is 3.3, taken from the function default. The example criterion is 2.0 m, taken from the existing example assertion setup; it is not a sourced operating limit.

The input arrays use angular frequency in rad/s. Wave spectral density has units m²·s. The response function is real amplitude in m/m for this example. A rotational response requires its own angular units; angular and translational criteria are not interchangeable.

4. Analysis Methodology

Linear response is calculated on a common frequency grid. The equations below describe the implemented methods identified in References; no standard certification or measured-response validation is implied.

Sᵣ(ω) = |R(ω)|² Sη(ω), where ω is angular frequency, R is the real response amplitude ratio, Sη is incident-wave spectral density and Sᵣ is response spectral density. The response function is squared point by point by the response-spectrum function.

mₙ = ∫ ωⁿ Sᵣ(ω) dω, evaluated over the supplied band by trapezoidal integration. The symbol n is the moment order and m₀ is the response variance. The significant single amplitude is aₛ = 2√m₀. This is not the crest-to-trough significant height.

For narrow-band Gaussian response with Rayleigh-distributed peaks, P(A > a) = exp(−a²/(2m₀)), where A is peak amplitude and a is the threshold. This probability applies to a peak, not to exceedance during an exposure duration.

The wave-spectrum generator normalizes the discrete spectral area to Hₛ²/16, where Hₛ is significant wave height. Operability is calculated as 100 Σ pᵢ χ(aₛ,ᵢ ≤ aₗᵢₘ)/Σ pᵢ, where pᵢ is sea-state occurrence weight, χ is an indicator, the subscript identifies a sea state and aₗᵢₘ is the supplied criterion.

Basis and criteria

The worked example is compared with its supplied amplitude criterion because that is the comparison performed by the public operability function. No external marine-operation criterion is substituted. Source-code equations and the analytical tests constitute the calculation basis; the test fixture constitutes the input basis. Published experimental validation for this specific example is NOT_EVALUATED.

Model-to-full-scale resistance conversion and wall treatment are NOT_EVALUATED because this workflow evaluates supplied frequency-domain motion rather than a discretized viscous flow field.

Existing validation evidence

The existing seakeeping tests check identity response, zero response, response-amplitude scaling, mismatched array lengths, integration of a flat spectrum, wave-height recovery, known significant amplitude, Rayleigh probability and operability extremes. These are analytical and software consistency checks. Wave-height recovery is partly enforced by discrete normalization and therefore is not independent evidence for spectral shape accuracy.

Physical response accuracy, directional spreading, measured response amplitude operators, full-scale operability and time-domain extremes are NOT_EVALUATED in this report.

6. Key Findings

The calculation supports a limited software-use conclusion. The distinction between an example criterion and an operating limit governs interpretation.

  • The spectral workflow is callable without a flow solver.
    • Arrays, motion variance and sea-state dispositions are returned for further assessment.
  • The example exceeds its criterion in the highest-wave-height case.
    • The weighted percentage is conditional on synthetic weights and a unity response function.

7. Limitations

The applicability limits are determined from the implementation and the evidence basis. Uncertainty in physical response cannot be quantified from the present example.

Only the first dictionary criterion is applied by the operability function. Simultaneous motion-component limits are not evaluated.

The operability function creates a uniform spectrum grid from the endpoint frequencies and sample count. Nonuniform input response grids are therefore not matched point by point.

The response-spectrum function squares real input amplitudes. Complex response functions are not converted to modulus squared by that function; supply real nonnegative amplitudes.

Finite, increasing frequencies, consistent array shapes, positive periods, nonnegative spectral densities and meaningful motion criteria require caller checks. The functions do not comprehensively reject invalid inputs. Sea-state weights are normalized by their sum; empty or zero-total weights return zero operability without establishing a probability model.

The Rayleigh approximation requires narrow-band Gaussian response. Its applicability to broad-band, nonlinear or impact-dominated motions is not established. Positive variance and a nonnegative amplitude threshold are required for physical interpretation.

8. Recommendations

The following actions are tied to the implementation limits and the missing engineering basis. The example is retained as a software demonstration.

  • Exclude the failing synthetic case from the example operating envelope at the present criterion. For an actual assessment, obtain a heading-specific response function and an approved motion limit before assigning an operating envelope.
  • Validate finite ascending uniform frequencies, response units, array alignment and positive total sea-state weight before calling operability. Reject unsupported input rather than infer it.
  • Evaluate each required motion component separately. Combine simultaneous criteria externally until the interface supports joint sea-state assessment.
  • Establish grid and bandwidth convergence against an independent analytical or published response benchmark. Height recovery alone is insufficient because the spectrum is normalized.
  • Obtain exposure duration and peak statistics before converting peak exceedance to an operation-duration probability. The implemented peak formula does not supply that conversion.

10. Acronyms and Symbols

The notation is defined for the spectral heave calculation. No response solver acronym is required to interpret the worked example.

RAO means response amplitude operator. Hₛ denotes significant wave height; Tₚ denotes peak period; γ denotes spectral peakedness; ω denotes angular frequency; R denotes the response amplitude ratio; Sη and Sᵣ denote wave and response spectral densities; mₙ denotes a spectral moment; aₛ denotes significant single amplitude; aₗᵢₘ denotes its criterion; p denotes occurrence weight.
