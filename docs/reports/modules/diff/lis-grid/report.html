AQWA listing grid completeness analysis

Summary

The structural reader returns all 33 declared frequencies, 33 added-mass matrices and 33 damping matrices. A damaged table is refused before conversion or comparison. This is a parser analysis; it establishes no hydrodynamic accuracy or design acceptance.

Inputs

All listing text is generated. The explicit deck contains 33 indexed HRTZ cards. Synthetic frequencies are ωᵢ = i/10 rad/s, i = 1…33. Coefficient column j is i×j for added mass and −i×j for damping, j = 1…12. These are stipulated parser inputs, not physical coefficients. Two synthetic headings are 0° and 90°. Twenty header lines after row ten exercise pagination.

Method and equation sources

T = 2π/ω follows OpenStax, University Physics Volume 1 (2016), §15.1, angular frequency and period. The acceptance identity Nparsed = Ndeclared is an exact cardinality contract, not a numerical tolerance. The card layout follows aqwa_backend.py: AQWABackend.build_deck6. The twelve selected matrix fields retain the existing reader mapping; their physical units and omitted couplings are NOT_EVALUATED here.

The historical 9-row count replays the fixed window described in issue #2107 on this synthetic text. The previous main reader's page-gap cutoff returns 10. These computed counts describe this fixture, not a recovered solver run.

Limits of use and NOT_EVALUATED

  • Solver coefficient accuracy, matrix unit normalization, engineering acceptance and real-output qualification: NOT_EVALUATED.
  • A listing without a matching deck or explicit count has declaration_status = NOT_EVALUATED; internal grid agreement alone does not prove independent completeness.
  • Automatic declaration reading supports explicit indexed HRTZ cards. Ranges, other frequency cards, ambiguous sibling decks and malformed cards refuse; their interpretation is NOT_EVALUATED.
  • Supported table boundaries are different variation-table titles and stability/mooring section titles. EOF is refused. Other listing dialects, multibody selection and incomplete RAO value syntax are NOT_EVALUATED.

Supply the matching deck or an independently known expected count, retain the listing terminators, and correct a refused input before benchmarking. This section is separate from the main diffraction report.

Reproduction

With the repository runtime dependencies available:

PYTHONPATH=src uv run --no-project --with numpy --with loguru --with pyyaml --with scipy --with pydantic --with plotly --with pandas --with jinja2 python scripts/reporting/build_aqwa_lis_grid_report.py --scratch <scratch>

The builder regenerates this page, changes.json and evidence.json. The regression test rebuilds them in temporary storage and compares every byte. No network or solver is accessed by the builder.
