Capytaine module analysis

Supplied-coefficient harmonic-response controls and open-source wrapper review.

1. Executive Summary

The manual response method is PASS against the independent complex-displacement, amplitude and phase controls [H1, H2]. The synthetic coefficients are supplied rather than BEM-computed; they establish neither mesh convergence nor physical accuracy of radiation/diffraction. Native execution, delegated response and NetCDF export remain NOT_EVALUATED against their required evidence.

H1 is a synthetic single-degree translational oscillator with positive and negative real force at opposite heading labels. The heading labels do not model a physical diffraction pattern. Extra damping is absent in the first control and supplied in the second. H2 is an explicitly separate coupled translational hand example, retained from the existing sign regression.

Response is dimensional displacement in m for the supplied force in N. It is not a motion-to-wave ratio in m/m: no incident wave amplitude is supplied for normalization. The numeric containers do not enforce units. Array axes are omega, heading, DOF; matrix rows are influenced DOFs and columns are radiating DOFs. Headings use rad and phases use deg [models.py, H1].

4. Analysis Methodology

With exp(-i*omega*t), differentiation gives qdot=-i*omega*q and qddot=-omega^2*q. Force balance therefore gives Z=K-omega^2*(M+A)-i*omega*(B+B_extra), and Z*q=F [H1]. The public function compute_rao_manual is called with independently constructible BEMResult arrays. Amplitude and phase are returned by that function; periods are obtained through WaveConditions.period_array.

Independent single-degree calculations [H1]

For radiation damping alone, Z=5-(2+1)-i=2-i N/m. Thus q=2/(2-i)=(4+2i)/5 m, |q|=2/sqrt(5) m and phase=atan(1/2) radians converted to degrees. With extra damping, Z=2-2i N/m and q=(1+i)/2 m, |q|=1/sqrt(2) m and phase=atan(1) radians converted to degrees. Reversing the real force reverses the complex response; its amplitude is unchanged and the principal phase decreases by a half turn.

Independent coupled calculation [H2]

M=I kg, A=0 kg, B=I N s/m, K=[[2,1],[1,2]] N/m, omega=1 rad/s and F=[1,i] N. Hence Z=[[1-i,1],[1,1-i]] N/m; direct multiplication gives Z*[(3+4i)/5,(-2-i)/5]=[1,i] N. This reuses the existing coupled sign evidence and is separate from H1.

Each absolute complex, amplitude and phase error is compared with 1e-12 in m, m and deg respectively. This is a double-precision algebra criterion, not an engineering acceptance threshold. Expected values use literal fractions and elementary angles; no second numerical solve is used [H1, H2].

6. Key Findings

Evidence status applies only to the stated method and criterion.

The existing coordinate regression covers requested frequency, heading and DOF ordering in extracted synthetic datasets, and the excitation table uses labeled selection. This does not qualify native BEM accuracy or every table and plot.

Static review observations remain unresolved: solver engine/method fields do not select alternate implementations; unknown Green-function names fall back to a default; configured hydrostatic stiffness is not consumed; native input validation does not establish rejection of all nonfinite inputs; and hydrostatic failures may leave partial results. Delegated response ordering and normalization need readback. Added-mass tables and coefficient plots can pair stored frequency order positionally with periods. Rotational plot labels require angular-unit confirmation. The manual singular-system fallback does not enforce a residual or condition criterion [solver.py, rao.py, results.py]. These observations are not independently reproduced defects fixed by this report.

7. Recommendations

The next qualification step should obtain the public benchmark source described in the evidence table, including its geometry, fluid conditions, coordinate definitions, coefficient normalization and published numerical values. Native readback should then compare matching coordinates and execute a defined mesh-refinement sequence before physical use. No benchmark outcome is asserted.

Targeted independent regressions should resolve the static API observations before affected methods are relied on. No BEM accuracy setting, screening threshold, default geometry or engineering acceptance criterion is changed.

8. Conclusion

The specified synthetic algebra controls are PASS against their absolute criteria. Physical radiation/diffraction accuracy, convergence and native export qualification cannot be established without the listed sources and retained native outputs. The remaining module qualification scope stays open.

10. Acronyms and Review Notes

BEM means boundary element method; DOF means degree of freedom; RAO means response amplitude operator. PASS denotes only agreement with the stated synthetic criterion. NOT_EVALUATED means the evidence needed to calculate or accept that method's result is absent.
