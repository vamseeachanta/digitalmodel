The OrcaFlex module is a collection of preliminary marine analysis utilities and simulation reporting interfaces. Analysis is performed to determine the analytical geometry and weight of a steel catenary riser, and the key results are summarized below.

  • Preliminary hang-off geometry can be calculated from pipe properties, water depth and hang-off angle.
    • The documented regression example returns a top tension of {{number:geometry.top_tension_kN}} kN and a suspended length of {{number:geometry.suspended_length_m}} m in still water. These are analytical estimates, with no allowable tension established.
    • The module can support initial geometry selection; it does not establish how far a host can operate or remain connected.
  • Engineering acceptance requires additional evidence.
    • The separate force-balance calculation agrees with the module at its returned precision. This comparison checks arithmetic within the same idealisation, not physical validation.
    • An allowable operating envelope is not established because capacity, environmental loading and host-motion evidence are absent from this example.

2. Introduction

The riser is represented as a uniform suspended pipe with a horizontal tangent at seabed touchdown. Riser analysis is performed for a public, synthetic regression example rather than a field installation.

The selected workflow starts with pipe properties, calculates submerged weight, and returns still-water catenary geometry and tension. The numerical input and output convention is the International System of Units. This preserves the implementation's native units without introducing a conversion layer.

The wider module supplies environment definitions, model dictionaries, mooring design, installation and pipelay estimates, weather-window calculations, code-check routines, vibration screening, response statistics and simulation report generation. These are distinct capabilities; their presence is not evidence of a completed riser design. Public interface record.

4. Analysis Methodology

The riser is idealised as an inextensible, perfectly flexible catenary under uniform submerged weight. Only still-water gravity and buoyancy are represented; pressure, current drag, bending stiffness, seabed penetration and dynamic motion are excluded from the geometry solution.

4.2 Weight and catenary equations

The implementation equations are reproduced below. The numerical comparison uses an independently arranged form of the same equations. Sources are the analytical implementation and document calculation definition; no standard-derived acceptance coefficient is applied.

d = D − 2t; Dc = D + 2c
As = π(D² − d²)/4; Ai = πd²/4; Ac = π(Dc² − D²)/4
w = g[ρsAs + ρiAi + ρcAc − ρwπDc²/4]

D is steel outer diameter, d is bore diameter, t is wall thickness, c is coating thickness, and Dc is coated diameter. A denotes area; subscripts s, i, c and w identify steel, internal contents, coating and seawater. The corresponding densities are denoted by ρ. Gravity g is {{number:gravity}} m/s² as specified in the implementation. The steel density is {{number:steel_density}} kg/m³ from the material registry; neither value constitutes material certification.

h = water depth + hang-off elevation; a = h sin θ/(1 − sin θ)
H = wa; s = √[h(h + 2a)]; x = a arcosh(1 + h/a)
V = ws; T = √(H² + V²) = w(a + h)

h is the vertical span, θ is the hang-off angle from vertical, a is the catenary parameter, H is horizontal tension, s is suspended arc length, x is horizontal hang-off-to-touchdown distance, V is vertical top force and T is total top tension. At touchdown the tension equals H. This is a geometric distance, not a permissible host excursion.

The supplied estimated total length includes an implementation allowance beyond the suspended length. Its design basis is not established; it is reported for interface completeness and is excluded from procurement or installation decisions. Corrosion allowance is recorded but is not subtracted from the wall in this submerged-weight calculation.

6. Key Findings

The analytical example returns a top tension of {{number:geometry.top_tension_kN}} kN and a suspended length of {{number:geometry.suspended_length_m}} m in still water. These are analytical estimates, with no allowable tension established.

The arithmetic comparison supports reproducibility of preliminary geometry within the stated idealisation. It does not establish wall tension, pressure containment, connection capacity, fatigue life or a permissible operating offset. The top-tension value is the resultant of the ideal cable equilibrium; it is not a pressure-adjusted wall-tension assessment.

7. Limitations

The module output is limited by its idealisations and by incomplete enforcement of configuration intent. The software angle bound is enforced by the input model, but the requested minimum touchdown distance and host draft do not affect the geometry calculation.

The pipe model constrains individual dimensions to positive values but does not establish all cross-field physical conditions, such as a positive bore or a corrosion allowance smaller than wall thickness. Input acceptance therefore does not constitute geometry qualification. The material defaults and coating properties remain assumptions until matched to a physical system.

7.1 Not covered

Current-loaded statics, irregular waves, host-motion response, dynamic stroke, tensioner stops, weak-point design, vortex-induced vibration and fatigue are not evaluated. Drift-off time and connected-operation limits are not evaluated: data needed are environmental cases, a watch circle and a qualified transient model. Do not use this example as a connection authorisation.

Recoil is not evaluated: data needed are closure curves and a qualified transient model. Weak point analysis is not performed. Lazy-wave sizing, top-tensioned configurations, mooring and synthetic-rope design, installation, pipelay, weather windows, automated code checks and simulation-file reporting are outside the worked example. Their individual methods require separate qualification.

8. Recommendations

The next engineering use is a bounded preliminary geometry study with explicit input checks. The following actions address the limitations identified in the configuration and test records.

  • Check the bore, wall allowance, submerged weight and vertical span before accepting a physical case; reject inconsistent geometry. Basis: the input-validation gaps described in the configuration record.
  • Compare the returned touchdown distance against the required separation explicitly. Establish the installed length from a documented layout rather than the implementation allowance. Basis: the unused distance input and estimated-length expression in the geometry method.
  • Establish an independent still-water benchmark, then current-loaded statics, then host-motion-driven irregular-wave dynamics before setting operating limits. Include pressure, bending, seabed contact, connection capacities and fatigue criteria. Basis: the evidence boundary in the existing tests and the idealisation in the method.
  • Require an approved design basis, applicable standard editions and clause-specific criteria before issuing a capacity conclusion. The implementation's reference list alone does not establish compliance.

10. Acronyms and Appendices

The terms and data records below define the example's scope and distinguish assumptions from missing evidence. All physical dimensions are reported in the metric system; thicknesses and corrosion allowance are shown in millimetres to three decimals, retaining the calculation input precision.

10.1 Terms

A steel catenary riser is a suspended steel pipe whose global shape is approximated by a catenary. Touchdown is the point where the suspended segment becomes tangent to the seabed. Hang-off is the upper support. A response amplitude operator describes a host's motion response to incident waves; none is supplied in this example. A true zero is a numerical input or result; “not evaluated” denotes missing analysis, and “not applicable” denotes a method outside the stated scope.
