1. Executive Summary

The mooring module is a static line-response and passing-body force calculator. Analysis is performed to determine the available static calculation capability and the key results are summarized below.

  • The synthetic spread example establishes a reproducible prescribed-offset calculation.
    • The initial line pretension is 75.00 kip and the horizontal fairlead-to-anchor span is 989.57 ft, from the static calculation in Section 5.
    • The displaced example returns −77.77 kip of surge restoring force. This is a prescribed-position result; an equilibrium offset is not established.
  • An operating envelope is not established.
    • The plotted breaking-strength reference is not an allowable tension. A governing design criterion and environmental demand are required before a connected operating limit is determined.
    • Dynamic response and failure transients are not evaluated because the time integration method is absent.

    2. Introduction

    A spread of chain lines connects fixed seabed anchors to moving hull fairleads. Static analysis is performed at prescribed surge, sway and yaw positions using load–distance tables and interpolated line forces.

    The example is synthetic public repository data, not a measured installation. The routed interface accepts a configuration dictionary, writes comma-separated result files and returns the enriched dictionary. The same underlying static functions are available for direct calculations. The public source records are identified in Section 9.2.

    3. Design Data

    The synthetic workflow fixture is adopted without changing its engineering inputs. All input values and their units are retained in the data appendix in Section 9.2.

    3.1 System and environment

    The line material, air weight, length, area, apparent modulus, breaking strength, bottom friction and anchor efficiencies are specified by the example. Fairlead coordinates, initial line directions, pretension percentages and prescribed offsets are also inputs. The vertical anchor-to-fairlead distance governs the line model; it is distinct from the environmental water-depth field.

    ASSUMED - to be confirmed: the synthetic flat-bottom chain arrangement represents the illustrative system only. Actual geometry, material certificates, soil properties and environmental loading are not supplied. Neither wind nor passing-body forces are applied to this static example.

    3.2 Criteria and rationale

    Numerical reproduction is assessed against the frozen legacy values and the tolerances defined by the existing tests. These tolerances account for printed rounding and arithmetic precision; they are not structural acceptance factors. The original numerical method is identified in the repository as legacy edition 6.10, March 2007.

    The minimum segment breaking strength bounds the horizontal-force sampling grid for this chain model. Total tension can exceed that reference at the end of the grid. The table extent is therefore not a design limit. Allowable tension, anchor resistance acceptance, offset allowance and fatigue criteria are NOT_EVALUATED: the governing design basis is required.

    4. Analysis Methodology

    The load–distance curve is calculated first, anchor positions are then obtained from the prescribed pretension, and static forces are calculated at each supplied offset. No time integration or external licensed calculation program is used by this example.

    4.1 Physical model and boundary conditions

    4.2 Equations and calculation sequence

    The following equations describe the grounded, flat-bottom branch used for the low-load portion of this example. The implementation changes branch after the entire line lifts from the bottom. The catenary relations follow the force-balance derivation in Floating and Submerged Structures, Section 28.1.1, derivation Steps 1–4. With zero vertical tension at touchdown, integration gives the suspended span and length; vector resolution gives T = √(H² + (ws)²) = H + wd. Repository locators in Section 9.2 identify the implemented approximation.

    c = H / w;   s = √[d(2c + d)];   z = L − s
    U = c asinh(s/c) + z + ΔU;   T = H + wd

    H is horizontal fairlead force, w is submerged line weight per length, d is vertical rise, s is suspended length, z is grounded length, L is total unstretched length, U is horizontal span, ΔU is the implemented elastic extension and T is total fairlead tension. Forces use pounds and lengths use feet in these equations.

    Ha = max(H − μwz, 0)
    ΔU = Hs/(EA) + (2H − μwz)z/(2EA), when H > μwz

    Ha is horizontal anchor pull, μ is bottom friction as a fraction, and EA is axial stiffness: area multiplied by apparent modulus in consistent units. The extension is obtained by integrating horizontal strain H/(EA) over suspended length and max(H − μwℓ, 0)/(EA) along grounded length ℓ. This applies linear elasticity from University Physics Volume 1, Section 12.3, Tensile Stress and Strain to the frictional tension gradient described in Line theory: Analytic catenary, Laid down line and Seabed friction. When friction exhausts tension, only the loaded grounded length extends. The legacy approximation adds horizontal extension to the inextensible profile; vertical elastic displacement is omitted, so these are not fully coupled elastic-catenary equations.

    w/wair = 1 − ρsw/ρsteel ≈ 0.87

    The weight ratio follows buoyancy in University Physics Volume 1, Section 14.4. Representative seawater and steel densities are 1025 kg/m³ and 7800 kg/m³, from College Physics 2e, Section 11.2, Table 11.1; their ratio gives 0.87 to two decimal places. These are illustrative tabulated values, not measurements at a qualified site condition. This explains the legacy rounded multiplier; neither density is measured for this synthetic example, and the historical density pair is not established. The calculation retains the implementation multiplier rather than substituting the unrounded ratio.

    Hj = B[j/(N − 1)]²;   P = pB/100
    Fi = Hi(ai − ri)/|ai − ri|;
    M = Σ(rx,iFy,i − ry,iFx,i)

    B is minimum segment breaking strength, j is the zero-based table index, N is the table length, P is prescribed pretension and p is its percentage of B. The table contains 50 rows, as defined by the implementation. Quadratic interpolation, with a linear low-load branch, supplies force at intermediate spans. The position vectors a and r denote the fixed anchor and displaced fairlead; the subscript identifies a line. The summed forces are rotated into hull axes. M is yaw moment about the displaced hull origin; positive surge is forward and positive sway is starboard.

    The sampling grid and pretension percentage are implementation definitions, not published design criteria. Force direction follows the unit-vector construction in University Physics Volume 1, Section 2.2; the yaw sum is the planar cross product from Section 10.6, Torque, taken about the displaced hull origin.

    The routed example is evaluated in still water at its initial and displaced positions. Current loading and wave-driven response are not added because the required dynamic calculation chain is not implemented.

    6. Key Findings

    The implemented workflow supplies static geometry, line tensions and restoring forces for the synthetic spread. The initial line pretension is 75.00 kip and the horizontal fairlead-to-anchor span is 989.57 ft, from the static calculation in Section 5.

    Legacy arithmetic agreement supports numerical reproduction within the existing test tolerances. Measured mooring performance, environmental equilibrium, anchor adequacy and a connected operating envelope are not established by that evidence.

    7. Limitations

    The calculation is limited to the implemented static and external-force methods. Engineering acceptance is not inferred from successful execution or from agreement with historical arithmetic.

    7.1 Limits of use

    Off-table force lookups clamp at the final row. A flat force response beyond that point is a numerical boundary, not additional physical capacity. Pretension below the supported interpolation range raises an error. The nonlinear-spring formulations retain a documented inconsistency between the single-segment and segmented branches.

    The reported anchor holding powers are weight multiplied by supplied efficiencies; no site-specific geotechnical resistance assessment is performed. The reported most-loaded-line index is selected using horizontal tension, not necessarily total tension, and broken-line indexing retains legacy ordering. The wrapper replaces its line-input list with output summaries; an independent input copy is required for subsequent evaluations.

    7.2 Not covered

    Elevated attachments, segmented lines, intermediate buoyancy, clump weights, nonlinear springs, fenders, static wind and passing-body histories are available sub-areas but are not calculated in the worked example. The passing-body methods retain legacy empirical and arithmetic conventions; their calibration range is not qualified here.

    Wave response, gusts, drift-off, recoil, failure transients and fatigue are not evaluated. A passing-body force history is an excitation history, not a predicted hull trajectory. Riser-specific travel, wall tension and pressure checks are outside this mooring assessment.

    8. Recommendations

    The static workflow is suitable for reproducing the documented numerical example within its stated scope. Progression to design use is conditional on the following evidence, derived from the documented implementation gaps and boundary behavior.

    • Retain the example as a regression case and compare any changed implementation against the existing frozen values before using its results.
    • Reject off-table spans as unqualified calculations and require an explicit interpolation-range check before reporting operating limits.
    • Obtain component certificates, surveyed geometry, environmental loads, soil resistance and the governing design criteria before assigning allowable tension or offset.
    • Use an independently qualified dynamic method for transient or environmental response until the missing integration chain has benchmark evidence. No dynamic operating limit is supplied by this static example.
