4. Methodology

The independent hand basis is addition for combined mass and the arithmetic average of the two depth endpoints for the midpoint [S8]. Inclusive comparisons for crane capacity and the checklist interval are source behavior [S2, S3]; the locally selected inputs are defined by [S1]. Engineering applicability remains NOT_EVALUATED. No unit conversion is required.

The interval predicate is lower ≤ entered value ≤ upper [S3]. Each item is enumerated as pass, fail or pending. completion_ratio measures passed checks, not the fraction entered: passed count divided by total count [S3]; the arithmetic ratio is supported by [S8]. is_complete requires no failed or pending items for this nonempty example [S1, S3].

Integer counts and exactly representable integer-valued results are checked by exact comparison. The hand test permits an absolute dimensionless roundoff allowance of 1e-15 for the mixed-state ratio only [S6]; this is a test allowance for floating-point division, not an engineering tolerance. Display percentages are rounded to one decimal place; decisions use returned values before rounding.

7. Limitations and Not Covered

Regulatory classification: NOT_EVALUATED. The approximate screening boundaries have no verified governing edition, clause, jurisdiction or applicability assessment in this analysis. The existing implementation is not used as a regulatory source.

Commercial cost and installation weather assumptions: NOT_EVALUATED. Dated quotations, scope, cost basis and an approved installation method and weather analysis are missing. No replacement cost or weather criterion is selected.

Sensor and alert defaults: NOT_EVALUATED. Calibrated sensor evidence, channel units, sampling requirements, fatigue budget and approved alarm criteria are missing. Template helper contents and real monitoring responses are outside this review.

Lifecycle defaults: NOT_EVALUATED. Approved scoring scales, weights, tieback criteria and jurisdiction-specific decommissioning decisions are missing. Recommendations returned by those methods are not adopted here.

Input validation is incomplete in the reviewed source: non-finite facility inputs, direct-item interval ordering, nonnegative tieback slot counts, timezone awareness and positive alert design life require separate regressions before qualification. Empty checklist semantics are not established by the nonempty examples. These are inspection findings, not executed invalid-input campaigns. No source module is changed.

The builder preflights existing output targets, including aliases and nonregular files. Concurrent output replacement is not supported; a rebuild requires exclusive access to its output directory. Native Windows junction behavior has not been exercised by this report.

8. Recommendations

The way forward is to obtain the missing approved criteria and engineering evidence for each NOT_EVALUATED method, then add independent cases before assigning an operational or regulatory disposition. The input-validation gaps require bounded failing regressions before source fixes. No replacement default, rating or commercial assumption is proposed. The originating issue remains open while methods are unqualified.
