Draft — synthetic below-chine hydrostatics

Strip forces and motion data flow, with a bounded independent worked calculation.

1. Executive Summary

The strip hydrostatics are compared with an independently integrated side-pressure load for a synthetic straight-sided wedge. The reference force is 613.125 N/m [H, M]. All worked cases meet the binary64 roundoff criterion stated in the method; dry cases return exact zero. This conclusion covers the specified below-chine geometry and gravity convention.

Dynamic accuracy and physical release are NOT_EVALUATED because experimental or qualified public response targets are absent. A reproducible rebuild establishes calculation freshness only.

4. Analysis Methodology

For the specified wedge, height above keel equals absolute transverse distance. Integrating submerged width gives cross-sectional area. Independently, gauge pressure is integrated over the horizontal projection of both straight sides [H]. The upward force differential is dFz = p cos(beta) ds = p dx, where beta is the side angle to the horizontal, ds is side length and dx is horizontal width.

h₊ = max(h, 0); b = h₊; A = ∫ 2z dz = h₊²;
F′ = 2∫ ρg(h₊ − x) dx = 2ρg(h₊b − b²/2) = ρgA [H].

The integrals run from the keel/centreline to the waterline. Here h is keel depth (m), b is waterline half-width (m), A is area (m²), ρ is density (kg/m³), g is gravity (m/s²), and F′ is upward load per length (N/m). The side count and integral factors are mathematical definitions. Gravity follows the rounded convention in H; G supplies a public reference for that convention.

The production body evaluates area as squared depth divided by the deadrise tangent [M]. The independent hand expression uses the elementary unit slope. Raw forces are compared using relative tolerance equal to 64 binary64 epsilons [H], with zero absolute tolerance; dry cases require exact zero. This allowance covers degree conversion, trigonometry and short arithmetic chains, not model uncertainty or discretisation. Differences are displayed to one decimal place; acceptance uses unrounded values.

Strip and motion data flow — inspection only

Geometry validation and properties feed the strip constructor, which sets longitudinal centres, strip length and the deadrise tangent [D, M]. Added mass takes a supplied half-wetted beam; the contact-width method takes entry velocity and duration; the simplified entry load takes entry velocity; hydrostatics take keel depth; steady lift takes speed and trim, with wetted length unused [M]. These methods return per-length quantities.

The motion constructor estimates displacement mass and pitch inertia. Its added-mass delegate integrates a full-half-beam strip value along the hull; restoring coefficients use a prescribed waterplane approximation and damping uses a critical-damping fraction [S]. Wave number and encounter-phase delegates feed clipped wave-velocity strip loads, which are multiplied by strip length and summed into force and moment. Separate heave and pitch state equations are advanced by the time integrator. The convenience function discards an initial transient window, selects nearest Fourier bins at encounter harmonics, normalises amplitudes and returns phase angles [S]. These steps are described, not qualified by the worked hydrostatic case.

7. Limitations and Not Covered

The worked case is a static straight-sided pressure balance. It does not establish hull equilibrium, total displacement, design loading, drag, resistance, power or suitability for an operating hull. Surface tension, free-surface transients, chine immersion and geometries outside the selected wedge are not represented. No dimensional defect is corrected by a passing rebuild.

  • Impact added mass: NOT_EVALUATED against experiments or public benchmark data.
  • Wetting: NOT_EVALUATED against experiments or public benchmark data.
  • Dynamic damping: NOT_EVALUATED against experiments or public benchmark data.
  • Time integration: NOT_EVALUATED for accuracy or convergence against an independent dynamic reference.
  • Phase extraction: NOT_EVALUATED against an independent phase reference.
  • Response amplitudes: NOT_EVALUATED against experiments or public benchmark data.

Existing tests T check shapes, finiteness, scaling, zero response and broad plausibility ranges. Those checks are behavioral evidence, not experimental targets. The hydrostatic tolerance is a roundoff criterion only; no engineering release tolerance is inferred for the deferred methods.

8. Way Forward

The calculation maintainer should reconcile the hydrostatic docstring with the integral, then review impact dimensions and source attributions before selecting a dynamic benchmark. Input-domain guards and explicit insufficient-window status should be specified and tested. The coordinate, velocity and phase-reference conventions should be documented together.

For motion qualification, independently sourced nonzero targets, governing geometry and loading, units, applicable speed and frequency ranges, and acceptance criteria are required. A synthetic signal should first establish phase and amplitude extraction; time-step, strip and window refinement should then be assessed against those criteria. No operating recommendation follows until that evidence is available. Deferred work remains on the open module issue.
