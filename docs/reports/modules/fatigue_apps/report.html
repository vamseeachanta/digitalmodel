1. Executive Summary

The fatigue applications package implements reference-sea-state load scaling, cycle counting, stress conversion and fatigue damage processing. This analysis checks only the offline converter against a declared uniform-bar force/area surrogate. The synthetic lookup nodes, interpolation and extrapolation are checked separately against the roundoff criterion in Section 6.

The maximum unrounded difference meets the roundoff criterion. Real stress-transfer tables, stress-concentration factors, counting qualification, fatigue damage and service life remain NOT_EVALUATED. The way forward is to qualify the missing inputs and methods before any engineering life assessment is issued.

4. Theory and Equations

For uniform axial stress on a constant area, force equilibrium gives F = integral(sigma dA) = sigma A. Thus sigma_MPa = (T_kN * 1000) / (2500 * 10^-6) / 10^6 = 0.4 T_kN. The area is declared synthetic; kilo, milli and mega supply the exact conversion factors [hand] [prefixes]. This relation does not model bending, local stress or structural flexibility.

The implemented converter evaluates a linear segment, sigma(T) = sigma_a + (sigma_b - sigma_a)(T - T_a)/(T_b - T_a). Interior segments interpolate; the endpoint segments continue beyond the table because the interpolator sets fill_value="extrapolate" [offline]. Independent force/area arithmetic establishes the comparison, rather than the interpolator itself.

For the documented processing flow, wind factors use the squared speed ratio and wave factors the height ratio; scaled tension histories are added [scaling]. Counting produces ranges and counts [counter]. Damage processing evaluates a curve, sums count-to-failure ratios, applies occurrence weighting and annualises by duration [damage]. These equations describe implemented flow; no counting, curve, damage or annual-life result is calculated here.

6. Validation Evidence

The maximum unrounded difference meets the roundoff criterion.

QuantityValue (MPa)Equation and basis
Maximum unrounded absolute difference0.0 MPa[report-test]
Absolute comparison budget1.4e-12 MPa[report-test]
Numerical comparison. Displayed differences are rounded; the decision uses unrounded values.

The comparison allowance is derived for this example: binary64 unit roundoff is u = epsilon/2; gamma_16 = 16u/(1 - 16u). The segment expression uses six rounded operations; force/area with unit conversion uses four; comparison uses one; the non-dyadic prefix factor needs one representation allowance. Four reserve operations give the stated budget [report-test]. A magnification allowance of 4.0 exceeds the largest segment coordinate 8/3 at the upper probe; the stress scale is the maximum hand value 200.0 MPa. The absolute criterion is gamma_16 * 4 * 200 MPa, with zero relative tolerance [report-test] [roundoff]. The budget applies only to these finite synthetic probes and accounts for numerical roundoff, not uncertainty in geometry, calibration or operating conditions.

The existing converter suite checks table nodes, interpolation, extrapolation, unsorted rows and query order [hand]. The new suite checks the unrounded oracle, every displayed quantity and unit, a fresh independent module call, controlled result mutation, inert JSON, isolated paths and identical rebuild bytes [report-test]. Reproducibility does not establish physical validation.

7. Limits of Use

Method or intended useStatusEvidence required before use
Real stress-transfer tablesNOT_EVALUATEDIndependently reviewed geometry, boundary conditions, units and calibrated stress-transfer evidence.
Stress-concentration factorsNOT_EVALUATEDA documented local stress definition, geometric detail and independent calibration.
Fatigue damageNOT_EVALUATEDQualified curve provenance, dimensionally consistent branch selection and independently checked accumulation.
Counting qualificationNOT_EVALUATEDIndependent reference histories, residual-cycle policy, gate sensitivity and full range/count agreement.
Service lifeNOT_EVALUATEDComplete operating cases, occurrence basis, measured sample timing and a qualified damage calculation.
Limits of use. Missing engineering evidence is not represented by a zero result.

The offline converter can create an assumed default table when input is missing or malformed, and can use a fallback slope for an underspecified table [offline]. Explicit synthetic input prevents those branches in this example; the production behaviours remain unchanged.

The alternate counter batch route calls refuse_damage_calculation and raises before file processing [counting] [contract]. Diagnostic counting remains available. The contract registry records separate verdicts for the exported and alternate counters; neither is newly qualified by this report.

The exported damage calculator compares stress against a threshold documented in cycles [damage]. Reference processing truncates histories, discards their timestamps during combination, annualises using an assumed sampling interval, and can represent missing damage cases as infinite life [processor]. These are correctness concerns requiring separate qualification, not evidence of a service-life result. The knowledge pack contains historical checks whose code pins and line references are not treated as current clearance [pack]. The validation framework remains a placeholder [validation].

8. Recommendations

Retain this example as a converter regression and a reproducible report scaffold. Before physical use, supply a reviewed stress-transfer table with its geometry, stress definition, units and calibration; establish concentration factors separately. Reject unqualified fallbacks in the consuming engineering assessment rather than interpreting their presence as evidence.

Resolve the stale load-scaling test interface and test the current processor against independent scaling and superposition controls. Qualify the selected counting path with complete histories and residual-cycle policy; retain the existing refusal for the alternate damage handoff. Resolve the stress/cycle threshold inconsistency, curve provenance, timestamp alignment and missing-case handling before independent damage accumulation and life checks. The parent module report issue remains open for this broader numerical qualification.
