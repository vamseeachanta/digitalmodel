Beam model construction worked example

Summary

This synthetic example demonstrates model construction only through build_beam_model. The admitted element length is 5 m, compared with the independent hand length of 5 m [H1]. The specified coordinates, connectivity, material, section, support and load are read back below. Buckling, stress and displacement are NOT_EVALUATED.

Method and equations

The explicit settings are passed to src/digitalmodel/structural/fe/model_builder.py:build_beam_model. Values in the next table are read from the returned nodes, element, material, boundary conditions and load, rather than copied from the input table.

[H1] The independent hand calculation uses the Pythagorean identity for a straight segment: L = sqrt((x_end - x_start)^2 + (y_end - y_start)^2). For the prescribed coordinates, L = sqrt(3^2 + 4^2) = 5 m. The exponents follow the identity, and the coordinates are specified in [S1].

Limits

This example checks data admission and straight-segment geometry only. No stiffness assembly, eigenvalue analysis, stress recovery, displacement solution or design-code check is performed. The inclined segment does not qualify solver coordinate transformations, support enforcement, material behaviour or load response. Yield stress, density and Poisson ratio are admitted data only; no physical response is inferred from them.

The way forward is separate analytical workflow examples and response checks before engineering use. Full module reporting and qualification remain follow-up work; this example does not complete the parent reporting issue.
