Summary

External matrices require declared SI units and a body-origin or centre-of-gravity reference. The computed example transfers a reciprocal matrix and emits physically equivalent damping inputs with explicit native units. AQWA nonzero external stiffness is refused pending native semantic qualification.

Method

Source 1 supplies matrix block dimensions. Source 2 defines OrcaWave SI force as kN; source 8 defines the kilo prefix, so every N-based block is divided by 1000. Sources 4–6 define the AQWA local CoG axes, SI units and additive FIDP damping.

Source 3 supplies S(r)a = r cross a. For r from target to source, u_source = u_target + theta cross r, T = [[I,-S(r)],[0,I]]. Substitution in quadratic energy or virtual work gives K_target = Tᵀ K_source T. The same relation holds for damping using velocity and power.

Exact symmetry is the supported reciprocal linear-input rule for both matrices; no physical tolerance is introduced. Positivity and passivity are NOT_EVALUATED.

AQWA stiffness disposition

AQWA external stiffness is NOT_EVALUATED: FISK is undocumented; SSTF global-frame composition requires qualification

Each generated input directory receives external-matrix-provenance.json with canonical, normalized and native values, units, points, CoG offset and conversion revision.

Limits of use

Small rotations, parallel axes and constant reciprocal linear matrices are required. The transfer excludes orientation changes, preload-dependent geometric stiffness and nonlinear damping. AQWA supports damping for one unrotated body with coincident mesh and body origins; rotated, positioned and coupled cases are refused. CoG-dependent free-floating matrices are refused because their CoG is determined by the solver.

NOT_EVALUATED

  • Native solver loading, execution and physical response.
  • AQWA structural stiffness: source 7 specifies global-frame SSTF semantics; the old FISK emission has no confirmed contract. Restoring composition remains separate.
  • Positive definiteness, passivity, physical acceptance and field calibration.
  • Legacy matched-case matrix migration without a confirmed data basis.
  • Nonlinear, preloaded, multibody and rotated-body external matrix behaviour.

Way forward: qualify native stiffness coordinates and composition, audit legacy units against their sources, then perform independently reviewed solver benchmarks.
