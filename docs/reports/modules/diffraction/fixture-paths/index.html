Rule and worked example

The reference test resolves from its own file and changes to an empty or decoy working directory. The YAML is parsed as text. The unmodified partial-mesh symmetry is refused; a temporary copy with only that declaration changed checks properties. No mesh qualification is inferred. The test docstring cites YAML lines for depth, density, mass, body name, mesh reference and all periods and headings. Angular frequency is independently calculated as one cycle of radians divided by period.

Known limits and way forward

The audit resolves simple pathlib assignments and existence conditions without executing tests. Dynamic fixtures, helper-returned paths and arbitrary expression syntax require manual review; absence from the table is not proof of coverage. Absolute literals are matched by path suffix, not by content identity. Synthetic configuration strings are distinguished from fixture reads by review. The diffraction guard has only exact, commented configuration-value exceptions. Review the broader unmatched inventory before extending that guard to other modules. Optional mesh packages and the command-line entry point must be supplied to evaluate those cases. The legacy automation file listed under syntax_errors cannot be parsed by this audit.
