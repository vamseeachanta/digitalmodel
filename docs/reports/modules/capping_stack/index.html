Capping-stack scalar module analysis

Static containment comparison and buoyancy balance; draft for technical review.

1. Summary

The public capping-stack API reproduces the synthetic scalar pressure boundaries and submerged-weight ratio derived below [H, S]. The pressure comparison accepts equality and rejects exceedance. These are arithmetic checks against supplied limits; they establish no equipment or operating qualification.

The calculated wet-to-dry force ratio is 50.0% [H, S]. Raising only the supplied sea state changes the returned governing constraint while hook load remains unchanged. The report inventories the wider package without evaluating its interface or inflow/transient methods.

2. Context and scope

The package provides static pressure comparison, nominal interface checks, scalar lift screens and constant-density inflow/transient helpers. Reviewed source revision: 09089a121a16069c4b657d1a320a630a23ab1dd5 [S]. The manifest binds the exact reviewed file bytes and report-generation evidence. A rebuild checks the current bytes; a matching replay alone is not independent numerical evidence.

Scope is limited to scalar pressure containment with zero vertical separation and the submerged-weight ratio. The cases are synthetic fixtures, not a field example, pressure class, deployment recommendation or selected design basis. The existing public-source worked document and its revision history are preserved; its nonzero-column example is separate evidence [W].

4. Method and public function inventory

For z positive downward from the upper datum, a static fluid element gives A dp = ρ A g dz. Integration gives p_res − p_wh,raw = ∫ρg dz = ρgh for constant density. The implementation then uses p_screen = max(p_res − ρgh, 0), U = p_screen/R, and is_contained = (p_screen ≤ R) [H, S]. Pressure units are kg/(m s²), or Pa. The zero clamp is an implementation policy; it is not evidence of flow direction or absolute vacuum.

Buoyancy force is the weight of displaced fluid. Net downward force W = (m − ρV)g, hook force F = DAF × W, lift utilisation = F/SWL, and the returned scalar flag requires both F/SWL ≤ unity and Hs ≤ Hs_limit [H, S]. DAF means supplied dynamic amplification factor, Hs means significant wave height and SWL means the supplied crane load limit.

5. Worked calculation

[H] Independent hand derivation: with ρ = 1000 kg/m³ and h = 0 m, ∫ρg dz = 0 Pa for any finite constant g. For p_res = 3.0, 4.0 and 5.0 MPa, scalar wellhead pressures are respectively 3.0, 4.0 and 5.0 MPa. With supplied R = 4.0 MPa, U = 3/4, unity and 5/4; the exact inclusive flags are True, True and False. These pressures and the rating are arbitrary scalar inputs, not an equipment pressure class.

[H] For mass 2000 kg, volume 1 m³ and water density 1000 kg/m³, W_wet/W_dry = (2000 − 1000 × 1)/2000 = one-half. The dry comparison uses the same mass and zero displaced volume. Standard gravity from [G] supplies dimensional forces; it is not needed for the one-half ratio. The supplied crane limit is the dry force, and DAF is unity, so lift utilisation is also one-half.

6. Checks

The dedicated regression test independently derives the preceding balances without importing implementation constants. Positive values use relative tolerance 1e-12 with no absolute tolerance, solely for binary floating-point roundoff; exact zero and inclusive decision flags are compared exactly. This is not an uncertainty allowance or a decision tolerance [T].

Separate checks compare API replay, two clean external rebuilds and committed bytes. Manifest digests are checked by independent readback. Negative controls change a result magnitude or sign and coherently regenerate both HTML and hashes: internal agreement passes integrity checks but fails the hand oracle. Additional tampering without regeneration fails the manifest check [T]. These are regression and freshness checks, not physical validation.

8. Limits / NOT_EVALUATED

  • Pressure reference and datum: static functions do not tag gauge versus absolute pressure or perform ambient-pressure conversion. Callers must provide a consistent reference for pressure and rating. Flow helpers require absolute pressures. Mixing these conventions is outside the evidence [S].
  • Density: static containment defaults to GAS_COLUMN_DENSITY = 200 kg/m³; the oil and brine presets are 800 and 1030 kg/m³ respectively [S]. These convenience densities are assumed, based on previous experience. Constant density and gravity are assumed; this report supplies density explicitly and checks no nonzero hydrostatic gradient. The clamp does not resolve an overbalanced well or flow behaviour [S, W].
  • Displacement and dynamics: omitted displacement is inferred as mass divided by STACK_BULK_DENSITY. The implemented bulk density is 4000 kg/m³, water density defaults to 1025 kg/m³ and DAF defaults to 2.0 [S]. These convenience assumptions are assumed, based on previous experience; they are not calibrated data. No default is qualified here; displacement, density and DAF are explicit in every displayed case. Water depth is stored but unused by feasibility; current, splash-zone loads, crane geometry and line dynamics are NOT_EVALUATED [S].
  • Input domains: static pressure and lift helpers reject nonpositive rating or crane SWL, but do not comprehensively validate finite or physically meaningful density, depth, mass, volume and dynamic multiplier. Broader input validation and the treatment of buoyant upward force remain open findings, without an algorithm or acceptance-policy change [S].
  • Nominal interface compatibility, connector/seal mechanics, interface standards, well-control operations, emergency-response decisions, deployment suitability and all standards qualification are NOT_EVALUATED. No licensed clause values or acceptance criteria are reproduced.
  • Inflow curves, choke callbacks, local gas-volume conversion, elastic transients, multiphase/compositional behaviour, cavitation and physical calibration are NOT_EVALUATED. Existing transient helpers do not imply transient multiphase qualification [S].

9. Way forward

Maintain the report as bounded arithmetic evidence. Before engineering use, establish pressure reference, external pressure treatment, credible column density, datum and rating provenance. Supply measured mass/displacement, qualified crane and environmental criteria and a justified dynamic-load method. Resolve input-domain and acceptance-policy findings separately. Obtain independent review of methods, standards applicability and physical data before any operational conclusion. The wider qualification portions remain open.
