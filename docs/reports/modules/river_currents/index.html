4. Method and public function review

[P] gives u(z) = u_s (z/H)^(1/m), with height clipped to the wetted depth, and its depth integral. The logarithmic alternative uses shear speed, roughness and a caller-selectable wall constant; it clamps the invalid sub-roughness region to zero. Finite input validation is incomplete in the profile functions; callers need to reject non-finite values before physical use. This remains an open finding.

[B] assumes f(x) = 1 − r + 6 r x(1 − x) on normalized width, and a separate linear bend bias 1 + a(2x − 1). These are unit-mean shapes, without empirical calibration. Confinement is A/(A − beam × draft). Constant-speed bend water-level rise follows u²/g × ln((R + W/2)/(R − W/2)); positive inner radius is required. This radial-balance model does not predict secondary circulation.

[L] integrates signed relative speed times its absolute value over the occupied draft using midpoint quadrature, then scales existing approximate force and yaw coefficients. A full-width under-keel slot drag hypothesis is always applied. It ignores side bypass; joint use with a channel-area factor requires a separate physical basis. The towing comparison uses resultant force × reserve / efficiency and absolute yaw demand against supplied capacities. A positive boolean addresses only those steady comparisons.

[E] uses least squares on transformed plotting ranks (rank − 0.5)/n. The zero-location Weibull annual return calculation uses F(level)^rate = 1 − 1/T; Gumbel requires annual maxima and uses F(level) = 1 − 1/T. Here rate is independent samples per year and T is return period in years. Distribution fitting, declustering, uncertainty, stationarity and physical upper/lower support require further evidence. Seasonal summaries retain input units and supplied labels without annualising.

5. Worked calculation

[H] independently stipulates H = 8 m, u_s = 3 m/s and m = 2, so u = 3√(z/8). Substitution at z = 0, 2 and 8 m gives 0, 1.5 and 3 m/s. Direct depth integration gives q = (3/√8)(2/3)8^(3/2) = 16 m²/s; mean speed = q/H = 2 m/s. These are hand-derived expectations, compared with public API answers in the results table.

For stipulated r = 0.4, ∫₀¹ f(x) dx = 1 − r + 6r(1/2 − 1/3) = 1; the bank factor is 0.6 and centre factor is 1.2. Simpson weights integrate this quadratic exactly [H]. The rectangular continuity factor is (20 × 8)/(20 × 8 − 4 × 2) = 20/19 [H, B]. The corrected quarter and surface speeds are respectively (3/2)(6/5)(20/19) = 36/19 m/s and 3(6/5)(20/19) = 72/19 m/s. These fractions are exact arithmetic, not calibrated predictions.

6. Checks and evidence meaning

The report tests compare normal public API outputs with the independent derivation [H]. Positive answers use relative tolerance 1e-12 and zero absolute tolerance; the bed-zero check is separate. This allowance covers binary64 roundoff in the short arithmetic chain, without adopting a hydraulic accuracy or operational limit.

Numerical oracles, production replay and byte freshness are separate checks. Negative controls change the mean result magnitude or sign while the builder, embedded data and manifest still agree; the independent oracle must reject them. Another control alters delivered results without updating their digest. Two fresh external builds must match each other and the committed deliverables byte for byte.

Existing baseline tests are linked as evidence of their stated assertions, rather than physical qualification: profiles, radial balance and extensions and existing examples. Test execution counts and commands belong to the accompanying change record; this deterministic page contains no run timestamp.

9. Way forward

Retain the mathematical regression as software evidence. Before physical use, obtain surveyed geometry, bed-referenced measured profiles, a consistent signed-flow convention and calibrated bank/bend/load inputs. Assess the full-width slot and section-area hypotheses together before combining them. Qualify temporal sampling, declustering and uncertainty before fitting physical extremes. The maintainers need to resolve finite-input policy and establish a separate acceptance basis; this report does not select design or operating limits.
