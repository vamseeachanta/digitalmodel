4. Method and heading coordinate

φ = k x cos(β) − ω t; x = U t; φ(U t,t) = −[ω − k U cos(β)] t.
ωₑ = −dφ/dt = ω − k U cos(β); k = ω²/g (deep water) [hand-calculation, methods].

Here φ is phase in radians, x is observer position in metres, t is time in seconds, U is observer speed, k is wave number and β measures wave propagation direction from positive x. The propagation projection along x is k cos(β). No absolute value is applied to the signed frequency. Negative values would indicate reversed phase progression; they are not exercised by this case.

The existing tests assign following seas to aligned propagation and head seas to opposing propagation. The contradictory docstring labels are corrected to match those tests and the unchanged arithmetic [methods, direction-contract]. Alignment with other heading definitions or external standards requires a separate convention assessment.

6. Arithmetic checks and criterion

The independent reference uses exact rational arithmetic for dispersion and exact cardinal cosines, without calling production dispersion. The governing comparison is |calculated − reference| ≤ atol + rtol × |reference|. The relative bound is 1.0e-12 and the absolute bound is 1.0e-12 in the compared quantity’s unit [numerical-control]. These are roundoff bounds, not physical accuracy limits.

7. Concrete correctness findings

  • The encounter-frequency docstring reversed the direction labels relative to its formula and the existing direction tests. Only those labels and the unsupported external-convention attribution are corrected [methods, direction-contract].
  • run_parametric_sweep records configured forward speed in result metadata but does not pass it to the solver or invoke the forward-speed correction helpers. A recorded speed therefore does not establish a corrected response [routes, delegates].
  • _extract_hull_params and _parse_variation_id split variation suffixes at underscores, although _make_variation_id emits parameter keys containing underscores. Parameter identity can be lost before dataframe or database storage [routes, delegates].
  • PassingShipSweepConfig.stagger_n_points and parallel are not forwarded by the passing-interaction sweep; the time-history delegate uses its own sampling defaults. Configuring those fields does not establish sampling refinement or parallel execution [routes, delegates].

The latter findings are static code observations and remain follow-up; numerical behavior is retained in this bounded report.
