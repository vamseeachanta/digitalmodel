1. Summary

The synthetic connector outer-fibre stress is 2e+08 Pa against a caller-supplied limit of 7e+08 Pa; utilization is 0.286 [H2]. The returned stress criterion flag is true. This establishes conditional linear-elastic arithmetic, not equipment suitability.

The stipulated tree rate ceiling is 0.000500691 m³/s [H3]. The retained production rate is 0.0005 m³/s and downstream pressure is 4e+06 Pa for the supplied loss [H4]. These quantities do not establish an operational envelope.

2. Context and scope

The trees package exposes rating-envelope, catalogue, liquid pressure-control and separate-port flow functions. The connectors package exposes circular section properties, connector load screening, thermal growth, elastic curvature, family metadata, fatigue assessment and offline structural export. The inventory below distinguishes executed helpers from source inspection.

The connection boundary is caller-managed. Tree handoff supplies separate rates and pressure; connector mechanics accepts geometry, loads and material properties. No public function automatically maps those ports into connector loads, temperatures or a solved network. The synthetic tree bore and connector bore are different, independent arithmetic fixtures; no physical adapter sizing or connected installation is implied.

3. Input basis

Public reference inputs [S1–S4] are separated from illustrative connector geometry, bend radius and pressure boundaries [H1–H4]. The generic steel modulus is 200 GPa [S1]. The 700 MPa comparison is a transverse plate yield datum at 50 mm thickness [S2], not a connector design allowable; no material certificate, allowable factor or service-temperature basis is established. The flow coefficient is derived from the published nozzle speed and water density [S3, S4], not an erosional design coefficient.

4. Method

[H1] With outer radius a = D/2 and inner radius b = a − t, polar area is dA = r dr dθ. Integration over the annulus gives A = π(a² − b²). The bending second moment is ∫(r sin θ)² r dr dθ = π(a⁴ − b⁴)/4, since ∫sin²θ dθ over a circle is π. The elastic section modulus is Z = I/a. All geometric factors follow these integrations; the elastic stress relation follows OpenStax University Physics Volume 1, 2016 online edition, section 12.3, Equation 12.33 [S1].

[H2] κ = 1/R; ε(y) = y/R; σ(y) = Eε(y); σouter = Ea/R; M = ∫σy dA = EI/R; u = σouter/σlimit.

The section remains homogeneous and linearly elastic. The comparison u ≤ unity uses the published plate yield datum [S2] only as a scalar arithmetic limit. The generic modulus [S1] is not grade-certified. No connector allowable, yield qualification, stability, seal capacity, external pressure or load combination is established.

[H3] vceiling = C/√ρ; Abore = ∫ dA = πD²/4; Qceiling = Abore vceiling.

The ceiling reproduces the published rounded nozzle speed [S3]; it is not erosional qualification. Rearranging v = C/√ρ gives C = v√ρ using density [S4]. Flow continuity follows OpenStax University Physics Volume 1, 2016 online edition, section 14.5, Equations 14.13–14.14 [S3]. Sand, corrosion, multiphase slip and pressure-loss prediction remain outside the evidence.

[H4] Qproduction,out = Qproduction,in; Qannulus,out = Qannulus,in; pout = pin − Δpsupplied.

Each rate is compared with its port ceiling without clipping or mixing. With zero annulus rate no annulus capacity is supplied. The supplied pressure drop is a boundary input, not a network solution.

5. Worked calculation

[H1] The independent hand calculation uses a = 1/10 m and b = 1/20 m. The annular area is π[(1/10)² − (1/20)²] = 3π/400 m²; the bore area is π/400 m². Integration gives I = π[(1/10)⁴ − (1/20)⁴]/4 = 3π/128000 m⁴ and Z = I/(1/10) = 3π/12800 m³.

[H2] The outer-fibre strain is (1/10)/100 = 1/1000. Multiplication by the supplied E gives σ = 200e6 Pa. The moment is (200e9 Pa)(3π/128000 m⁴)/(100 m), and the ratio to the published 700e6 Pa comparison datum is 2/7 (0.286); the criterion is u ≤ 1. Curvature is 1/(100 m).

[H3] For the public nozzle example [S3, S4], C/√ρ = (25.5√1000)/√1000 = 25.5 m/s. The 0.005 m diameter gives area π(0.0025)² m² and reference rate 25.5π(0.0025)² m³/s. [H4] The incoming 0.0005 m³/s is retained below that reference ceiling, annulus rate is zero, and the illustrative boundary subtraction (5e6 − 1e6) Pa = 4e6 Pa is passed downstream. Unrounded π is used throughout.

6. Checks and evidence criterion

The dedicated report test compares normal public API outputs and delivered values with the independent integrations and balances above. Positive results use relative tolerance 1e-12 and zero absolute tolerance, allowing binary64 arithmetic roundoff only. Zeros and booleans are checked exactly. This numerical criterion is not a physical modelling tolerance or design acceptance criterion.

The negative controls double an area or rate and reverse a stress or pressure sign while regenerating mutually consistent HTML, JSON and digests. The independent numerical assertion rejects those bundles. A separate result-byte edit is rejected by digest readback. Agreement between builder and report alone is insufficient.

Two fresh external rebuilds are compared byte for byte with each other and the delivered HTML, results, history, manifest and README. These checks establish deterministic delivery and freshness, separately from the numerical oracle. The manifest binds every other delivered file; it cannot contain its own digest. Source digests bind the inspected package bytes, builder, test and house style.

The normal connectors import reaches the fatigue stack, including pylife, even for static helpers. Execution uses the actual dependencies; package initialization is not bypassed. No solver is started, imported or queried by the report calculation.

Open source findings: the combined connector check uses a thin-wall hoop approximation and signed bending contribution with caller/default policy factors. The synthetic thick annulus is used only for exact geometry and pure bending, never for that pressure model. Limiting-fibre stress envelopes, nonfinite-input handling and allowable-stress domain validation require separate assessment. Defaults and embedded rating-table claims are not independently qualified. No arithmetic correction or algorithm replacement is made by this report.

9. Way forward

The synthetic static arithmetic can be reproduced using the command in the accompanying README. Physical use remains conditional on qualified material, geometry, flow-coefficient and load data, plus an explicit acceptance basis. The rating, pressure-control, thermal and combined-stress interfaces should receive independent worked cases before their output is used for design. The separate fatigue, dynamic, network and standards gaps above should remain open.
