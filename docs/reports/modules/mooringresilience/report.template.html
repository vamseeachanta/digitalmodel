1. Executive Summary

The mooring resilience module is a scalar screening calculation for a spread-moored floating system. Analysis is performed to determine how atlas tension, anchor capacity and an illustrative fatigue curve are combined; the key results are summarized below.

  • The public interface can be exercised without a licensed solver.
    • The documented example returns a synthetic fatigue life of @@LIFE@@ years and a margin of @@MARGIN@@ against the chosen @@DURATION@@-year duration. These values test arithmetic, not chain endurance.
  • A design disposition is not established.
    • The material curve, safety factors, damaged-load redistribution and physical benchmark require a qualified basis before the traffic light is used for an operating decision.

2. Introduction

A spread mooring is represented by peak line tension and anchor holding capacity. Screening analysis is performed using scalar environmental queries rather than a coupled floating-body and line model.

The main workflow combines intact strength, damaged strength, foundation demand and a constant-amplitude fatigue proxy. The report covers the public assessment interface and existing atlas evidence. Not covered: line geometry solution, seabed contact, heading effects, coupled dynamics, corrosion, inspection updates, rainflow counting and the separate higher-fidelity fatigue atlas.

3. Design Data

The public unit-test configuration is adopted as an arithmetic example [1]. No site, hull, line layout or measured environment is supplied; a physical configuration is not inferred from the atlas names.

4. Analysis Methodology

The assessment is performed by querying the tension and capacity atlases and then applying scalar arithmetic [1]. The following diagram is a conceptual load path, not a geometry model or installation drawing.

4.1 Calculation basis

Nominal stress range is tension range divided by steel area; this is the axial-stress definition in University Physics, volume 1, 2016, section 12.3 [4]. Fatigue life is expressed using a stress–life curve and constant-amplitude damage accumulation; the general basis is described in Fatigue, 2001, sections “S-N curves” and “Miner’s law for cumulative damage” [5]. Those sources do not establish chain coefficients or the wrapper's environmental scaling.

Damaged tension = redistribution × intact tension.
Strength utilization = supplied strength factor × tension / minimum breaking load.
Foundation utilization = supplied foundation factor × damaged tension / anchor capacity.
Tension range = supplied dynamic coefficient × significant wave height.
Stress range = tension range / steel area, with consistent force and area units.
Allowable cycles = supplied curve coefficient × stress range raised to minus the supplied exponent.
Life = allowable cycles / annual cycles. Fatigue margin = life / specified duration.

These are software definitions [1], not a claim of a standards-qualified mooring model. Redistribution, environmental scaling and the chosen curve require project-independent engineering evidence before design use. The general fatigue source does not validate a single-range approximation for a variable sea-state history.

4.2 Criteria and rationale

Unity utilization means factored demand equals capacity; unity fatigue margin means calculated life equals specified duration. These are the arithmetic comparison limits. The program gives escalation priority when either atlas query is outside its range. Otherwise a utilization above unity or fatigue margin below unity gives red. An amber classification begins above 0.8 utilization or below 2.0 fatigue margin; equality is governed by strict comparisons [1]. These amber thresholds are software policy, not sourced design limits.

The design factors remain NOT_EVALUATED. API RP 2SK is named by the code without an edition or clause. DNV-OS-E301 has an edition mismatch between the tension atlas and citation registry. DNV-RP-C203 is named without a fatigue clause. No numerical value attributed to those licensed publications is reproduced here.

6. Key Findings

The wrapper is executable and its returned quantities can be checked against the declared arithmetic inputs. A physical design conclusion is not established by the public example or the atlas interpolation records.

Damaged demand is a scalar multiplier; actual line removal and load redistribution are not solved. Changing line count does not change the result. The tension query also omits line stiffness, strength, anchor geometry and soil strength; changing those inputs does not regenerate the tension response.

7. Limitations

Use is limited to scalar screening within the active atlas domains [2]. Dataclass construction does not validate positive finite strength, area, cycles, duration or factors.

Active atlas query domains [2]
    @@DOMAINS@@

Wave height and water depth are in metres; peak period is in seconds; anchor dimensions are in metres; undrained strength is in kilopascals. The domain values are read from the evidence records in section 9.2.

Nonpositive stress range or annual damage can return infinite life, and invalid divisors can fail. Missing atlas files can raise errors rather than return escalation. The citation helper is separate from assessment and can return an empty mapping; calculation is not blocked by absent standards evidence.

Wave heading, return period, combined wind and current, seabed degradation, anchor inclination, chain wear and fatigue stress concentration are not represented by this wrapper. Its traffic light is not a station-keeping authorization.

8. Recommendations

The next engineering slice is a bounded screening interface with validated input domains and an explicit basis for every factor. Release for design use is conditional on the evidence below.

Reject nonfinite and nonpositive divisors before calculation. Replace synthetic fatigue inputs with a qualified material curve and a documented cycle spectrum; the stress–life and damage-accumulation basis is given in [5]. Reconcile standards editions and resolve citations within assessment before strength utilization is used for a decision.

For the synthetic failing fatigue margin, select a curve, section area and loading history that produce a margin at least equal to unity against the specified duration, then recalculate. This is the arithmetic remedy defined in section 4, not a specified chain redesign. Compare intact tension, a genuinely removed-line case and anchor loading with an openly documented physical benchmark before assigning an operating envelope. Preserve escalation for any query outside the atlas bounds.

10.2 Quality pre-flight

The arithmetic anchors use the declared synthetic curve. At the first plotted height the nominal stress is calculated from displayed inputs, allowable cycles are divided by the displayed annual cycles, and calculated life is divided by the displayed duration. Another height provides a separate arithmetic anchor. The rebuild test compares rounded module results and the generated document; it does not establish physical accuracy.

The main-workflow tests and report tests are the bounded checks for this document. Coupled solvers, physical benchmarks, the complete repository test suite and browser execution are not part of this evidence. The chart and comment controls are inline and require JavaScript. Comments are exported as a separate JSON file for saving beside this document; importing that file restores them. An explicit save action is required.
