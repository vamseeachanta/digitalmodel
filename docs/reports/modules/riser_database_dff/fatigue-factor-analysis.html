Method and hand result

The existing touchdown step-5 contract defines allowable damage A = 1/F, usage U = D/A = D F, and a pass when U ≤ 1. These are definitions for a supplied criterion, not independently sourced standard requirements. For this example, A = 1/4 = 0.250; U = 0.200 × 4 = 0.8, so the arithmetic passes. Damage derivation from stress cycles is outside this example.

Program result

The builder calls get_riser_dff, resolve_dff and fatigue_damage_verdict. It returns A = 0.250, U = 0.8, and PASS. The regression test independently writes out the arithmetic. The difference from the hand result is 0.0 % for allowable damage and 0.0 % for usage.

Citation note: safety class normal; user-supplied class value 4.0; NOT_EVALUATED: standard class value and table locator unconfirmed.

Limits of use and way forward

This is a conditional arithmetic pass for synthetic inputs. Engineering acceptance requires a qualified safety class, class factor, damage history and component model. A missing class or class factor is refused; a supplied override records both values. Explicit workflow dff inputs retain their previous precedence.

NOT_EVALUATED

  • DNV-OS-F201 (2010) class-table values, exact locator and applicability.
  • Stress histories, S–N basis, SCF, thickness effects, wave and VIV response.
  • Private-context sources, component integrity and engineering acceptance.
