Internal floating roof calculation verification

Date: 2026-11-02. Scope: internal floating roof routine-loss calculations, the synthetic example and the independent normal vent comparison. No measured or client data are used.

The baseline annual result is 3,487 kg/year, matching the independent hand calculation. Components are rim 1,957, fittings 697.2, seams 805.1 and withdrawal 26.84 kg/year. Unit tests use numerical tolerances; rounded documentation values are not substituted into the calculation.

Verification evidence

  • TDD: the initial IFRT test collection failed because the module did not exist. The subsequent pressure-margin retention test failed before that output was implemented.
  • Final related-folder run: 247 passed, including all 38 IFRT cases, the complete existing code-check folder and the fire-safety folder.
  • Ruff check and format check passed for the module, tests and runnable example. The engineering-register checker passed for the three changed Markdown files.
  • The example JSON was executed and read back. Baseline masses, seal/deck comparisons, normal duties of 1,750/2,000 Nm³/h, capacity margins of 250/200 Nm³/h and pressure/vacuum margins of 0.3/0.1 kPa matched their independent arithmetic.
  • A wheel was built with uv build --no-sources --wheel, unpacked into an isolated directory, and imported from that directory. The complete worked example returned 3,487 kg/year with both bundled source records resolving. No scratch files were present in the wheel.

Test command: PYTHONPATH=src uv run python -m pytest tests/code_checks tests/fire_safety -q.

Local defect review

At plan stage, the review targeted method applicability, public-source boundaries, gallon/barrel conversions, seam geometry, column versus leg treatment and unsupported API qualification. The resulting design kept P/V-only tanks outside the routine-loss method and required cited vent factors and thermal duties.

At code stage, equations and selected coefficients were checked against the public EPA document, including rendered seam/withdrawal equation pages and table footnotes. The review targeted the squared vapor-pressure denominator, the absence of an extra π/4 in the seam equation, net throughput, zero-vapor-pressure clingage, citation failures even at zero fitting count and missing packaged sources.

The pressure-boundary test exposed subtraction-order roundoff. Pressure and connected loss are now summed before comparison with the tank limit, so an entered equality passes the stated criterion. Related tests initially used a newer Plotly version than the repository pin; the project version restored the committed report fixtures without changing those fixtures.

Limits and remaining scope

Only routine afloat emissions are calculated. Roof landing/cleaning losses, roof and leg structural design, API 650 circulation/opening design, emergency relief, flashing, blanketing failures and certified vent selection are not evaluated. Vent factors, thermal loads and curve points in the example remain synthetic; a passing entered comparison does not establish API 2000 compliance or tank protection.

The external explorer entry and floating-roof FFS catalog expansion remain follow-ups.

Sources: EPA AP-42 Chapter 7.1 (June 2026), API 2000 public seventh-edition scope and contents, and NIST SP 811, Appendix B.8.
