Synthetic tank bridge acceptance run

Summary

The repository synthetic L-tank is meshed by Gmsh 4.15.1, converted to OpenFOAM v2312 and advanced through the prescribed short sloshing run. Mesh and execution criteria pass. This result establishes the synthetic bridge execution only. Numerical uncertainty, experimental agreement and production geometry readiness are not established.

Basis and method

BASE is 64c14740da3acae9dffa0cea2c83edab1ef783e9. The bridge originated in commit 6d60f6e3ee7f26f7a9a2fb224e63abb518e4da96. Input is examples/cfd/synthetic_l_tank/input.yml: breadth 1.2 m, height 0.8 m and length 1.6 m, with two perforated internal members. The existing write_sloshing_case writer supplies prebuilt-mesh fields, laminar volume-of-fluid dictionaries and rigid prescribed roll. The existing fixture and bridge contracts supply deterministic first-order tetrahedra, wall/atmosphere patches and the all-cell fluid zone. No change from the open sloshing-controls pull request is used.

The writer uses 50 % breadth as the fill elevation and 4 degrees roll. Its analytical period is used for prescribed motion; no experimental period is substituted. The existing pressure-tap renderer samples p_rgh at a point derived from the fixture dimensions; the existing roll-moment renderer integrates the walls about the prescribed axis origin. These are execution diagnostics, without a reference force or pressure comparator.

The criteria are frozen in criteria.json before meshing. Recorded SHA-256 and UTC time prove that order because the change is committed once after computation. The native sequence is fixture generation twice, gmshToFoam, changeDictionary, checkMesh -allGeometry -allTopology, setFields, decomposePar, mpirun -np 2 interFoam -parallel, reconstructParMesh and reconstructPar. Cases and fields remain external to the repository. The separate run record gives the measured duration of each command.

Computation cost

Each deterministic mesh build uses one thread and takes 1.7 s. Conversion and mesh checks take 0.4 s. The native parallel solver command takes 2.5 s; the execution sequence including field initialization, decomposition and reconstruction takes 3.6 s. These times are measured for this small case at two ranks. An equivalent rerun is projected at approximately 7.4 s of preparation and execution, assumed, based on previous experience with this run. Scaling to eight ranks or a production case is not established.

Evidence and limitations

The manifest binds committed text evidence to its SHA-256 digests and records criteria timing. Header lines containing private paths or host identity are replaced with fixed removal markers; numerical output is unchanged. The complete unsanitized logs, mesh and fields are retained outside Git. Probe pressure is p_rgh, not reconstructed physical pressure. Force and moment histories establish finite execution outputs only. No published comparison value is used, no plot is digitised, and no source-data uncertainty is claimed. Further work will require grid and time-step refinement plus an opened public benchmark before quantitative sloshing validation.
