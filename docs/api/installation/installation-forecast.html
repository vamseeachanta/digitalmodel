The alert cutoff is 20.0%, also written as 0.200; it is assumed, based on previous experience. For each complete calibration window, its joint error trajectory is added to the current forecast. The window exceeds the load limit only if its maximum is strictly greater than the limit. The empirical probability is the number of exceeding windows divided by the window count; an alert occurs when that probability is greater than or equal to the cutoff.

Forecast and calibration settings

History-only ridge autoregression; fixed order 40, ridge 0.001. Sampling interval: 0.5 s; forecast horizon: 120 s; calibration stride: 10 samples; minimum of 10 complete calibration windows.

The simulated time axis starts at 0 s. The first back-test origin is sample 119 (three orders of training minus one); its 120 s horizon contains 240 samples. Thus 359 = 119 + 240, and the complete-window count for the displayed origins is N = floor((NOW / 0.5 - 359) / 10) + 1, with NOW in seconds. At NOW 240, 300, 360, 420 and 480 s, N is 13, 25, 37, 49 and 61 respectively.

Two maxima equal the limit and do not exceed it. Three maxima exceed it: 3 / 5 = 60.0 % exceeds the 20.0 % cutoff, so the example alert is true. Exactly 1 / 5 = 20.0 % would also trigger an alert under the inclusive cutoff rule.
