Blasius skin friction: local coefficient to plate mean

Summary

The analytical average of the local Blasius skin-friction coefficient over one plate face is twice its trailing-edge value. The runnable example compares that integral with blasius_plate_cd. This checks the formulas; it supplies no CFD validation evidence.

Basis and coefficient definition

The existing public SU2 laminar flat plate tutorial, in its background section and skin-friction equation, gives the rounded Blasius local law Cf(x) = 0.664 / sqrt(Re_x). That coefficient is retained without fitting. The example assumes steady, incompressible laminar flow with uniform free-stream speed, constant kinematic viscosity and zero pressure gradient.

Here Re_x = U*x/nu and Cf(x) = tau_w(x)/(rho*U^2/2). For constant span b, drag on one wetted face is D = b*integral(tau_w(x) dx). Normalizing by (rho*U^2/2)*b*L gives the plate coefficient Cd = integral(Cf(x) dx)/L, based on that face's area b*L. No second-face or pressure drag is included.

Analytical integration at the leading edge

Re_L = U*L/nu
Cf(x) = Cf(L)*sqrt(L/x)

Cd = lim(epsilon -> 0+) integral(epsilon to L, Cf(x) dx)/L
   = lim(epsilon -> 0+) 2*Cf(L)*sqrt(L)*(sqrt(L) - sqrt(epsilon))/L
   = 2*Cf(L)
   = (2*0.664)/sqrt(Re_L)
   = 1.328/sqrt(Re_L)

The factor two follows from the antiderivative of x^(-1/2); 1.328 is derived as 2*0.664. Although the local coefficient diverges at x=0, its improper integral is finite. The example never evaluates Cf(0) and uses no quadrature grid, leading-edge cutoff or new numerical flow solution.

Synthetic inputs and units

The inputs are chosen for arithmetic illustration, not taken from a measured fluid: U=1 m/s, L=0.1 m, and nu=0.00001 m^2/s. Thus

Re_L = (1 m/s)*(0.1 m)/(0.00001 m^2/s) = 10000
sqrt(Re_L) = 100
Cf(L) = 0.664/100 = 0.00664
Cd = 2*0.00664 = 0.01328

Reynolds number and both coefficients are dimensionless. In centimetres the same physical inputs are 100 cm/s, 10 cm and 0.1 cm^2/s, using the SI prefix definition for centi, which gives 1 m = 100 cm. Their ratio again gives Re_L=10000. Velocity and length change by the length conversion factor; kinematic viscosity changes by its square. Mixing unit systems changes the result.

Run the saved example

From the repository root, in an environment with the package's import dependencies available:

PYTHONPATH=src python examples/openfoam/blasius_integral.py

The executable checks agreement with the package helper and prints:

Formula comparison only; no CFD validation.
Re_L = 10000
Cf(L) = 6.640e-03
Plate mean from integral = 1.328e-02
Plate coefficient from helper = 1.328e-02
integral / Cf(L) = 2.0

The companion tests independently integrate the local power law, check the hand calculation, repeat the calculation in centimetres and execute the saved example. The existing helper's constants are not imported as expected values.

Formula checks and remaining CFD validation

Agreement here establishes consistency of the rounded analytical laws and Reynolds-number construction for the specified assumptions. It does not establish mesh convergence, wall-shear accuracy, boundary-layer profiles, transition behaviour or drag from a solved flow field. The ideal leading-edge law is used as a mathematical reference, not a resolved leading-edge model.

This is partial scope for issue #1167. Remaining work includes reusable comparison of solved wall-shear data with the reference, explicit sample and leading-edge treatment for that data, and solver-backed profile, thickness and mesh-convergence checks. The separate flat plate CFD report describes existing solver evidence; no result from that report is regenerated or extended by this formula example.
