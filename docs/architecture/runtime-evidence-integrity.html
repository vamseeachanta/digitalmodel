Scope and method

The inventory is produced from Python syntax trees without importing scanned modules. Comments and docstrings are excluded. Paths, source lines, enclosing definitions and assertion expressions are retained by the utility for contextual review. Missing or unparseable input refuses the inventory rather than reporting successful coverage. Equivalent lexical paths are normalized before enumeration.

The bounded command is python scripts/audit_runtime_asserts.py src/digitalmodel scripts/review/results/issue-2089/replay-synthetic-example.py. The observed set comprises 2,556 package source files and one selected synthetic replay source: 2,557 files, with 43 assertions across 20 files after the export fix. Traversal does not follow directory symlinks. This is a source inventory, not proof that all evidence entry points or dynamically generated code have been reviewed.

Verification

The new tests and all existing tests for the touched monitoring module pass: 45 tests comprising nine inventory cases, nine export cases, fifteen retained-reference cases and twelve existing monitoring cases. Ruff passes on all four Python files.

Export tests independently substitute the literal JSON value tampered for synthetic. Valid exports remain readable, changed exports refuse, and an existing output remains unchanged. Reference tests pin the original synthetic bytes using the standard-library SHA-256 implementation, then alter the bytes, source identity, digest syntax or availability. The expected refusal is independent of the verifier. Child test oracles use conditional exceptions and emitted JSON rather than assertions that optimization could remove. No engineering constants or tolerances are introduced.

Known limits and later slices

Thirty-four remaining assertion contexts require further review before any trust-gate classification. A readback compares parsed JSON values, not byte identity; it neither establishes source authenticity nor protects the file from later modification. A refused export remains on disk for inspection, as before; no atomic publication guarantee is added. The optimized tests cover a reusable retained-reference primitive, not every canary path. Independent provider review remains pending before merge.
