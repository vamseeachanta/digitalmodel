Foam report-pack fixture comparison

Summary

The sizing fixture produces CSV tables that are compared with the checked-in tables before the report pack is rendered. CRLF pairs are converted to LF in both byte strings for this comparison. All remaining bytes must match.

Inputs and workflow

foam_system_sizing.yml supplies the sizing inputs. The sizing workflow writes the demand, hydraulic-run and hydraulic-terminal tables into data/. input.yml consumes these tables for the report pack. The regression test redirects generated files to a temporary directory; the checked-in tables remain unchanged.

Method and source

The comparison contract is the CRLF-to-LF alternative described in issue #1626. It follows the existing hull-girder demo comparison. The foam CSV writer explicitly selects LF as its line terminator. Git checkout settings can convert these terminators to CRLF.

Only b"\r\n" pairs are replaced with b"\n" before equality is tested. No numeric tolerance, engineering equation, coefficient or acceptance limit is introduced.

Worked example: inputs, method and answer

The following synthetic header and record have identical content and different line terminators. Replacing the CRLF pairs produces the LF input exactly, so the first result is True. Changing the record value leaves different bytes after replacement, so the second result is False. The expected answers follow by inspecting the literal strings independently of the comparison helper.

fresh = b"item,value\nsample,original\n"
checkout = b"item,value\r\nsample,original\r\n"
changed = b"item,value\r\nsample,changed\r\n"

print(fresh.replace(b"\r\n", b"\n") == checkout.replace(b"\r\n", b"\n"))
print(fresh.replace(b"\r\n", b"\n") == changed.replace(b"\r\n", b"\n"))

True
False

Regression coverage

The foam report-pack tests regenerate all demo CSVs against the actual checkout and a temporary CRLF checkout. Literal cases exercise LF, CRLF on either side, and mixed terminators. Negative cases retain rejection of changed values, delimiters, spaces, row order, missing rows, bare CR and missing final LF. The existing sizing, citation and report-rendering checks remain part of the same test module.

From the repository root, run the module using an environment containing the test and reporting dependencies. Select an unused external temporary directory for SCRATCH:

python -m pytest tests/report_pack/test_foam_report_pack.py -q -rA -p no:cacheprovider --basetemp="$SCRATCH"

Known limits

The comparison normalizes CRLF pairs throughout the payload, including quoted fields. Raw-file hashes can still differ between checkouts. Git attributes, production CSV output and sizing results are unchanged. The local regression suite simulates CRLF checkouts with temporary files. Native Windows execution was verified on one CRLF checkout by the second-provider review: 16 tests passed, and the base-revision regression test failed as expected. Hosted Windows CI is not established.
