# Riser VIV screening

This synthetic, offline example screens a uniform pinned span for vortex-induced
vibration using an envelope of the supplied current. It returns cross-flow and
in-line lock-in flags, a narrow-band cross-flow damage rate, and a screening
verdict. It does not establish a detailed response prediction or a certified
fatigue assessment.

Run from the repository root:

```bash
uv run --no-sources python -m digitalmodel examples/workflows/riser-viv-screening/input.yml
```

The structure has a length of 60 metres, outer diameter of 0.2731 metres, inner
diameter of 0.2287 metres, Young's modulus of 207 billion pascals, and mass per
length including added mass of 180 kilograms per metre. Effective tension is
zero newtons. The scalar current speed is 0.22 metres per second and annual
exposure is 0.05. All values are synthetic inputs retained in `input.yml`.

The design life is 20 years and the explicit design fatigue factor is 3.0, giving
a required screening life of 60 years. Mode 1 is cross-flow locked and mode 2 is
in-line locked. The amplitude ratio of 0.5221 gives a cross-flow stress range of
46.989 megapascals. The computed damage rate is 0.0928336563 per year and the
screening life is 10.77195535 years, below the 60-year requirement; the verdict is
`fail`. The in-line flag does not carry an in-line damage estimate.

The input `unit_modal_stress_MPa` is the supplied stress amplitude at unit
amplitude-to-diameter ratio; it is 45 megapascals in this example. Neither stress
nor the design fatigue factor is supplied by the module base configuration.
Missing `dff` raises a configuration error. Missing modal stress when either
lock-in direction is flagged requires escalation instead of a guessed damage.

A scalar current or a nonempty profile of depth and speed pairs is required.
Profiles are screened by their minimum and maximum speeds; spatial mode shapes
and current shear are not resolved. The optional mode count defaults to 10 and
the optional S-N curve to F1 in seawater with cathodic protection. Custom
cross-flow lock-in ranges are rejected because the reused amplitude relation
supports only reduced velocities from 4 to 8.

The applicability checks require detailed SHEAR7/VIVANA-class analysis when
modal stress is missing, a cross-flow amplitude ratio exceeds 0.8, three or more
unique modes are locked, the last checked frequency is below the maximum-current
shedding frequency, or the maximum-current Reynolds number lies outside 300 to
10 million. Escalation suppresses damage and life values in every result output.
A non-escalating `pass` is a screening comparison only; in-line fatigue and a
sheared-current response remain outside this damage estimate.

The methods reference DNV-RP-C205 (2019), Section 9 and its simplified Figure 9-3
amplitude relation; DNV-RP-F105 (2017), Section 4 for natural frequency; and
DNV-RP-C203 for the reused S-N curve and Palmgren-Miner calculation. The Reynolds
window and escalation thresholds are workflow applicability criteria specified
by the approved plan, rather than newly derived standard limits.

Running the command above writes three deterministic outputs under `results/`:
`input.yml`, `input_viv_screening.csv`, and `input_viv_screening_summary.csv`.
As for the other workflow examples, this directory is not tracked by the repository;
the outputs are regenerated by running the example. The YAML echo
contains the input and result blocks without runtime paths or timestamps. CSV
headers declare stress in megapascals and frequency in hertz using the workflow
contract's unit suffixes. Annual cycles omit the design-life multiplier.
